怎麼跟聽損的家人說話

家人有聽力困難時，日常對話常常要講好幾次，雙方都容易累、容易誤會。下面幾個小方法，可以讓溝通輕鬆一點。

  • {% include "screening/family/talk_drawings/call_name.html" %}先叫名字，等他看你再說可以輕拍肩膀，不要從背後或隔壁房間說話。
  • {% include "screening/family/talk_drawings/face_to_face.html" %}面對面、讓他看得到你的臉表情和嘴型能幫助理解。站在光線照得到你臉的地方，不要背光。
  • {% include "screening/family/talk_drawings/speak_slowly.html" %}說清楚、稍微放慢，不用大喊大喊會讓聲音變形，反而更難聽懂，也容易聽起來像在生氣。
  • {% include "screening/family/talk_drawings/mouth_uncovered.html" %}說話時不要遮住嘴巴不要邊吃東西、邊走開或戴著口罩說重要的事。
  • {% include "screening/family/talk_drawings/another_way.html" %}聽不懂時，換個說法同一句話重複很多次不一定有用，換成比較簡單或不同的詞試試看。
  • {% include "screening/family/talk_drawings/quieter.html" %}減少背景噪音說話前先把電視、收音機關小聲，在餐廳選安靜的角落。
  • {% include "screening/family/talk_drawings/write_down.html" %}重要的事寫下來看診時間、地點、吃藥方式，說完再寫在紙上或傳文字訊息，請他確認。
  • {% include "screening/family/talk_drawings/one_at_a_time.html" %}多人聊天時，一次一個人說話換話題時先提醒「我們在講……」。
  • {% include "screening/family/talk_drawings/let_him_join.html" %}耐心，也讓他參與不要替他回答，也不要說「算了，沒事」，被排除在對話外會讓人更不想說話。
