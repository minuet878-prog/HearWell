## 1. 量測方法（照著做可以重現）

### 1.1 環境

- 本機 `python manage.py runserver`（由本人啟動），DEBUG 模式。
- Chrome，視窗寬 1536 px；用本機的假帳號登入，作答過至少一次。
- **CSS 快取**：本機沒有檔名雜湊，改完 `styles.css` 後要強制重新載入（或在 DevTools 停用快取），否則會量到舊的顏色。正式環境由 whitenoise 換檔名，沒有這個問題。

### 1.2 頁面清單

| 頁面 | 網址 | 狀態 |
|---|---|---|
| 首頁 | `/` | 已登入 |
| 登入 | `/login` | |
| 註冊 | `/register` | 一般狀態；錯誤狀態見下方例外 |
| 問卷列表 | `/questionnaire_list` | 已登入 |
| 作答頁 | `/questionnaire/1` | 一般狀態 |
| 作答頁（錯誤） | `/questionnaire/1` | 什麼都不選就送出。選項有 `required`，瀏覽器會先擋下，所以要先在 Console 執行 `document.querySelector('form[action*="questionnaire"]').noValidate = true` 再按送出（伺服器驗證會擋，不寫資料） |

**第一次量測的例外**（下次補上）：
- 註冊（錯誤狀態）沒跑 axe：送出註冊表單需要另外同意，這次沒做。單元測試 `test_aria_describedby_targets_exist` 只確認錯誤與說明有關聯到欄位，**不量對比**。
- 歷史頁（沒紀錄）修正後沒有重量：量修正後時帳號已有紀錄。

### 1.3 自動檢查：axe-core

在每一頁的 DevTools Console 貼上：

```js
if (!window.axe) { await new Promise((ok, err) => { const s = document.createElement('script');
  s.src = 'https://cdnjs.cloudflare.com/ajax/libs/axe-core/4.10.2/axe.min.js';
  s.onload = ok; s.onerror = err; document.head.appendChild(s); }); }
const r = await axe.run(document, { runOnly: { type: 'tag',
  values: ['wcag2a', 'wcag2aa', 'wcag21a', 'wcag21aa', 'wcag22aa'] } });
r.violations.map(v => ({ id: v.id, n: v.nodes.length,
  nodes: v.nodes.map(n => n.target.join(' ') + ' ' + (n.any[0]?.data?.contrastRatio ?? '')) }))
```

- 版本固定 **axe-core 4.10.2**；規則只跑 WCAG 2.0／2.1／2.2 的 A、AA。
- 記錄每條規則的違規數，以及代表性的元素和對比值。

### 1.4 手動檢查清單

| 項目 | 怎麼檢查 | 合格標準 |
|---|---|---|
| 鍵盤操作 | 只用 Tab／Shift+Tab／空白鍵／方向鍵完成「登入 → 作答 → 看結果」 | 能完成，焦點順序合理 |
| 焦點可見 | Tab 時看得到目前焦點在哪 | 每個可操作元素都有可見焦點 |
| 200% 縮放 | 瀏覽器放大到 200%（或視窗縮成一半寬） | 不需要左右捲動、文字不重疊不被切掉 |
| 觸控尺寸 | DevTools 量按鈕、選項、連結的大小 | 至少 44×44 CSS px |
| 字級 | 內文、說明文字 | 用 rem，內文 ≥ 1rem |
| 選項群組 | 作答頁每一題 | 用 `fieldset`／`legend` 把題目和選項綁在一起 |
| 頁面語言與標題 | `<html lang>`、`<title>` | 有設定，而且每頁標題能分辨 |

> axe 抓不到「選項沒有分組」：作答頁修正前完全沒有 `fieldset`，axe 沒有算違規。這項只能靠手動清單。

### 2.3 這次修了什麼

| 修正 | 做法 |
|---|---|
| 內文與 `text-muted` | `styles.css` 在 `:root` 覆蓋 `--bs-body-color`、`--bs-secondary-color` 為 #495057（8.18:1） |
| 分級與錯誤文字 | `.text-success` #1E7B55（5.22）、`.text-warning` #8A5A00（5.93）、`.text-danger` #C23B1C（5.34）、`.text-secondary` #495057（8.18）；只覆蓋文字用的 class，不動主題變數 |
| 選項群組 | 作答頁每題用 `fieldset`／`legend`；助聽器錯誤用 `aria-describedby` 關聯到群組 |
| 選項排法 | 分數題與助聽器題統一為 `.choice-group`：橫排大按鈕、整塊可點、`min-height: 3rem` |

## 3. 待辦（量到但這次沒修）

| 問題 | 影響 | 備註 |
|---|---|---|
| 主色 #78C2AD 當文字或按鈕底（白字）只有 1.96–2.07:1 | 所有主按鈕、問卷連結、首頁大標題 | 要改主題主色或按鈕樣式，牽涉品牌視覺 |
| 導覽列文字 1.81:1 | 每一頁 | 同上 |
| 登入頁浮動標籤 3.33:1 | 登入頁 | Bootstrap 浮動標籤有半透明；可考慮改成一般標籤（跟註冊頁一致） |
| 每頁 `<title>` 都是「HearWell」 | 螢幕閱讀器、分頁辨識 | 各頁加上 `{% block title %}` |
| 「從這裡登入」連結 80×19 px、「查看結果」90×38 px | 觸控 | 未達 44 px |
| 作答頁錯誤只說「表單資料有誤」，沒指出哪一題沒答；分數題的錯誤也沒關聯到該題（讀屏只念「無效」） | 長輩找不到漏答的題目 | 分數題也要像助聽器題一樣，用 `fieldset` 的 `aria-describedby` 關聯錯誤 |
| 選項選取後外框不變、鍵盤焦點只有小圓鈕外一圈 | 看不出選了哪個、焦點在哪 | 可用 `label:has(input:checked)` 換外框色、`label:focus-within` 整框加焦點外框 |
