## 1. 目標

HearWell 蒐集健康資料（篩檢作答、分數、聽力圖、助聽器配戴）與個資（帳號、電子郵件、出生年）。個資法對健康資料要求明確同意，也要求告知「誰蒐集、為什麼、存在哪、給誰、能要求什麼」。做完之後：

- 任何人（不用登入）都能讀到一頁白話的隱私權說明。
- 使用者在 HearWell 處理他的健康資料之前，明確表示同意；網站記得他什麼時候、同意哪一版說明。

這也是 Phase 7 資料匯出、刪除與 Phase 8 分享的前置條件。

> 這份規格處理的是產品行為。說明頁的文字由 AI 擬稿、本人審定；**正式對外前建議請懂個資法的人看過**，AI 不能當法律意見。

## 2. 範圍

### 要做
- 隱私權說明頁：公開、不用登入；65 歲以上讀得懂的白話；內容項目見 4.1。
- 同意：註冊時同意（見待決問題 2）；已經有帳號、還沒同意的人，在使用健康資料相關功能前要先同意（見待決問題 3）。
- 記錄同意：時間與說明版本。
- 說明頁改版時，要能讓使用者重新同意（機制見待決問題 5）。
- 從註冊、登入、全站都找得到說明頁的入口。

### 不做
- 資料匯出、帳號與資料刪除（Phase 7 下兩項）；說明頁先寫「怎麼提出要求」（見待決問題 6）。
- 撤回同意的線上按鈕（撤回等於停止處理，要跟刪除一起做）。
- Cookie 橫幅：本站只用登入必需的 cookie，沒有追蹤或廣告。
- 英文版、其他語言。
- 任何新的資料蒐集、統計或第三方服務。
- 改動既有的作答、計分、聽力圖行為（除了「沒同意不能用」）。
- 管理後台的同意紀錄報表。

## 4. 行為描述

### 4.1 隱私權說明頁

| 項目 | 內容 |
|---|---|
| 誰可以看 | 所有人，不用登入 |
| 內容（個資法第 8 條告知事項） | 誰在蒐集（營運者與聯絡方式，待決問題 1）；蒐集目的；蒐集哪些資料（帳號、電子郵件、出生年、篩檢作答與分數、助聽器配戴、聽力圖）；存放地點與期間；給誰（主機、資料庫、錯誤監控 Sentry 只送什麼不送什麼）；使用者的權利（查詢、閱覽、複製、更正、停止、刪除）與怎麼提出；不提供資料的影響（不能使用篩檢與紀錄）；本站不是醫療診斷 |
| 版本 | 頁面上寫版本與日期 |
| 寫法 | 短句、分段小標、條列；不用法律術語，必要的術語附白話解釋 |

### 4.2 同意

| 項目 | 內容 |
|---|---|
| 誰要同意 | 每一個帳號 |
| 什麼時候 | 見待決問題 2、3 |
| 同意前不能做 | 見待決問題 4 |
| 怎麼同意 | 見待決問題 2（勾選、按鈕文字） |
| 記錄 | 同意時間、說明版本；只有本人看得到自己的紀錄 |
| 說明改版 | 見待決問題 5 |

4. [x] **同意頁內容**（test_consent.ConsentPageTests）
   Given 已登入、還沒同意的使用者，When 打開同意頁，Then 看到說明重點摘要、全文連結、「我同意」與「不同意」兩個按鈕。

   Given 同意頁，When 按「我同意」，Then 記下同意時間與目前的說明版本，並回到原本要去的頁面；沒有原本要去的頁面就回首頁；原本要去的網址是外部網站時也回首頁。
6. [x] **按「不同意」**（test_consent.ConsentPageTests）

7. [x] **既有帳號**（test_consent.GateTests）
   Given 這次上線前就存在、沒有同意紀錄的帳號，When 登入，Then 先到同意頁；他既有的作答、聽力圖等資料不變。
8. [x] **沒同意不能用健康資料功能**（test_consent.GateTests）
   Given 已登入、還沒同意的使用者，When 打開作答、結果、我的紀錄、聽力圖（含新增、比較）頁面，Then 被帶到同意頁，同意後回到那一頁。
9. [x] **沒同意仍可用的頁面**（test_consent.GateTests）
   Given 已登入、還沒同意的使用者，When 打開首頁、隱私權說明、加到主畫面說明、登出，Then 正常使用，不被帶走。
10. [x] **API 一樣擋**（test_consent.ApiGateTests）
    Given 已登入、還沒同意的使用者，When 呼叫讀寫健康資料的 API，Then 回 403；同意之後同一個請求正常回應。沒有登入的人，API 行為和現在一樣。
11. [x] **只算自己的同意**（test_consent.GateTests、ApiGateTests）（規則 8）

12. [x] **重大改版要重新同意**（test_consent.RevisionTests）

13. [x] **小修正不打擾**（test_consent.RevisionTests）
