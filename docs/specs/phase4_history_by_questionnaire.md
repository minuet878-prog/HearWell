## 1. 目標

「我的紀錄」把不同問卷混在一張清單，看不出各自的變化。改成依問卷分開，每份問卷用適合它的圖：HHIE-S 看分數趨勢並分得出有沒有戴助聽器、看得到配戴前後差多少；IOI-HA 看各題跟常模的位置（書頁 168 計分表的樣子）。

## 2. 範圍

### 要做
- 「我的紀錄」改成分頁籤：每份「有紀錄的」問卷一個分頁，每個分頁有自己的網址（重新整理停在同一頁、上一頁回到前一個分頁）。
  - 預設打開最近一次作答的那份問卷。
  - 只有一份問卷有紀錄時，不顯示分頁籤，直接顯示那份問卷。
  - 標籤順序：HHIE-S 在前、IOI-HA 在後。
- HHIE-S 分頁：
  - 配戴前後差值（4a）：最近一次「沒戴」減最近一次「有戴」（不管先後），顯示兩筆的日期與分數和「少了 N 分／多了 N 分／沒有變化」，加一句「分數越低，聽力對生活的影響越小」；缺任一筆就不顯示這一區。
  - 趨勢圖（4b）：沿用現有趨勢圖，點依配戴狀態用不同形狀並標文字：沒戴＝實心圓、有戴＝空心方形、未記錄＝空心三角形。
  - 紀錄清單（沿用現有欄位：日期、總分、助聽器、分級、查看結果）。
- IOI-HA 分頁：
  - 常模圖（3A）：每題一欄（7 欄），灰色帶是最近一次那筆的常模組範圍，點出最近一次各題分數；有「同一組」的前一次時，用另一種形狀疊上前一次。
  - 最近一次「未分組」：只點分數、不畫灰色帶，並說明「需要一筆沒戴助聽器時填的 HHIE-S，才能跟常模比較」；不疊前一次。
  - 紀錄清單（沿用現有欄位：日期、量表名稱、常模組別、查看結果）。
- IOI-HA 結果頁的「看我的紀錄」直接打開 IOI-HA 分頁。

### 不做
- 不同問卷畫在同一張圖（例如在 HHIE-S 圖上標 IOI-HA 時間點，選項 4c）。
- IOI-HA 總分、總結論；HHIE-S 差值的好壞判定或切點。
- HHIA-S 的差值與圖（系統還沒有 HHIA-S 題目）；沒有專屬圖的其他問卷，分頁只列紀錄清單。
- 改 HHIE-S／IOI-HA 的計分、分級、門檻、常模；結果頁除了 IOI-HA「看我的紀錄」的連結以外都不改。
- 篩選、日期區間、一頁幾筆的分頁、匯出、列印、記住上次看的分頁。
- 改首頁、導覽列、作答頁、選問卷頁。
- 改變既有 API 的回傳（是否需要新增 API 屬於實作，計畫時再提）。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本任務特別注意：
  - 只能看到自己的紀錄（第 8 條）；分頁、圖、差值用的資料也一樣。
  - 差值與 IOI-HA 比較由後端算好，前端不重算（第 10 條）；HHIE-S 分數走 `Submission` 的計分方法，IOI-HA 比較走 `scoring.compare_to_norm`。
  - 差值 0 是合法結果（「沒有變化」），不是「沒資料」（第 11 條）。
  - 「未記錄」配戴狀態的 HHIE-S 不算「沒戴」也不算「有戴」。
  - 網址指定的分頁不存在或沒有紀錄時，打開預設分頁，不 404、不 500。
  - 圖要有文字替代（報讀器讀得到每個點的日期、分數、配戴狀態；IOI-HA 每題的分數與常模範圍）；形狀＋文字區分，不只靠顏色；目前的分頁有標示，報讀器也讀得到；字級用 `rem`；320px 與 200% 放大不需左右捲動。

## 4. 行為描述

### 4.1 我的紀錄（既有頁面）

| 項目 | 內容 |
|---|---|
| 網址與方法 | 既有「我的紀錄」，GET；每個分頁有自己的網址（同一頁加上指定問卷） |
| 誰可以使用 | 未登入：導向登入　　已登入：只看自己的　　能否存取他人資料：不行 |
| 回傳／顯示的欄位 | 分頁籤（兩份以上有紀錄時）；HHIE-S 分頁＝差值（有兩筆時）、趨勢圖（配戴狀態形狀）、清單；IOI-HA 分頁＝常模圖、清單 |
| **不能**回傳／顯示的欄位 | IOI-HA 總分、總結論；差值的好壞判定；別的問卷的紀錄出現在這個分頁 |
| 需要計算的資料 | 由誰計算：後端　　計算路徑：HHIE-S 分數走 `Submission` 計分方法；IOI-HA 比較走 `scoring.compare_to_norm` |
| 空資料時的行為 | 沒有任何紀錄：維持「您還沒有做過篩檢紀錄」；某份問卷沒紀錄：沒有那個分頁；缺沒戴或有戴：不顯示差值區；IOI-HA 最近一次未分組：不畫灰色帶並說明 |

### 4.2 IOI-HA 結果頁（既有頁面，只改一個連結）

| 項目 | 內容 |
|---|---|
| 行為 | 「看我的紀錄」連到我的紀錄的 IOI-HA 分頁；其他內容不變 |
