## 1. 目標

第一次來的使用者按首頁的「3 分鐘了解我的聽力狀況」後，登入或註冊完會直接到問卷，不會繞回首頁再按一次；過程中每一步都知道為什麼要登入、接下來要做什麼。

## 2. 範圍

### 要做
- 登入、註冊成功後，回到「原本要去的頁面」；沒有的話維持回首頁。
- 「原本要去的頁面」在登入頁、註冊頁之間來回切換，以及輸入錯誤（密碼錯、帳號重複等）之後，都不會弄丟。
- 「原本要去的頁面」只接受本站網址；外部網址一律當作沒有，回首頁。
- 有「原本要去的頁面」時，登入頁顯示：「請先登入，沒有帳號請按註冊。登入後會帶您回到剛剛的頁面。」
- 首頁未登入時，主按鈕下方顯示：「首次使用請先註冊，已有帳號請登入」；已登入不顯示。主按鈕文字不變。

### 不做
- 不登入也能先作答、最後才註冊（要改資料庫設計，屬於產品定位決策）。
- 註冊改用 `UserCreationForm`、收生日（Phase 2 另一項）。
- 錯字、英文殘留（例如登入頁的「Welcome」，屬於 Phase 2 另一項）。
- 已登入的人打開登入頁時自動跳轉。
- 導覽列對未登入者顯示「篩檢」連結。
- 註冊頁顯示說明文字。
- 登出後回到原本的頁面。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 開放式重導（open redirect）：只能導向本站網址，要有測試。
  - 新文字的字級用 `rem`；對比要達 WCAG AA，不用 `text-muted`。
  - 測試用假帳號，不用真實資料。

## 4. 行為描述

### 4.1 登入頁

| 項目 | 內容 |
|---|---|
| 網址與方法 | 既有登入頁，GET 顯示、POST 登入 |
| 誰可以使用 | 所有人 |
| 回傳／顯示的欄位 | 有「原本要去的頁面」時多顯示說明文字；切到註冊頁的按鈕帶著它 |
| **不能**回傳／顯示的欄位 | 無 |
| 需要計算的資料 | 無 |
| 空資料時的行為 | 沒有「原本要去的頁面」→ 不顯示說明，登入後回首頁 |

### 4.2 註冊頁

| 項目 | 內容 |
|---|---|
| 網址與方法 | 既有註冊頁，GET 顯示、POST 註冊 |
| 誰可以使用 | 所有人 |
| 回傳／顯示的欄位 | 「從這裡登入」連結帶著「原本要去的頁面」 |
| **不能**回傳／顯示的欄位 | 無 |
| 需要計算的資料 | 無 |
| 空資料時的行為 | 沒有「原本要去的頁面」→ 註冊後回首頁 |

### 4.3 首頁

| 項目 | 內容 |
|---|---|
| 網址與方法 | 既有首頁，GET |
| 誰可以使用 | 所有人 |
| 回傳／顯示的欄位 | 未登入：主按鈕下方多一行「首次使用請先註冊，已有帳號請登入」 |
| **不能**回傳／顯示的欄位 | 已登入：不顯示那行字 |
| 需要計算的資料 | 無 |
| 空資料時的行為 | 不適用 |

- [x] 1. 假設未登入，當在首頁按主按鈕，則被帶到登入頁，而且登入頁顯示說明文字。
- [x] 2. 假設未登入，當直接打開登入頁（沒有原本要去的頁面），則不顯示說明文字。
- [x] 3. 假設從主按鈕來到登入頁，當帳密正確並登入，則直接到問卷列表。
- [x] 4. 假設直接打開登入頁，當帳密正確並登入，則回首頁。
- [x] 5. 假設從主按鈕來到登入頁，當密碼打錯，則留在登入頁並顯示錯誤；接著輸入正確密碼登入，則仍然到問卷列表。
- [x] 6. 假設原本要去的頁面是外部網址（例如 `https://evil.example.com`、`//evil.example.com`），當登入成功，則回首頁，不會被帶到外部網站。
- [x] 7. 假設從主按鈕來到登入頁，當按「註冊」，則註冊頁帶著原本要去的頁面；註冊成功後直接到問卷列表。

- [x] 9. 假設從主按鈕來到註冊頁，當按「從這裡登入」，則登入頁仍帶著原本要去的頁面，並顯示說明文字。
- [x] 10. 假設註冊時原本要去的頁面是外部網址，當註冊成功，則回首頁。
- [x] 11. 假設未登入，當打開首頁，則主按鈕下方顯示「首次使用請先註冊，已有帳號請登入」；假設已登入，則不顯示。
- [x] 12. 新加的文字（登入頁說明、首頁提示）字級用 rem、黑字，不用 `text-muted`。
