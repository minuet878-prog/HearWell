## 1. 目標

聽損者可以把自己的「HearWell 聽力報告」用一個連結傳給家人（例如用 LINE），家人不用註冊就能看；
連結 7 天後自動失效，本人可以隨時取消，也看得到家人打開過幾次。讓家人了解聽損者的狀況，進而參與照護。

## 2. 範圍

### 要做
- 聽力報告頁上方加「分享給家人」區塊（列印時不印）。
- 本人產生分享連結：產生前先看一段說明「拿到連結的人都看得到這份報告」，按確認才產生。一次只有一個有效連結。
- 家人打開連結：先看到封面，按「打開報告」才看到 C3 聽力報告的唯讀版（內容見 4.2）。
- 連結 7 天後失效；本人可以隨時取消；失效或取消後，家人打開看到「這個連結已經失效」。
- 本人看得到：連結有效到什麼時候、開啟次數、最後一次開啟時間。
- 「傳給家人」按鈕：沿用家屬衛教頁的手機分享方式（不支援時顯示網址讓人複製）。
- 刪除帳號時，分享連結一起刪除（連結立刻失效）。
- 「下載我的資料」加入分享紀錄（不含連結代碼）。
- 隱私權說明頁補上「您可以主動把報告分享給別人」（小修正：更新日期，不要求重新同意）。

### 不做
- 家屬帳號、家屬註冊、家屬填問卷、家屬協助作答。
- 同時有多個有效連結；記錄連結是給誰的（關係）。
- 分享報告以外的頁面（我的紀錄、單筆結果頁、聽力圖頁、作答明細）。
- 寄 email、簡訊；網站自己串 LINE（只用手機內建的分享）。
- 額外的通行碼、驗證碼（B4 已決定不用）。
- 記錄是誰打開的（IP、裝置、瀏覽器）；只記次數與最後時間。
- 讓本人自訂期限、延長期限（要延長就取消後重新產生）。
- 在分享區塊顯示已失效連結的紀錄（只在「下載我的資料」看得到）。
- 保存「分享當下」的報告版本。
- 分享頁面的 API endpoint、React 化。
- 修改計分、門檻、聽力圖判讀；在報告上加新的判讀。
- 修改 C3 報告本身的內容或版面（除了家人版需要的差異）。
- 其他健康資料頁面全站加「不快取」（C3 審查 4 留下的待辦，另外做）。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 這是全站第一個「沒登入也看得到健康資料」的頁面。只能用連結本身找到資料，連結必須無法猜到、無法列舉。
  - 本人的管理功能（產生、取消、看開啟次數）限定 `request.user`（規則 8）：A 不能取消或查看 B 的連結，回 404。
  - 家人頁面的分數、分級、判讀走和 C3 報告同一條計算路徑（規則 10），0 分照實顯示（規則 11）。
  - 家人頁面（封面與報告）：瀏覽器不快取、搜尋引擎不收錄、從這頁點出去的網站拿不到這個連結。
  - 字級用 `rem`（規則 13）；家人也可能是長輩。

## 4. 行為描述

### 4.1 本人：分享管理（聽力報告頁上方的區塊）

| 項目 | 內容 |
|---|---|
| 位置 | 聽力報告頁上方；列印時不印 |
| 網址與方法 | 看狀態跟著報告頁 GET；產生、取消 POST |
| 誰可以使用 | 未登入：導到登入頁　　已登入但未同意：導到同意頁　　能否操作他人的連結：不能（404） |
| 沒有有效連結時（含過期、已取消） | 說明「拿到連結的人，不用登入就看得到這份報告；連結 7 天後失效，您可以隨時取消」＋「產生分享連結」按鈕；按下後先出現確認說明，按確認才產生。不顯示上一個連結的紀錄 |
| 有有效連結時 | 連結網址、「傳給家人」按鈕、有效到（台灣時間）、已開啟 N 次、最後一次開啟時間（沒開過寫「還沒有人打開」）、「連結有效期間，家人看到的是您最新的報告」、「取消分享」按鈕；沒有「產生分享連結」按鈕 |
| 同時有效的連結 | 最多一個；已有有效連結時再送出產生請求，不會多一個 |
| 沒有任何紀錄時 | 不能分享（報告本身就沒有內容） |

### 4.2 家人：看分享的報告

| 項目 | 內容 |
|---|---|
| 網址與方法 | 連結網址，GET；網址裡只有無法猜到的代碼，沒有使用者編號 |
| 誰可以使用 | 任何拿到有效連結的人，不用登入 |
| 封面（打開連結先看到） | 「家人分享了一份 HearWell 聽力報告給您」、連結有效到 ○月○日、「打開報告」按鈕。**不含任何健康資料**（分數、分級、聽力圖、年齡都沒有）。打開封面不算開啟次數（LINE 預覽只抓得到封面） |
| 報告（按「打開報告」後） | C3 報告的內容（摘要框、聽力圖、HHIE-S／HHIA-S、配戴前後、IOI-HA、免責聲明），頁首註明「這是家人分享給您的報告，連結有效到 ○月○日」；可以列印。每次顯示報告算一次開啟 |
| **不能**顯示的內容 | 網站導覽列中需要登入的項目、「分享」管理功能、使用者名稱、出生年、手寫「姓名：＿＿＿」欄、email、內部編號 |
| 年齡 | 本人有填出生年才顯示年齡；沒填就不顯示 |
| 資料時間點 | 最新：連結有效期間本人新增的紀錄，家人重新打開就看得到 |
| 本人的同意狀態 | 不影響連結：本人還沒同意新版隱私權說明時，連結照常有效 |
| 連結失效（過期、取消、帳號已刪除、代碼不存在）| 封面與報告都顯示同一個畫面「這個連結已經失效，請向分享的家人要新的連結」，狀態碼 404，不透露是哪一種原因 |

### 4.3 其他

| 項目 | 內容 |
|---|---|
| 下載我的資料 | 每個分享連結（含已失效）列出：產生時間、有效到、是否取消、開啟次數、最後開啟時間；不含連結代碼 |
| 隱私權說明頁 | 加一段：您可以主動把報告分享給別人；拿到連結的人不用登入就看得到；7 天失效、可隨時取消。更新日期；不要求已同意的人重新同意 |

  - 代碼明碼存：規格要求本人看得到網址，雜湊就顯示不出來。
  - `ReportShare` 不註冊進 admin：多一個看得到代碼的地方，規格也沒要求。
