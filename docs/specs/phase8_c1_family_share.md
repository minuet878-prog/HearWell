## 6. 待決問題（討論題）

- [x] ~~**Q1 「家屬版」的核心是什麼？**（可複選，請排優先順序）~~ → **已決：B（家屬看得到結果）＋ C（給家屬的溝通與陪伴內容）**；不做 A、D（2026-10-17）
  - A. **家屬也填一份問卷**：家屬從自己的角度評估「聽損對家人（或對自己）的影響」，例如 HHIE 的配偶／重要他人版（HHIE-SP），或評估第三方困擾的量表（如 SOS-HEAR）。網站並排兩份分數：本人和家屬看法的落差，在臨床上常是討論的起點（例如本人低估困擾）。代價：要選有中文版、可以使用的量表，並確認版權；會多一份計分規則。
  - B. **家屬看得到聽損者的結果**：本人同意後，家屬可以看紀錄或聽力報告（C3 的延伸）。代價：要設計分享機制（見 Q3），這是「把健康資料交給另一個人」，風險最高。
  - C. **給家屬看的溝通與陪伴內容**：例如怎麼跟聽損家人說話、怎麼陪他去驗配助聽器。代價：內容要你寫或審；比較接近 C2 衛教內容，不太需要新的資料結構。
  - D. **家屬協助作答**：長輩自己不會用手機時，家屬幫忙操作，紀錄上標註「由家屬協助填寫」。代價：小；但要想清楚協助填寫的分數算不算本人的自評。
  - 我的看法：A 最能發揮網站「有計分、有紀錄」的特點，而且不需要先蓋分享機制；B 價值高但牽涉最廣，建議等 A 或 C 做完再做。**最後請你依臨床經驗判斷。**
- [x] ~~**Q2 如果選 A：用哪一份量表？**~~ → 不做 A，不適用
  - 你臨床上用過、而且有中文版的家屬版量表是哪一份？（HHIE-SP、SOS-HEAR，或其他）
  - 版權：可以放在網站上免費使用嗎？出處要怎麼寫？（之前 IOI-HA 寫了書名頁碼）
  - 有沒有正式的切點或判讀方式？沒有的話，和 HHIE-S 分項一樣只顯示分數、註明「僅供參考」。
- [x] ~~**Q3 家屬和聽損者的資料怎麼連在一起？**（影響 A 和 B）~~ → 見下方 B2：分享連結
  - A. **家屬用聽損者的帳號填**：在同一個帳號裡多一份「家屬填寫」的問卷。最簡單；代價：家屬看得到本人全部的紀錄，本人沒辦法分開管理。
  - B. **家屬自己註冊帳號，雙方互相連結**：本人發邀請、家屬接受，本人可以隨時解除。最完整；代價：要做邀請、連結、撤回、兩邊的刪除，範圍最大。
  - C. **一次性的填寫連結**：本人產生一個連結傳給家屬，家屬不用註冊就能填一份問卷，結果回到本人帳號。代價：連結外洩時別人也能填；要設過期。
  - 這題我先不給建議，要看 Q1 選什麼。
- [ ] **Q4 家屬是誰？**（開工時再確認：同時能有幾個有效的連結）
  - 只限一位（例如配偶、主要照顧者），還是可以多位？
  - 要不要記錄關係（配偶、子女、其他）？臨床上這個資訊有沒有用？
- [x] ~~**Q5 第一次先做到哪裡？**~~ → B、C 拆成兩份規格，C 先做（`phase8_c1_family_guide.md`）
  - 這一項可能很大。建議先挑一個最小、但對使用者有實際價值的版本，做完再決定下一步，像聽力圖分兩批做那樣。
