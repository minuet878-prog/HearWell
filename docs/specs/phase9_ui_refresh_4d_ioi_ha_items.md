## 1. 目標

IOI-HA 結果頁現在每一題只寫「您的回答：……（低於常模）」，使用者看得到比較結果，但不知道這代表什麼、可以做什麼。
這一份讓使用者看完結果頁，就知道哪幾題值得注意，以及下一步可以怎麼做。

## 2. 範圍

### 要做
- IOI-HA 結果頁加上逐題的白話解讀（哪些題目有解讀，見 Q1、Q2；怎麼呈現，見 Q3）。
- 解讀文字：本人要求 AI 先擬草稿（2026-10-18），本人修改並確認後才定稿（見 Q5）。
- IOI-HA 出處區加一句解讀文字的來源（Q5-A）。

### 不做
- 本人確認之後，AI 自行修改解讀文字。
- 改 IOI-HA 的常模、分組規則、比較方式（`低於常模／在範圍內／高於常模` 照舊）。
- 改「我的紀錄」的 IOI-HA 圖。
- 改 HHIE-S 的結果頁與建議文字。
- 新增題目、改題目文字（規則：已上線的問卷不能動）。
- 用 LLM 產生或挑選解讀（規則 9）。
- 其他頁面（是否包含聽力報告與家屬分享版，見 Q4）。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 規則 9：顯示哪一段解讀，只能由固定規則決定（題號＋比較結果），不能用 LLM。
  - 解讀文字是衛教說明，不能寫成診斷；每段都能讓使用者「帶去跟聽力師討論」。
  - 規則 8：結果頁仍然只看得到自己的作答（非本人回 404，既有行為不變）。
  - 字級用 `rem`；320px 不能左右捲動；200% 字級不破版；螢幕閱讀器念得到解讀。

## 4. 行為描述

### 4.1 IOI-HA 結果頁

| 項目 | 內容 |
|---|---|
| 誰可以使用 | 已登入、作答者本人（他人回 404，照舊） |
| 有常模組別時 | 每一題照舊顯示題目、您的回答、比較結果；**「低於常模」的題目**，在該題下方多一段解讀（該題專用的文字） |
| 「在範圍內」「高於常模」的題目 | 不加解讀（照舊） |
| 呈現 | 解讀直接寫在該題「您的回答」下方，淡藍底框，在同一個清單項目裡（Q3-A） |
| 其他頁面 | 聽力報告（自己的、家屬分享版）不動（Q4-A） |
| 未分組時（沒有沒戴助聽器時填的 HHIE-S） | 不加解讀；照舊提示「需要一筆沒戴助聽器時填的 HHIE-S，才能跟常模比較。」 |
| 一題都沒有低於常模時 | 不加解讀；照舊 |
| 頁尾那句「如有多項低於常模，可以帶這份結果跟您的聽力師討論。」 | 保留（Q6-A） |
| 出處區 | 多一句「逐題解讀由聽力師依臨床經驗撰寫，不能取代個別諮詢。」（Q5-A；只在 IOI-HA 結果頁） |

### 4.2 解讀文字（AI 擬草稿，本人修改確認，2026-10-18）

| 題號 | 項目 | 低於常模時的解讀 |
|---|---|---|
| 1 | 使用時間 | 您每天戴助聽器的時間比多數使用者短。可能是還不習慣、戴起來不舒服，或覺得聲音不自然。可以告訴聽力師哪些時候不想戴，請他幫忙調整。 |
| 2 | 幫助程度 | 在您最想聽清楚的場合，助聽器的幫助比多數使用者少。可以記下是哪些場合聽不清楚，帶去請聽力師調整設定。 |
| 3 | 剩餘困難 | 戴了助聽器之後，您仍然覺得困難比多數使用者多。吵雜的場合本來就比較難，可以請聽力師檢查設定，也可以一起練習溝通的技巧。 |
| 4 | 值得程度 | 您覺得助聽器值得的程度比多數使用者低。可能是效果不如預期、使用上麻煩，或花費的考量。把您在意的地方告訴聽力師，一起看看怎麼改善。 |
| 5 | 生活影響 | 戴了助聽器後，您的日常生活或工作受到的影響仍比多數使用者多。可以說說哪些活動最困擾您，請聽力師針對這些情況調整。 |
| 6 | 干擾他人 | 您覺得聽力困難對身邊的人造成的干擾比多數使用者多。可以和家人聊聊他們的感受，也可以請家人陪您一起找聽力師討論溝通的方法。 |
| 7 | 生活樂趣 | 助聽器讓您享受生活的程度提升得比多數使用者少。可以想想有哪些想做、卻因為聽不清楚而放棄的事，和聽力師討論怎麼幫上忙。 |
