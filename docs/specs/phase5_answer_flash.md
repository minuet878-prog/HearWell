## 1. 目標

打開 HHIE-S／HHIA-S 作答頁時，畫面不要先閃過全部題目再換成一題一頁；JavaScript 失敗時，網頁版作答表單仍然要能用。

背景（本人 2026-10-16 回報，根本原因已確認）：網頁版表單是 React 失敗時的備用，伺服器一送來就畫出來；React 要等程式下載完、再向伺服器拿到題目，才把表單藏起來。中間那段時間畫面上就是全部題目。

## 2. 範圍

### 要做
- 有 JavaScript 的瀏覽器：一開始就不顯示網頁版表單，改顯示「題目載入中…」
- React 拿到題目：照現在一樣換成一題一頁
- React 拿題目失敗，或 5 秒內都沒有回報（例如程式檔下載失敗）：把網頁版表單顯示出來（本人 2026-10-16 定 5 秒）

### 不做
- 把題目直接放進頁面（選項 B）
- 改動一題一頁的作答流程、中途儲存、送出
- IOI-HA 作答頁（不載入 React，本來就不會閃）
- 聽力圖頁（沒有網頁表單備用，不會閃）
- 網頁版連按兩次（F-10）

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本任務特別注意：
  - 任何情況下，使用者最後都要看到能作答的畫面（一題一頁或網頁表單），不能停在空白或永遠的「載入中」。
  - 「題目載入中…」要讓螢幕閱讀器唸得到；字級用 `rem`。

## 4. 行為描述

### 4.1 作答頁載入過程

| 情況 | 畫面 |
|---|---|
| 沒開 JavaScript | 跟現在一樣，直接顯示網頁表單；沒有「題目載入中…」 |
| 有 JavaScript，題目還沒拿到 | 不顯示網頁表單，在說明文字下方（原本表單的位置）顯示「題目載入中…」；問卷名稱、題數、說明照常顯示 |
| 拿到題目（5 秒內） | 一題一頁，「題目載入中…」消失 |
| 拿題目失敗（伺服器錯誤、斷線） | 立刻顯示網頁表單，「題目載入中…」消失 |
| 5 秒到了，題目還沒拿到 | 顯示網頁表單，「題目載入中…」消失；之後才拿到題目也維持網頁表單，不換成一題一頁（使用者可能已經開始作答） |
