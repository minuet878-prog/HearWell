## 1. 目標

每個元素現在分量都差不多、也沒有分組，畫面看起來散。這一輪只改「每一頁都共用」的部分：
內容寬度、間距、頁尾、程度標籤的顏色、可點擊卡片、按鈕層級。改一次全站生效，讓後面三輪有一致的基礎。

## 2. 範圍

### 要做
- 主要內容設最大寬度並置中（寬度見 Q1）。
- 間距只用一組固定的值（見 Q2），把明顯不一致的地方（例如頁尾前面突然空一大段）改掉。
- 全站共用的頁尾（內容與樣式見 Q3）。
- 程度標籤（Badge）：有底色的小標籤，文字照常寫出來；套用範圍與顏色見 Q4。
- 可點擊卡片統一一種樣子（見 Q5）：選擇問卷、我的紀錄的每一筆、聽力圖列表。
- 按鈕層級：每頁只有一顆實心主要按鈕，其他改成外框或文字連結（各頁的主要按鈕見 Q6）。

### 不做（留給後面幾輪）
- 第 2 輪：趨勢圖分開有戴／沒戴、同一天多筆、IOI-HA 刻度與「分數越高越好」說明。
- 第 3 輪：帳號設定頁（搬走下載資料／刪除帳號）、第二層分頁改成分段控制、首頁區塊重排、刪除首頁重複的那句話、「可達 10 年」補來源。
- 第 4 輪：首頁插圖、步驟卡片、信任元素、結果預覽、聽力圖縮圖、問卷卡片圖示與標籤、IOI-HA 逐題解讀文字。
- 換主色、換字型、換字級（18px 不變）；換掉 Bootstrap；新增 CSS 框架或套件。
- 改計分、分級、門檻、聽力圖判讀；改任何文案的意思（只搬位置、改樣式）。
- 改列印版（聽力報告、家人版報告的列印樣式維持黑白）。
- 改 React 頁面的內部畫面（趨勢圖、作答頁、聽力圖輸入），只受外層寬度與頁尾影響。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 字級、間距、寬度一律用 `rem`（規則 13）。
  - 顏色不能是唯一的資訊：標籤一定要有文字；文字對底色對比至少 4.5:1（WCAG AA）。
  - 整張卡片可點時，螢幕閱讀器念出來的連結名稱要說得出是哪一筆（日期＋結果），不能只念「›」或「查看」。
  - 改完 axe 量測維持 0 個問題（無障礙基準線）；手機 320px 不能左右捲動、200% 字級不破版。

## 4. 行為描述

### 4.1 內容寬度
| 項目 | 內容 |
|---|---|
| 主要內容 | 最大寬度 40rem（18px 字級下約 720px），置中；比 40rem 窄的螢幕照現在左右留白 |
| 頁首、導覽列、頁尾 | 底色照樣滿版；裡面的文字、按鈕對齊同一個 40rem 寬度 |
| 手機底部分頁列 | 不變（滿版、固定在底部） |
| 原本就比較窄的 | 登入／註冊表單（30rem）、聽力圖輸入（32rem）維持原本寬度 |
| 列印 | 不受影響（聽力報告的列印樣式不變） |

### 4.2 間距
| 項目 | 內容 |
|---|---|
| 可以用的值 | Bootstrap 原有的間距：0.25／0.5／1／1.5／3rem（class 的 1–5）。0.25rem 只用在同一組內的行與行之間 |
| 規則 | 這一輪新寫或改到的 CSS，margin／padding／gap 只用這組值；看到的明顯不一致（例如頁尾前面的大空白）改掉 |
| 不做 | 不逐行改寫既有 CSS 裡其他的間距值（例如圖表內部、邊框粗細） |

### 4.3 全站頁尾
| 項目 | 內容 |
|---|---|
| 出現在 | 每一頁（所有繼承共用版型的頁面，包括登入、註冊、家人版報告、連結失效頁） |
| 內容（照順序） | 「給家人看：怎麼跟聽損的家人溝通」「把 HearWell 加到手機主畫面」「隱私權說明」三個連結；「結果僅供參考，不能取代聽力檢查與醫師診斷。」；「聯絡我們：hearwellweb@gmail.com」（信箱可以點開寄信） |
| 樣式 | 淺灰底 #f1f3f5、深灰字 #343a40（10.34:1）、連結主色（7.47:1）；說明文字比內文小一級 |
| 頁面上原本的連結 | 「我的紀錄」頁的「給家人看」拿掉（頁尾有）。首頁的「給家人看」「加到主畫面」也拿掉（2026-10-17 本人追加：頁尾有了就重複）；首頁的免責聲明那段（含「由執業聽力師開發」）留到第 3、4 輪 |
| 手機 | 在底部分頁列的上方，捲到最下面才看到，不被分頁列蓋住 |
| 列印 | 聽力報告、家人版報告列印時照樣不印頁尾 |

### 4.4 程度標籤
| 項目 | 內容 |
|---|---|
| 樣式 | 圓角小標籤，淺色底＋深色字，文字一定寫出來 |
| 問卷分級 | 無明顯影響＝綠（#e3f4ec／#1e7b55）、輕度到中度影響＝黃褐（#fff4d6／#8a5a00）、顯著影響＝紅（#feece7／#c23b1c）、無法判讀＝灰（#f1f3f5／#495057）。和結果頁色塊同一組 |
| 聽力圖程度 | 正常＝綠；輕度、中度＝黃褐；中重度、重度、極重度＝紅；資料不足＝灰 |
| 套用的地方 | 「我的紀錄」每一筆的問卷分級（IOI-HA 沒有分級，不放標籤）；聽力圖列表每一張的左右耳程度；單張聽力圖頁的左右耳程度 |
| 不套用 | 結果頁的大色塊（不變）、聽力圖比較頁、聽力報告（黑白列印） |

### 4.5 可點擊卡片
| 項目 | 內容 |
|---|---|
| 套用的地方 | 選擇問卷的每一份、「我的紀錄」的每一筆、聽力圖列表的每一張 |
| 樣子 | 整張卡片就是一個連結；右側一個「›」箭頭；滑鼠移上去或手指按住時底色淺藍（#eef3fa）、邊框主色；鍵盤焦點有明顯外框 |
| 連結名稱 | 就是卡片上的文字（日期、分數、分級／程度、問卷名稱），螢幕閱讀器念得出是哪一筆；箭頭不念 |
| 拿掉的 | 「我的紀錄」每一筆的「查看結果」按鈕 |
| 點下去 | 和現在一樣：作答頁、結果頁、單張聽力圖頁 |

### 4.6 按鈕層級
| 頁面 | 實心（主要） | 改成外框 |
|---|---|---|
| 我的紀錄 | 沒有 | 「聽力報告」 |
| 聽力報告 | 「列印或存成 PDF」；分享區塊點開後的「確認產生」、已有連結時的「傳給家人」 | 「產生分享連結」 |
| 其他頁面 | 不變（已經只有一顆） | — |
