## 1. 目標

使用者可以自己刪除帳號和在 HearWell 的全部資料，落實個資法第 3 條的「刪除」權利，
並讓隱私權說明頁上「保存到您刪除帳號為止」這句話成真。刪除前提醒先下載（資料匯出已完成）。

## 2. 範圍

### 要做
- 一個「刪除帳號」確認頁（入口：「我的紀錄」頁底部「下載我的資料」旁，用不顯眼的樣式；隱私權說明頁也放連結），說清楚會刪掉什麼、不能復原，並提供「先下載我的資料」連結。
- 使用者再輸入一次密碼確認後，一次**真的刪除**該帳號和它的全部資料（帳號、問卷與每題答案、聽力圖與每個點、同意紀錄；不做匿名化），登出，回首頁並顯示「已刪除」說明。
- 隱私權說明頁更新：可以自己刪除帳號；刪除後備份裡的資料會在 6 小時內自動清除（Neon History window，本人 2026-10-17 在後台確認為 6 hours）。屬於小修正：只更新說明頁的「更新日期」，不加版本號，已同意的人不用重新同意。

### 不做
- 只刪部分資料（單筆問卷）；單張聽力圖本來就能刪，不動。
- 冷靜期、可以反悔的「軟刪除」、排程清除。
- 刪除前寄 email 通知或確認信。
- 管理員替別人刪除的介面或指令（寄信要求時再處理）。
- 匿名化、保留統計資料。
- 密碼重設、忘記密碼功能。
- 修改問卷、題目、計分、門檻。
- React 版畫面、或新的 API endpoint。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 只能刪 `request.user` 自己（規則 8）；網址不帶任何使用者編號。
  - 刪除只在測試資料庫驗證，不在 shell 對正式資料庫操作（規則 12）。
  - 刪除必須是「全部成功或全部不做」：中途出錯不能留下刪一半的資料。
  - 只收 POST 才真的刪除；GET 只顯示確認頁。

## 4. 行為描述

### 4.1 刪除帳號確認頁

| 項目 | 內容 |
|---|---|
| 網址與方法 | 一個固定網址；GET 顯示確認頁，POST 執行刪除 |
| 誰可以使用 | 未登入：導到登入頁，登入後回來　　已登入：可以（還沒同意新版說明的人也可以）　　管理員帳號：不能（`is_staff` 或 `is_superuser`；顯示說明、沒有按鈕）　　能否刪除他人：不能（網址沒有編號） |
| 顯示的內容 | 會刪掉什麼（帳號、問卷紀錄 N 筆、聽力圖 N 張、同意紀錄）、「刪除後無法復原」、「先下載我的資料」連結、密碼欄位、「刪除帳號」按鈕（危險色）、「取消」回「我的紀錄」 |
| 刪除的資料 | 帳號、全部問卷與每題答案、全部聽力圖與每個點、全部同意紀錄 |
| 空資料時的行為 | 沒有任何紀錄的帳號照樣可以刪（數量顯示 0） |

### 4.2 刪除完成

- 登出（這個帳號在其他裝置的登入也一併失效），回首頁，顯示「您的帳號和資料已經刪除」。
- 同一個使用者名稱之後可以被重新註冊（是全新的帳號，看不到舊資料）。

## 5. 驗收條件

- [x] 1. 假設 使用者 A 有問卷、聽力圖、同意紀錄，當 A 在確認頁完成確認並按「刪除帳號」，則 A 的帳號、所有問卷與每題答案、所有聽力圖與每個點、所有同意紀錄都從資料庫消失。
- [x] 2. 假設 使用者 B 也有資料，當 A 刪除帳號，則 B 的帳號和全部資料一筆都沒少。
- [x] 3. 假設 A 刪除成功，則 A 被登出、回到首頁並看到「已刪除」說明；用原本的帳號密碼登入失敗。
- [x] 4. 假設 A 同時在兩台裝置登入，當 A 在其中一台刪除，則 另一台下一次操作時也是未登入狀態。
- [x] 5. 假設 密碼錯誤或沒填，當 按「刪除帳號」，則 什麼都沒刪，留在確認頁並顯示錯誤（錯誤訊息關聯到欄位、焦點移過去）。
- [x] 6. 假設 未登入，當 打開刪除網址，則 被導到登入頁，登入後回到確認頁。
- [x] 7. 假設 已登入，當 用 GET 打開刪除網址，則 只顯示確認頁，什麼都沒刪；頁面列出 A 的問卷筆數、聽力圖張數，並有「先下載我的資料」連結。
- [x] 8. 假設 POST 沒帶 CSRF token（防偽造請求的隨機碼），則 回 403，什麼都沒刪。
- [x] 9. 假設 刪除途中發生資料庫錯誤，則 全部還原，A 的資料一筆都沒少。
- [x] 10. 假設 帳號沒有任何問卷和聽力圖，當 刪除，則 成功。
- [x] 11. 假設 A 有一筆 IOI-HA 是依據某筆 HHIE-S 分組的（兩筆互相關聯），當 A 刪除，則 兩筆都刪除成功，不會因為關聯而失敗。
- [x] 12. 假設 A 刪除後，有人用同一個使用者名稱註冊，則 註冊成功，新帳號看不到任何舊資料。
- [x] 13. 假設 使用者還沒同意目前版本的說明，當 打開刪除網址並輸入正確密碼刪除，則 可以刪除（不被導到同意頁）。
- [x] 14. 假設 管理員帳號（`is_staff` 或 `is_superuser`），當 打開確認頁，則 看到「管理員帳號請先在後台移除管理員權限」、沒有刪除按鈕；就算直接送出 POST（含正確密碼），也什麼都沒刪。
- [x] 15. 假設 任何人，當 看隱私權說明頁，則 寫明可以自己刪除帳號、連到確認頁，並寫明「備份中的資料會在 6 小時內自動清除」。
- [x] 16. 假設 已登入，當 看「我的紀錄」頁，則 有「刪除帳號」連結到確認頁（沒有任何紀錄時也有）。
- [x] 17. 假設 密碼頭尾有空白（註冊、登入時都保留空白），當 輸入同一組密碼刪除，則 刪除成功。（審查 1 追加，2026-10-17）
- [x] 18. 假設 這台裝置上有作答到一半的暫存，當 送出刪除表單，則 暫存從裝置上清除（跟登出一樣）。（審查 2 追加，本人 2026-10-17 同意）
