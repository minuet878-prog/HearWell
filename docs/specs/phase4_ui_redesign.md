## 1. 目標

讓 65 歲以上的使用者和家屬覺得這是可信的健康工具：字夠大、對比夠、按鈕好按，在手機（最窄 320px）上不用左右捲動、不用放大，導覽用詞一看就懂；同時把無障礙基準線量到但還沒修的 7 項一起解決。

## 2. 範圍

### 第 1 批：共用版型（`feat/ui-redesign`）
- 主色換成深藍 `#1f4e8c`（按鈕、連結、導覽、焦點外框）。
- 全站基礎字級 1.125rem（18px），標題等比放大；系統預設字型。
- 導覽：電腦版在上方、手機版改成底部固定分頁列（圖示＋文字）；用詞與項目改版（見 4.2）。
- 響應式：每一頁在 320px 寬不需左右捲動。
- 無障礙基準線第 3 節 7 項全部處理（見 4.4）。
- 趨勢圖改版：配合新主色，比較頁選 A「柔和分級底色＋每點標分數」（見 4.5；2026-10-15 追加）。

### 第 2 批：逐頁動線（另開分支，開工前補這一節的細節與劇本）
- 首頁有明確的起點；結果頁引導下一步；作答頁顯示進度（不靠 JS）。

### 不做
- 第 2 批的項目（首頁內容改寫、結果頁下一步、作答進度）。
- 改動計分、分級、建議文字的內容或計算；改動 API、資料模型。
- 分級顏色（綠／黃／紅）的語意。
- 趨勢圖的資料與行為（筆數、問卷挑選、摘要文字、錯誤訊息、浮動框內容）：只改外觀。
- 深色模式、可切換字級的按鈕、多語系。
- 新增任何 JS（導覽與選項樣式只用 HTML／CSS）；外部圖示字型或字型檔。
- 漢堡選單、帳號設定頁。
- 除了導覽、頁面標題、作答錯誤訊息以外的文案修改。

## 4. 行為描述

### 4.1 主色與字級（全站）

| 項目 | 內容 |
|---|---|
| 主色 | `#1f4e8c`（白字 8.31:1）；按鈕、連結、導覽、鍵盤焦點外框 |
| 字級 | `html` 基礎 1.125rem；內文、表單、按鈕跟著放大；不再到處個別加 `fs-4`／`fs-5` 補字級 |
| 對比 | 所有文字與背景 ≥ 4.5:1（大字 ≥ 3:1） |
| 分級文字顏色 | 維持現在的意義與對比（已在 Phase 2 修過） |

### 4.2 導覽

| 項目 | 已登入 | 未登入 |
|---|---|---|
| 導覽項目 | 首頁／開始篩檢／我的紀錄 | 首頁／登入／註冊 |
| 頁首右上 | 「目前登入：帳號」＋「登出」按鈕 | 不顯示 |
| 電腦版（寬螢幕） | 導覽在頁首下方，橫排 | 同左 |
| 手機版（窄螢幕） | 導覽改成畫面底部固定分頁列，每格圖示＋文字，整格可按；頁面內容不會被它蓋住 | 同左 |
| 目前所在頁 | 該項目有視覺標示，且有 `aria-current="page"` | 同左 |

- 「開始篩檢」連到問卷列表；首頁也顯示（現在首頁會隱藏「篩檢」）。
- 登入、註冊頁也顯示導覽（現在這兩頁沒有導覽）。
- 登出維持 POST（按鈕送出表單），不改成連結。

### 4.3 響應式

- 每一頁在 320px 寬：不需左右捲動，文字不被截斷或重疊。
- 「我的紀錄」的卡片在窄螢幕上改成上下排列（日期與總分／助聽器／分級／查看結果）。
- 圖片、表格、趨勢圖不超出畫面寬度。

### 4.4 無障礙待辦（基準線第 3 節）

| # | 問題 | 改成 |
|---|---|---|
| 1 | 主色當文字或按鈕底只有約 2:1 | 用新主色，≥ 4.5:1 |
| 2 | 導覽列文字 1.81:1 | ≥ 4.5:1 |
| 3 | 登入頁浮動標籤 3.33:1 | 改成一般標籤（標籤在輸入框上方），跟註冊頁一致 |
| 4 | 每頁 `<title>` 都是「HearWell」 | 首頁「HearWell 聽力自我照護」、登入「登入｜HearWell」、註冊「註冊｜HearWell」、問卷列表「開始篩檢｜HearWell」、作答「HHIE-S 作答｜HearWell」（問卷名稱）、結果「篩檢結果｜HearWell」、我的紀錄「我的紀錄｜HearWell」 |
| 5 | 「從這裡登入」「查看結果」觸控尺寸不足 | 所有按鈕、連結、導覽項目至少 44×44 px |
| 6 | 作答頁錯誤沒指出哪一題沒答 | 頁面上方：「還有 N 題沒有回答，請看標示紅字的題目。」；每一題沒答的題目下方顯示「這一題還沒有回答」，並用 `aria-describedby` 關聯到該題的 `fieldset`；已選的答案保留 |
| 7 | 選項選取後外框不變、焦點只有小圓鈕 | 選取的選項整個框變色加粗；鍵盤焦點時整個選項框有明顯外框 |

### 4.5 趨勢圖樣式（A：柔和分級底色＋每點標分數）

| 項目 | 內容 |
|---|---|
| 版面順序 | 標題「問卷名 總分變化」→ 摘要框 → 圖（白底圓角卡片）。摘要框獨立在圖的上方（驗收後追加） |
| 摘要框 | 淡藍底圓角框，分三行：「最近一次（日期）」、大字「N 分」＋粗體分級文字、變化那句（「比上一次增加／減少 N 分。」「和上一次相同。」；只有 1 筆時「再做一次篩檢，就能看到分數的變化。」）。資訊與原本的摘要句相同，只是拆行 |
| 線與點 | 主色 `#1f4e8c`；最近一次的點實心、較大，其他點空心（白底深藍框） |
| 分數標示 | 每個點旁直接寫該次總分（含 0 分），不用滑過去才看得到；點在頂端時字放在點下方，不超出圖 |
| 分級底色 | 淡色：無/極輕微 `#e3f4ec`、輕度到中度 `#fff4d6`、顯著 `#feece7`；分級標籤靠右，用分級的深色字（`#1e7b55`／`#8a5a00`／`#c23b1c`），對比皆 ≥ 4.5:1 |
| 縱軸 | 不顯示數字與軸線（每個點已標分數，分級範圍看底色標籤；驗收後追加，避免左下角擠在一起） |
| 橫軸日期 | 放得下就每個點都標；放不下時自動省略中間的，但第一次與最近一次一定顯示；日期與圖之間留空白（驗收後追加） |
| 不變 | 資料（最近 20 筆、同一份問卷）、摘要文字、錯誤訊息、浮動框內容、字級 rem、`aria-hidden` 與文字替代 |
