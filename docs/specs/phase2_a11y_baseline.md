## 1. 目標

在換成 React（Phase 4）之前，用一套**可以重複執行**的方法量一次全站無障礙狀況，留下基準報告當作對照；同時修掉已知、對 65 歲以上使用者影響最大的三項。

## 2. 範圍

### 要做
- **基準報告** `docs/accessibility_baseline.md`（進版控）：
  - 量測方法：頁面清單、工具（axe-core，版本寫明）、手動檢查清單，寫到之後可以照著重做。
  - 修正**前**的結果（每頁）與修正**後**的結果。
  - 量到但這次不修的問題，列成待辦。
- **修正一：文字對比**：全站內文與 `text-muted` 改成 `#495057`（對白底 8.18:1），在 `styles.css` 一處覆蓋主題變數。
- **修正二：選項群組**：作答頁每一題（含助聽器題）用 `fieldset` 包起來，題目文字放在 `legend`；助聽器題的錯誤訊息要讓螢幕閱讀器讀得到（跟選項群組關聯）。
- **修正三：選項排法**：分數題與助聽器題統一成**橫排大按鈕**（整塊可點、觸控高度至少 3rem，窄螢幕自動換行）。
- **修正四：分級與錯誤文字顏色**（量測後追加，本人同意）：只覆蓋「文字用」顏色，不動主題變數——`.text-success` #1E7B55（5.22:1）、`.text-warning` #8A5A00（5.93:1）、`.text-danger` #C23B1C（5.34:1，錯誤訊息同色）、`.text-secondary`（「無法判讀」）#495057（8.18:1）。

### 不做
- Minty 主色（薄荷綠 #78C2AD，對白底 2.08:1）用在按鈕、連結、導覽列的對比問題：列進報告待辦。
- 量測發現的其他問題：列進報告待辦。
- admin 頁面。
- 深色模式。
- React／PWA。

## 4. 行為描述

### 4.1 量測頁面

首頁、登入、註冊（含錯誤狀態）、問卷列表、作答頁（含錯誤狀態）、結果頁、歷史頁。

### 4.2 手動檢查清單

| 項目 | 怎麼檢查 | 合格標準 |
|---|---|---|
| 鍵盤操作 | 只用 Tab／Shift+Tab／空白鍵／方向鍵完成「登入 → 作答 → 看結果」 | 能完成，焦點順序合理 |
| 焦點可見 | Tab 時看得到目前焦點在哪 | 每個可操作元素都有可見焦點 |
| 200% 縮放 | 瀏覽器放大到 200% | 不需要左右捲動、文字不重疊不被切掉 |
| 觸控尺寸 | 量按鈕、選項、連結的大小 | 至少 44×44 CSS px |
| 字級 | 內文、說明文字 | 用 rem，內文 ≥ 1rem |
| 頁面語言與標題 | `<html lang>`、`<title>` | 有設定且正確 |
