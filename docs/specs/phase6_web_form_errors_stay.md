## 1. 目標

HHIE-S／HHIA-S 用網頁表單（React 沒接手時的備用）送出、驗證沒過時，使用者要看得到哪幾題沒答、已經選的答案也還在，補完就能送出。
不要被 React 接手、從頭重答。

## 2. 範圍

### 要做
- 驗證沒過重新顯示的頁面不載入 React、不藏表單，留在網頁表單（錯誤和已選答案都在）
- roadmap「無障礙重新量測」補一條：驗證沒過時焦點移到錯誤摘要

### 不做
- React 作答頁本身的流程（一題一頁、草稿、送出）
- IOI-HA（不載入 React，本來就沒有這個問題）
- 錯誤訊息的文字、紅字標示的樣式（沿用現有）
- 焦點移到錯誤摘要（記進 roadmap，跟無障礙重新量測一起看）

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。

  - 上一項（F-10）的收據編號：驗證沒過重新顯示時沿用同一個編號，這次不能弄壞

## 4. 行為描述

### 4.1 作答頁（HHIE-S／HHIA-S）

| 情況 | 現在 | 改成 |
|---|---|---|
| 打開作答頁（GET） | React 接手，一題一頁；5 秒沒接手就用網頁表單 | 不變 |
| 網頁表單送出、驗證沒過 | 重新顯示後，React 又接手、從頭開始 | 這一頁不載入 React、不顯示「題目載入中…」，直接顯示網頁表單、錯誤和已選答案 |
| 網頁表單送出、成功 | 轉到結果頁 | 不變 |
