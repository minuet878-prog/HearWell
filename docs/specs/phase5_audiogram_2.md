## 1. 目標

描錯的聽力圖可以直接改，不必刪掉重描；有兩張以上聽力圖的人，可以看出聽力前後的變化。

## 2. 範圍

### 要做
- 修改已存的聽力圖（點和檢查日期）
- 比較兩張聽力圖：疊在同一張圖上，附逐頻率的對照表

### 不做
- 修改紀錄（誰在什麼時候改了什麼）、復原到修改前
- 自動判斷「惡化／進步」，或依門檻標色等任何臨床意義的變化標籤（待決 6）
- 四頻平均的趨勢折線圖（待決 3 沒選）
- 三張以上同時比較
- 聽力圖型態判斷、OCR、列印、匯出、分享、LLM 文字（同第 1 批）
- 跟問卷結果交叉比對
- 改動第 1 批的輸入方式、判讀規則
- 改動既有問卷、作答、歷史紀錄的行為

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本任務特別注意：
  - 修改、比較都限定本人；別人的回 404（頁面與 API 都要有測試）。
  - 比較頁的判讀數字一律由後端算，走跟檢視頁同一條判讀路徑，前端不重算、不自己相減。
  - 0 dB、-10 dB 是合法值；比較時「某頻率只有一張有值」不能當成 0。
  - 字級用 `rem`；320px 可以操作；比較的內容要有表格版給螢幕閱讀器。

## 4. 行為描述

### 4.1 修改聽力圖

| 項目 | 內容 |
|---|---|
| 入口 | 檢視頁多一顆「修改」按鈕 |
| 誰可以使用 | 只有本人；別人的回 404；未登入導向登入頁（帶 next） |
| 畫面 | 跟新增頁一樣的編輯器，打開時已經帶入原本的點（含遮蔽、無反應）和檢查日期 |
| 存檔條件 | 跟新增一樣：日期必填、不能是未來；至少一個點 |
| 存檔後 | 整張換成新的內容（不留舊版），回到檢視頁，判讀依新內容即時重算 |
| 清除按鈕 | 打開後還沒標過新的點時不能按（跟空白新增頁一樣）；標過之後照舊清除最後標的那一點 |
| 沒存就離開 | 不提醒（跟新增頁一樣） |

### 4.2 比較兩張聽力圖

| 項目 | 內容 |
|---|---|
| 入口 | 清單頁上方「比較聽力圖」按鈕；少於兩張時不能按，旁邊寫「要有兩張聽力圖才能比較」 |
| 誰可以使用 | 只有本人；未登入導向登入頁（帶 next）；選到別人的聽力圖回 404 |
| 選哪兩張 | 兩個下拉選單，各列出自己全部的聽力圖（檢查日期）；預設最新一張與前一張。兩張的新舊由檢查日期決定（同一天則後存的算新），跟選在哪個選單無關。兩個選單選同一張時，顯示「請選兩張不同的聽力圖」，不畫圖 |
| 圖 | 一次看一耳，圖上方「右耳／左耳」切換鈕（預設右耳）。一張圖畫兩次檢查：新的用耳色（右紅、左藍）實線，舊的用同耳色的淡色虛線；氣導、骨導都畫，遮蔽、無反應符號照第 1 批；圖例寫明哪條是哪個日期（2026-10-16 看比較頁選 A3） |
| 對照表 | 每耳一張表（跟著切換鈕顯示目前那一耳），每個頻率一列：舊 dB、新 dB、差值（新 − 舊）。氣導、骨導分開。最上面一列是四頻平均（舊、新、差值）與程度（舊、新） |
| 差值 | 只顯示數字，不標色、不寫「變差／進步」；寫成「+15」「-10」「0」，表頭註明「差值＝新 − 舊，正數＝要更大聲才聽得到」。任一邊沒有值 → 差值寫「—」；任一邊是無反應 → 差值寫「無法比較」（無反應只代表「至少這麼差」） |
| 四頻平均差值 | 兩張都能算出四頻平均才顯示差值；任一張資料不足 → 「—」；任一張四頻含無反應 → 照算，但加註「含無反應的頻率，實際差距可能不同」 |
| 需要計算的資料 | 四頻平均、程度、差值全部由後端計算，走跟檢視頁同一條判讀路徑 |
| 說明文字 | 「兩次檢查的條件（機器、地點、耳機）不同，數字也會有幾 dB 的差異。這只是數字的對照，不能取代聽力師的判讀。」 |
| 無障礙 | 對照表就是圖的文字版，不收合 |
