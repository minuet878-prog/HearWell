## 1. 目標

解決第 1 批記下的三個動線問題：首頁一打開就知道從哪裡開始、作答時知道進度、看完結果知道下一步可以做什麼。文案只寫網站真的有的功能。

## 2. 範圍

### 要做
- **首頁**（比較頁版本 B）：標題＋一句說明＋「開始篩檢」按鈕放最上面；三個步驟；「7–10 年」縮成下方小卡片；頁尾說明與免責聲明。首頁不寫量表名稱。
- **選問卷頁**：每份問卷顯示名稱、適合對象、題數、大約時間。「開始篩檢」仍然先到這一頁（為之後加 IOI-HA 預留）。
- **作答頁**：題目上方顯示「共 N 題，大約 3 分鐘」；每題標題前顯示「第 n 題／共 N 題」。
- **結果頁**（比較頁版本 A）：依序是作答日期 → 分級色塊（分級＋總分）→ 建議 → 下一步按鈕（「看我的紀錄與趨勢」「回首頁」）→ 分數細節（分項、助聽器、分項說明）→ 收合的作答明細。
- 結果頁不顯示帳號名稱；冒號一律全形。
- 我的紀錄頁：「總分:」改成全形「總分：」，其他排版不動。

### 不做
- 首頁依登入狀態或歷史紀錄顯示不同內容（例如上次結果）。未登入時的「請先註冊／登入」提示維持原樣。
- 「開始篩檢」直接進作答頁（跳過選問卷頁）。
- 作答頁「已回答 n 題」的即時計數、分頁作答（一頁一題）。
- 結果頁依分級顯示不同的下一步、外部連結（找聽力師、補助資訊）、列印或匯出。
- 修改建議文字、分級文字、分項說明文字、作答頁原有的說明段落。
- 改動計分、分級、資料模型、API、趨勢圖。
- 新增任何 JS。
- IOI-HA（另有規格 `feat/ioi-ha`）、HHIA-S。
- 導覽列、頁首、登入／註冊頁。
- 我的紀錄頁除了冒號以外的任何修改。

## 3. 必須遵守的規則
