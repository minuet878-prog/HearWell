## 1. 目標

首頁的順序和文字在第 3 輪整理好了，但整頁還是一段一段的字。這一份增加「層次和視覺節奏」，不增加資訊量：
一張插圖讓人一眼知道網站在講聽力、三個步驟做成有圖示的卡片、聽力師背書做成醒目的信任區塊、一張結果的示意圖讓人在開始前就知道會得到什麼。

## 2. 範圍

### 要做
- 首頁上方的插圖（來源見 Q1）。
- 三個步驟改成卡片，各配一個圖示（見 Q3）。
- 信任區塊（內容見 Q2）。
- 結果預覽（見 Q4）。
- 區塊之間用很淡的品牌色底交替，分出段落（見 Q5）。

### 不做

- 動畫、輪播、影片。
- 外部圖片網站、圖示套件、字型。
- 改其他頁面。
- 4d 的內容。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 長輩用：插圖和卡片「大而簡單」，沒有動畫，字不變小。
  - 插圖、圖示是裝飾：`aria-hidden` 或空的替代文字；資訊靠文字。
  - 結果預覽用假資料，必須清楚標示「示意」，不能讓人以為是自己的結果（規則 3：不放真實資料）。
  - 信任區塊寫的事要是真的；具名與否、證照資訊由本人決定（牽涉本人隱私與職業規範）。
  - 首頁未登入也看得到：不能放任何使用者資料。
  - 字級與大小用 `rem`；320px 不能左右捲動；200% 字級不破版。

## 4. 行為描述

### 4.1 首頁（未登入、已登入都一樣，只有「第一次使用請先註冊……」照舊只給未登入）
| 順序 | 內容 |
|---|---|
| 1 | 淡藍底區塊：插圖「耳朵與聲波」（SVG、`aria-hidden`、置中、最寬 20rem）→ 標題 → 副標 → 「開始篩檢」→（未登入）註冊提示 |
| 2 | 三張步驟卡片：每張有號碼 1／2／3、圖示（夾板、勾選框、長條圖，`aria-hidden`）、原本的步驟文字；寬螢幕三張橫排，放不下時自動換成直排 |
| 3 | 小標「結果長這樣」＋結果示意圖（見 4.2） |
| 4 | 「很多人在察覺聽力問題好幾年後，才尋求協助。及早了解，才能及早處理。」 |
| 5 | 淡藍底信任區塊：標題「由聽力師開發」，兩點「由在台灣執業的聽力師設計與審定內容」「使用國際通用的標準化量表：HHIE-S、IOI-HA」 |
| 拿掉 | 原本的「本網站由執業聽力師開發，使用經過驗證的標準化量表。」（換成信任區塊） |

### 4.2 結果示意圖
| 項目 | 內容 |
|---|---|
| 樣子 | 一張縮小的結果卡：分級色塊（黃褐）＋分級文字、「HHIE-S 總分 18 分（滿分 40）」、建議文字開頭約 40 字加「……」 |
| 文字來源 | 分級文字、滿分、建議文字都取自網站實際的分級與建議（假分數 18 分代進去），不另寫一份 |
| 標示 | 左上角「示意圖」；下方說明「實際結果依您的回答而定。」 |
| 無障礙 | 螢幕閱讀器念得到「示意圖」與說明，知道這不是自己的結果 |
| 不能 | 放任何使用者自己的資料 |
