## 1. 目標

聽力圖列表的每張卡片現在只有日期和左右耳程度的文字。聽力圖本身就是一張圖，放一張小縮圖，使用者不用點進去就看得出大概的形狀（例如高頻下降），也比較容易找到要看的那一張。

## 2. 範圍

### 要做
- 聽力圖列表每張卡片加一張縮圖（內容、大小、位置見 Q1–Q3）。
- 縮圖的顏色沿用單張聽力圖：右耳紅 `#c0392b`、左耳深藍 `#1f4e8c`（見 Q4）。

### 不做
- 改單張聽力圖頁、比較頁、輸入頁、聽力報告上的大圖。
- 縮圖可以點、放大、互動（整張卡片照舊是一個連結）。
- 改判讀、程度、顏色標籤（第 1 輪的標籤照舊）。
- 新增圖表套件或前端程式：縮圖由伺服器直接畫成 SVG，不靠 JavaScript。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 只畫 `request.user` 自己的聽力圖（列表本來就限定本人，規則 8）。
  - 縮圖是裝飾：`aria-hidden`，資訊靠卡片上的日期與程度文字；顏色不是唯一的資訊。
  - 聽力圖的慣例：縱軸往下是聽力越差（0 在上、120 在下），頻率由左到右變高。
  - 縮圖用到的數值照資料庫存的點，不另外推算；無反應（NR）的點畫在它存的值上。
  - 列表的資料庫查詢次數不能因為縮圖變多（沿用既有的 `prefetch_related("points")`）。
  - 字級、大小用 `rem`。

## 4. 行為描述

### 4.1 縮圖
| 項目 | 內容 |
|---|---|
| 位置與大小 | 聽力圖列表每張卡片左側，6rem 寬 × 4.5rem 高 |
| 座標 | 橫軸 250–8000 Hz（對數，跟大圖一樣）；縱軸 −10 到 120 dB HL，往下是聽力越差；不畫刻度數字 |
| 底 | 白底、淡灰格線（每 20 dB 一條）、正常範圍（−10 到 25 dB）淺綠底 |
| 畫的點 | 只畫氣導：右耳紅 `#c0392b` 線＋小圓圈、左耳深藍 `#1f4e8c` 線＋小叉 |
| 連線規則 | 跟大圖一樣：照頻率順序連，中間缺的頻率跳過；「無反應」的點畫在它存的值上，但不連線（線在那裡斷開） |
| 沒有氣導資料 | 只顯示空的格子 |
| 無障礙 | 整張縮圖 `aria-hidden`；卡片念的仍是日期與左右耳程度 |

### 4.2 卡片文字
| 項目 | 內容 |
|---|---|
| 排法 | 日期一行；「右耳：〔標籤〕」一行；「左耳：〔標籤〕」一行（所有寬度都這樣） |
