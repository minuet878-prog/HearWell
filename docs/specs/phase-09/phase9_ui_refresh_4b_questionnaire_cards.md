## 1. 目標

「請選擇問卷」頁現在只有兩張文字卡片，使用者要自己讀說明判斷該做哪一份。這一份加上一句正確的選擇引導、
每張卡片一個代表圖示，題數和時間做成容易掃讀的小標籤，讓第一次來的人不用想就知道從哪裡開始。

## 2. 範圍

### 要做
- 頁面上方一段選擇引導（文字見 Q1）。
- 每張問卷卡片：左側一個代表圖示（見 Q2）；題數、時間做成小標籤（見 Q3）。
- 卡片的順序固定（見 Q4）。

### 不做
- 依使用者年齡自動推薦或擋問卷（`docs/decisions/product-ui.md` 的「問卷適用條件」仍待定）。
- 新增問卷（HHIA-S 等）、改題目、改計分。
- 4a、4c、4d 的內容。
- 改卡片的點擊行為（第 1 輪定的整張可點＋「›」不變）。
- 用外部圖示套件或圖片檔（圖示用 inline SVG，跟導覽列同一種畫法）。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 選擇引導是臨床內容，由本人審定文字。
  - 圖示是裝飾：`aria-hidden`，資訊靠文字；卡片念出的名稱照舊是問卷名稱與說明。
  - 標籤文字要能被螢幕閱讀器念到（不能只是圖示）；字級用 `rem`。
  - 沒有在 `QUESTIONNAIRE_INFO` 的問卷（例如以後新增的）照樣要能顯示：沒有時間就不顯示時間標籤、沒有圖示就用通用圖示。

## 4. 行為描述

### 4.1 選擇問卷頁
| 項目 | 內容 |
|---|---|
| 引導 | 標題下、卡片上方一個淺藍底的說明框：「第一次使用，請從 HHIE-S 開始；已經戴助聽器的人，可以再做 IOI-HA。」 |
| 卡片順序 | HHIE-S 第一、IOI-HA 第二；其他問卷照建立先後排在後面；不管資料庫怎麼排都一樣 |
| 卡片內容 | 左側圓形淺藍底的線條圖示；標題（問卷名稱＋副標）；適合對象一句（有的話）；標籤「N 題」「約 M 分鐘」（沒有時間資料就只有題數） |
| 圖示 | HHIE-S：耳朵＋聲波；IOI-HA：耳掛式助聽器；其他：夾板。裝飾用，螢幕閱讀器不念 |
| 不變 | 整張卡片是一個連結、右側「›」、點下去到作答頁 |
