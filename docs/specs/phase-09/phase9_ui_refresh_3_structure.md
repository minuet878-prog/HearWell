## 1. 目標

把東西放回它該在的地方：帳號管理（下載資料、刪除帳號）跟「紀錄」無關、刪除帳號放在紀錄旁邊容易誤觸，搬到自己的頁面；
「我的紀錄」上方切換問卷的分頁長得跟主導覽一樣大，改小；首頁照使用者腦中的問題重新排順序，刪掉重複的話，數據補上來源。

## 2. 範圍

### 要做
- 新增「帳號設定」頁（入口與內容見 Q1、Q2），「我的紀錄」底部的「下載我的資料」「刪除帳號」搬過去。
- 隱私權說明頁裡「到『我的紀錄』頁按……」的說明改成新位置；刪除帳號頁的「回我的紀錄」改成回帳號設定。
- 「我的紀錄」切換問卷的分頁改成分段切換器（見 Q3）。
- 首頁：刪掉重複的說明（見 Q4）、「可達 10 年」處理（見 Q5）、區塊重新排序（見 Q6）。
- （待決）趨勢圖最右欄的分數壓到底色的分級文字（見 Q7）。

### 不做
- 修改帳號資料（改名稱、改 email、改密碼、改出生年）：帳號設定頁這輪只「看」不「改」。
- 改刪除帳號、下載資料本身的流程與內容（只換入口位置）。
- 第 4 輪的東西：首頁插圖、步驟卡片＋圖示、信任元素區塊、結果預覽、聽力圖縮圖、問卷卡片圖示與標籤、IOI-HA 逐題解讀。
- 主導覽列的項目（首頁／開始篩檢／我的紀錄／聽力圖）不增不減（除非 Q1 選 B）。
- 改計分、分級、API。

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本 phase 特別注意：
  - 帳號設定頁只顯示 `request.user` 自己的資料（規則 8）；未登入導到登入頁。
  - 帳號設定頁要不要過同意閘門：下載資料、刪除帳號在 Phase 7 定為「未同意也能用」（行使權利），帳號設定頁是它們的入口，所以也要放行。
  - 隱私權說明頁只改「在哪裡按」的文字，算小修正（不改 `CONSENT_VERSION`）。
  - 首頁上的數據與出處是臨床內容，由本人提供或審定。
  - 字級用 `rem`；分段切換器要鍵盤可用、`aria-current` 照舊。

## 4. 行為描述

### 4.1 帳號設定頁
| 項目 | 內容 |
|---|---|
| 網址與方法 | 新的一頁，GET |
| 誰可以使用 | 未登入：導到登入頁　　已登入但未同意：可以進來（同下載資料、刪除帳號）　　能否看他人資料：不能（只顯示 `request.user`） |
| 由上到下 | ① 帳號資料（只看）：使用者名稱、電子郵件、出生年；沒填寫「未填」 ② 「下載我的資料」外框按鈕＋一句說明「把您在 HearWell 的所有資料下載成一個檔案保存。」（審查後改：下載的是給程式讀的檔案，不是給醫師看的報告） ③ 「隱私權說明」連結＋「您在 YYYY/MM/DD 同意了目前的版本」；還沒同意時寫「您還沒有同意目前的隱私權說明」＋連到同意頁 ④ 最下方、和上面明顯隔開：「刪除帳號」紅色文字連結（連到現有的刪除頁，刪除頁本來就要再輸入密碼） |
| 不做 | 修改任何帳號資料、登出按鈕（頁首已有） |

### 4.2 入口
| 項目 | 內容 |
|---|---|
| 頁首 | 已登入時「目前登入：名稱」整段是連到帳號設定的連結；螢幕閱讀器念「目前登入：名稱，帳號設定」（念出的名稱包含畫面上的字） |
| 頁尾 | 已登入時多一個「帳號設定」連結；未登入不顯示 |
| 「我的紀錄」 | 底部的「下載我的資料」「刪除帳號」拿掉 |
| 刪除帳號頁 | 「回我的紀錄」「取消」改成回帳號設定 |
| 隱私權說明頁 | 「登入後到『我的紀錄』頁按……」改成「登入後到『帳號設定』頁按……」（下載、刪除兩處）；算小修正，不改同意版本 |

### 4.3 切換問卷（「我的紀錄」上方）
| 項目 | 內容 |
|---|---|
| 樣子 | 分開的小膠囊：選中的深藍實心白字、其他白底深藍外框；放不下時自動換行；寬度依文字，不撐滿 |
| 不變 | 每顆仍是連到各自網址的連結、`aria-current="page"`、只有一份問卷時不顯示 |
| 觸控 | 每顆至少 2.75rem 高 |

### 4.4 首頁
| 順序 | 內容 |
|---|---|
| 1 | 標題「了解聽力對您生活的影響」；副標改成「聽力變化很慢，自己常常沒發現。花 3 分鐘看看聽力對生活的影響。」 |
| 2 | 「開始篩檢」按鈕；未登入時下面「第一次使用請先註冊，已有帳號請直接登入。」 |
| 3 | 三個步驟（文字不變） |
| 4 | 一張卡片：「很多人在察覺聽力問題好幾年後，才尋求協助。及早了解，才能及早處理。」＋「本網站由執業聽力師開發，使用經過驗證的標準化量表。」 |
| 拿掉 | 大字「可達 10 年」；首頁的「結果僅供參考，不能取代聽力檢查與醫師診斷」（頁尾已有） |

### 4.5 趨勢圖的分級文字
