## 1. 目標

這一輪修的是「會讓人看錯」的地方，不是好不好看：HHIE-S 趨勢圖把有戴、沒戴助聽器連成同一條線，看起來像聽力「改善」了；
同一天兩筆的日期分不出來；IOI-HA 的數字落在格線之間、也沒說分數越高越好。做完之後，使用者看圖得到的結論和資料一致。

## 2. 範圍

### 要做
- HHIE-S 趨勢圖：有戴、沒戴分開畫（方式見 Q1）。
- 趨勢圖上方摘要框的「比上一次增加／減少 N 分」改成不跨條件比較（見 Q2）。
- 同一天有多筆時，橫軸分得出是哪一筆（見 Q3）。
- 分級底色的邊界不要剛好壓在分數上（見 Q4）。
- IOI-HA 圖：刻度數字、格線、點對齊（見 Q5）；加上分數方向的說明（見 Q6）。

### 不做
- IOI-HA 逐題文字解讀（第 4 輪）；IOI-HA 標題區和下方卡片資訊重複（第 3 輪結構調整再看）。
- 配戴前後比較框（「沒戴 N 分、有戴 M 分」）：已經是同條件比較，不改。
- 改計分、分級、門檻、常模；改 API 回傳的分數或分級（規則 10：前端不重算分數）。
- 換圖表套件、改聽力圖（聽力圖有自己的規格）、改聽力報告的列印版。
- HHIA-S 的趨勢圖（目前只有 HHIE-S 有圖，不新增）。

## 4. 行為描述

### 4.1 HHIE-S 趨勢圖：有戴、沒戴分開
| 項目 | 內容 |
|---|---|
| 線 | 沒戴助聽器：實線＋實心圓；有戴助聽器：虛線＋空心方塊。只連同一種狀態的點，兩種狀態的點之間沒有線 |
| 未記錄 | 很早期、還沒問助聽器的紀錄：空心三角形，只畫點、不連線 |
| 橫軸位置 | 以「天」為單位（2026-10-17 本人驗收後改）：同一天的紀錄排在同一條直線上；最多顯示最近五天 |
| 同一天、同一種狀態有兩筆以上 | 只畫當天最後一筆；較早的不在圖上，下方紀錄卡片照樣列出（卡片有時間） |
| 圖例 | 只列出圖上有的狀態，線段樣式＋點的形狀＋文字（「沒戴助聽器」「有戴助聽器」「未記錄」） |
| 說明文字 | 圖的標題下加一句：「分數越低，聽力對生活的影響越小。」 |
| 最近一次 | 照舊放大：最後一天、最近一次那種狀態的點 |

### 4.2 摘要框
| 情況 | 顯示 |
|---|---|
| 第一行 | 「最近一次（日期，有戴助聽器）」；狀態文字：有戴助聽器／沒戴助聽器／助聽器未記錄 |
| 同一種狀態有上一筆 | 「比上一次有戴助聽器（2026/10/01）減少 4 分。」／「增加 N 分。」／「和上一次有戴助聽器（日期）相同。」（沒戴同理） |
| 同一種狀態沒有上一筆，但有別的紀錄 | 「這是第一筆有戴助聽器的紀錄。」（沒戴同理） |
| 最近一次是「未記錄」 | 「這筆沒有記錄助聽器，不和其他紀錄比較。」 |
| 全部只有一筆 | 照舊：「再做一次篩檢，就能看到分數的變化。」 |
| 範圍 | 用全部拿到的紀錄（最近 20 筆）找同一種狀態的上一次，不限圖上的五天 |
| 分數、分級文字 | 照 API 給的，不重算 |

### 4.3 同一天多筆
| 項目 | 內容 |
|---|---|
| 橫軸 | 只寫日期（2026-10-17 本人驗收後改：不加時間）；兩個日期之間至少空 1.5rem（約 27px），放不下時自動少顯示幾個，頭尾一定留著 |
| 提示框 | 標題是日期；那天有兩筆以上時，每一筆後面加時間，例如「20 分，輕度到中度影響，助聽器：沒戴（14:30）」 |
| 下方紀錄卡片 | 同一份問卷同一天有兩筆以上時，那幾張卡片的日期後面加時間；其他照舊 |

### 4.4 分級底色的邊界
| 項目 | 內容 |
|---|---|
| 位置 | 畫在相鄰兩級中間：前一級的最高分和下一級的最低分的中點。HHIE-S：0–9 綠、9–25 黃褐、25–40 紅 |
| 不改 | 分級規則、門檻、分級文字 |

### 4.5 IOI-HA 圖
| 項目 | 內容 |
|---|---|
| 格線 | 每一個分數一條線，畫在那一列的正中間；左側的分數數字、點、上一次的菱形都落在線上 |
| 說明 | 灰色常模說明下面加：「7 題都是分數越高，代表助聽器的效益越好。」沒有常模（未分組）時也照樣顯示這句 |
| 不改 | 常模範圍、上一次的菱形、圖例 |
