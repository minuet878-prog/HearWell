## 1. 目標

健康工具的文字可信度就是產品可信度。使用者看到的每一段文字都是完整、正確的繁體中文，作答頁的題目不會被截斷。

## 2. 範圍

### 要做
- 作答頁題目改成「題號. 全文」（例如「6. 聽力問題讓你較少參加各項活動（例如宗教活動、社團活動等）嗎？」），任何長度都不截斷。
- 作答頁說明修錯字（見 4.2）。
- 建議文字修錯字、統一用「您」（見 4.3）。
- 英文殘留與用詞：登入頁標題「Welcome」→「登入」；右上角「Signed in as X」→「目前登入：X」、「Not signed in」→「尚未登入」；歷史頁按鈕「連結」→「查看結果」。
- 問卷列表拿掉孤兒 `</li>`。
- 歷史頁沒有紀錄時，「你還沒有做過篩檢紀錄」→「您還沒有做過篩檢紀錄」（審查時發現，本人同意加入）。

### 不做
- admin 用的顯示方式（`Question` 的 30 字簡寫、`Submission` 的「submit at」）：只有管理者看得到。
- 註冊頁輸入框的英文 placeholder（浮動標籤樣式下不會顯示）。
- 題目文字本身（量表原文，而且作答過的題目已鎖定）。
- 建議文字的臨床內容改寫。
- 對比度、`text-muted`（屬於無障礙基準線）。
- 分數旁的半形冒號等其他標點統一。

### 4.3 建議文字

**normal**：不變（已經全部用「您」，沒有錯字）。

**mild_to_moderate**
- 改前：聽力的問題已經慢慢開始影響到您的社交活動以及情緒**ex.**與家人之間常常因為聽不清楚或是電視聲音等而產生爭吵、在多人且吵雜的社交環境當中會因為聽不清楚而導致社交上的窘迫及退縮，許多聽力衰退帶來的問題是微妙且和緩的，但經過此次篩檢能夠讓**你**體認到聽力對自身生活的影響，建議前往醫院耳鼻喉科進行聽力相關檢查及詢問相關專業意見。
- 改後：聽力的問題已經慢慢開始影響到您的社交活動以及情緒，**例如**與家人之間常常因為聽不清楚或是電視聲音等而產生爭吵、在多人且吵雜的社交環境當中會因為聽不清楚而導致社交上的窘迫及退縮，許多聽力衰退帶來的問題是微妙且和緩的，但經過此次篩檢能夠讓**您**體認到聽力對自身生活的影響，建議前往醫院耳鼻喉科進行聽力相關檢查及詢問相關專業意見。

**severe**
- 改前：聽力問題已經嚴重影響到**你**的生活了，許多人常常會忽視這一塊，聽不到這件事情往往已經十分嚴重了才會發現，若您尚未採取任何行動建議立即前往醫院耳鼻喉科尋求專業建議，並且考慮配戴助聽器。聽力喪失影響的並不只是聽不聽**的**到，無形中**對**也會增加社交活動的壓力**(ex.**因為聽不清楚常會在聊天的過程中退縮、裝作聽得懂等**)**這些壓力以及情緒的低落會增加長者的認知負擔。
- 改後：聽力問題已經嚴重影響到**您**的生活了，許多人常常會忽視這一塊，聽不到這件事情往往已經十分嚴重了才會發現，若您尚未採取任何行動建議立即前往醫院耳鼻喉科尋求專業建議，並且考慮配戴助聽器。聽力喪失影響的並不只是聽不聽**得**到，無形中也會增加社交活動的壓力**（例如**因為聽不清楚常會在聊天的過程中退縮、裝作聽得懂等**），**這些壓力以及情緒的低落會增加長者的認知負擔。

**unknown**：不變。
