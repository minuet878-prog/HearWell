## 1. 目標

病人拿著醫院給的聽力檢查報告，在 HearWell 上用點選的方式把聽力圖「描」進來、存起來，
並看到依固定規則算出的每耳聽損程度與類型（僅供參考）。之後可以回頭看自己歷次的聽力圖。

## 2. 範圍

> 分兩批（待決 1）；第 1 批完成後才寫第 2 批的劇本。

### 要做（第 1 批）
- 新增一張聽力圖：在圖上按住拖曳標記，左右耳 × 氣導／骨導四種符號，含無反應（NR）與遮蔽
- 填檢查日期後存檔
- 單張聽力圖的檢視頁：圖＋每耳判讀（四頻平均、程度、類型）＋「僅供參考」說明
- 我的聽力圖清單（依檢查日期新到舊）；導覽列最後多一項「聽力圖」，在聽力圖的各頁標成目前所在頁
- 刪除自己的聽力圖
- 判讀規則沿用 `audiogram_tool` v1（見 4.3）

### 第 2 批（先列，不在這次）
- 修改已存的聽力圖
- 多張聽力圖比較或趨勢

### 不做
- 聽力圖型態判斷（平坦、陡降、cookie-bite）
- 照片辨識、OCR
- 跟問卷結果交叉比對、在問卷結果頁顯示聽力圖
- 語音、語言測驗（SRT、WRS）、鼓室圖
- 列印、匯出
- 分享給家屬或聽力師
- 用 LLM 產生解讀文字
- 改動既有問卷、作答、歷史紀錄的行為（包括「我的紀錄」的分頁籤）
- 沒有 JavaScript 時的備用表單（只顯示「需要開啟 JavaScript」）
- 檢查地點、備註等自由文字欄位

## 3. 必須遵守的規則

- 一律遵守 CLAUDE.md「不可違反的規則」。
- 本任務特別注意：
  - 所有讀寫都限定在 `request.user`；別人的聽力圖一律回 404（頁面與 API 都要有測試）。
  - 判讀只用規則式程式碼；判讀結果由後端算好，前端不重算。
  - 0 dB、-10 dB 都是合法值，不能當「沒資料」。
  - 介面字級用 `rem`；手機 320px 寬可以完成輸入；只能用滑鼠／手指點圖的話，鍵盤和螢幕閱讀器使用者就用不了，所以要有替代輸入方式：圖下方可收合的數值表，跟圖雙向同步。
  - 測試只用假資料。

## 4. 行為描述

### 4.1 新增聽力圖

| 項目 | 內容 |
|---|---|
| 網址與方法 | 待定（實作計畫時提） |
| 誰可以使用 | 未登入：導向登入頁（帶 next）　已登入：可以　能否存取他人資料：不能 |
| 畫面 | 聽力圖座標：橫軸頻率（氣導 250、500、1000、2000、3000、4000、6000、8000 Hz；骨導 500、1000、2000、4000 Hz），縱軸 -10 到 120 dB HL、每 5 dB 一格、由上往下增加；骨導只到 80 dB；符號切換按鈕：右耳氣導（紅 O）、左耳氣導（藍 X）、右耳骨導（紅 <）、左耳骨導（藍 >）；圖下方的清除按鈕；檢查日期欄位；存檔按鈕 |
| 輸入方式 | 左右耳畫在同一張圖。先選符號，再在圖上**按住、上下拖曳、放開**：<br>・按下時決定頻率（目前符號可用的頻率裡，離手指最近的那個），拖曳過程頻率不變，只改 dB<br>・dB 跟著手指，對齊 5 dB；手指上方顯示放大的「頻率＋dB」<br>・放開才算數；同一耳、同一導程、同一頻率只會有一個點，標在已有點的頻率就是移動 |
| 無反應（NR） | 氣導：拖過圖的下緣（120 dB 以下）＝無反應，標在 120 dB 並加向下箭頭。骨導：拖過 80 dB＝無反應，標在 80 dB 加箭頭。放大鏡顯示「無反應」。往上拖過 -10 停在 -10 |
| 刪除一個點 | 在已有的點上再點一下（放開時的頻率和 dB 跟原本的點一樣）＝刪除。圖下方固定顯示提示「再點一下同一個點可以刪除」。圖下方的清除按鈕寫明是哪一點（例如「清除 右耳氣導 1000 Hz」），清除最後標的那一點；沒有可清除的點時不能按 |
| 遮蔽 | 符號鈕下方一個整排寬的開關按鈕（預設關，寫「遮蔽：關」；打開時橘色實心，寫「遮蔽：開（△ □ [ ]）」；2026-10-16 看過比較頁選 A＋B 圖框）。打開時，圖外框變成橘色虛線，放大鏡多寫「遮蔽」，四個符號鈕上的符號變成遮蔽符號（ASHA：右耳氣導紅 △、左耳氣導藍 □、右耳骨導紅 [、左耳骨導藍 ]），接下來標的點都是遮蔽，直到關掉。遮蔽只是點的標記：同一耳、同一導程、同一頻率仍然只有一個點。遮蔽可以和無反應同時存在 |
| 再點一下的判定 | 放開時的 dB、無反應、遮蔽三者都跟原本的點一樣 → 刪除；只有遮蔽不同 → 把原本的點改成目前的遮蔽狀態（不刪除） |
| 連線 | 同一耳的氣導點依頻率連線（遮蔽點照樣連）；無反應的點不連線 |
| 存檔條件 | 檢查日期必填、不能是未來；至少要有一個點 |
| 需要計算的資料 | 無（存檔後才判讀） |

### 4.2 單張聽力圖檢視

| 項目 | 內容 |
|---|---|
| 誰可以使用 | 只有本人；別人的回 404 |
| 顯示 | 檢查日期、聽力圖（唯讀）、左右耳各一張判讀卡：四頻平均（dB HL）、程度、類型 |
| **不能**顯示 | 「診斷」字樣；任何 LLM 產生的文字 |
| 需要計算的資料 | 由後端計算，每次即時算、不存欄位 |
| 遮蔽 | 圖上用遮蔽符號；數值表在值後面加「（遮蔽）」 |
| 無反應 | 某耳用來算平均的頻率含無反應時，該耳判讀卡註明「含無反應的頻率，實際聽力可能更差」 |
| 空資料時的行為 | 某耳氣導四頻缺任何一個 → 該耳顯示「資料不足，無法判讀」；骨導不完整 → 程度照常顯示，類型顯示「需要骨導資料才能判斷」 |
| 說明文字 | 「這是依固定規則算出的參考結果，不能取代聽力師的判讀。」 |

### 4.3 判讀規則（沿用 `audiogram_tool` v1，本人 2026-10-08 定）

- 四頻平均：500、1000、2000、4000 Hz 的平均，不先四捨五入就拿去比門檻
- 程度（看氣導平均）：≤25 正常、≤40 輕度、≤55 中度、≤70 中重度、≤90 重度、>90 極重度
- 類型，依序判斷（氣骨導差＝氣導平均 − 骨導平均）：
  1. 氣導平均 ≤25 → 正常（不需要骨導）
  2. 氣骨導差 <15 → 感音神經性
  3. 氣骨導差 ≥15 且骨導平均 ≤25 → 傳導性
  4. 氣骨導差 ≥15 且骨導平均 >25 → 混合性
- 遮蔽（本人 2026-10-16 定）：遮蔽值跟未遮蔽值一樣算，判讀只看數值
- 無反應（本人 2026-10-16 定）：直接用標的值算平均（氣導 120、骨導 80），不另外加減；骨導平均只用 500、1000、2000、4000 Hz（骨導沒有 3000）

| 項目 | 內容 |

| 誰可以使用 | 只看得到自己的 |
| 顯示 | 每筆：檢查日期、左右耳程度；點進去是 4.2 |
