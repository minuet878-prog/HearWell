# 0075 「已完成」蓋章和倒數圓環可以動

日期：2026-11-21（本人審定，[照顧旅程展開改版拷問決定](../planning/redesign/journey-redesign-grill-decisions.md) Q19–Q20）

> 補充 [ADR 0028](0028-button-feedback-motion.md) 的例外。

> 已併入 [ADR 0077](0077-play-once-entrance-animations.md)。

> 2026-11-21 本人驗收首頁時改：倒數不再是圓環，改成半圓，跟旁邊「上次結果」的半圓儀表同一款（淺灰底線、藍色粗弧是已經等了多久，「還有 N 天」寫在半圓下面）。首頁「離下次篩檢」和照顧旅程第 6、7 步的倒數卡都換，全站一致。動畫規則不變：弧線畫一次、天數往上跑、減少動態效果時直接顯示。

## 情境

ADR 0028 規定回饋以變色為主，會位移或縮放的只限列出的幾種（藥丸滑動、開關、完成一站畫勾、旅程進場）。本人在照顧旅程設計圖選了兩個會動的東西：已完成的步蓋上朱紅「已完成」章，以及倒數卡的圓環從 0 畫到目前進度。

## 決定

只放行這兩種：只播一次、不到 1 秒、系統開「減少動態效果」時直接顯示結果。印章用朱紅 #b3261e。其他動畫仍照 ADR 0028。

## 理由

蓋章讓長輩一眼知道「這件事做完了」；圓環讓人看出離下次還有多久。都只播一次，不會一直吸走注意力。

## 代價

規則多一條例外；設計圖上其他頁的動畫（首頁小鳥、紀錄圓點）不在這次範圍，要用得另外決定。紅色在網站也代表右耳（ADR 0058），印章要靠形狀和「已完成」三個字分辨。
