# 0082 家人模式對齊 #741、#702 與看診畫面的權限與流程邊界

日期：2026-11-23（本人審定，補充更新 [ADR 0046](0046-family-link-between-own-accounts.md)）

## 情境

ADR 0046 訂於 2026-11-13，之後專案歷經多項改版：待辦打勾移除（ADR 0073）、Apple 聽力測試 PDF 匯入（#702）、頁首改為頭像下拉選單與七步照顧旅程（#741）、確認本人機制（#505）、email 重測提醒（#656）與看診畫面定案（ADR 0081）。在進入規格與實作前，需對齊最新的代記、權限與安全邊界。

## 決定

- **代記與刪改邊界**：移除已廢除的手動待辦；家人可代記聽力圖（含手動標記與從 iPhone 匯入 Apple PDF）及選配路線／首頁問答卡的回答。聽力圖僅允許修改或刪除**自己代記**的那幾張，不能改或刪長輩本人或其他家人記的。
- **不污染閱讀紀錄**：家人在家人模式下點開選配指引章節或查詢醫療院所，不寫入長輩的 `GuideChapterView`（看過紀錄），避免代看衛教文章時悄悄替長輩推進照顧旅程。
- **檢視與設定分工**：家人切到長輩後可打開長輩的「看診畫面」（ADR 0081）與「聽力報告」（含列印）；「保留配戴狀態比較組合」與「email 重測提醒開關」維持限長輩本人操作。
- **切換介面與狀態保存**：切換清單放進右上角頭像下拉選單（有家人連結才顯示），切到長輩時每頁頂端固定橫幅「正在看○○的資料｜切回我」。目前看誰存在伺服器 Session（不放網址參數），登出或任一方解除連結立刻失效並退回本人；所有健康資料頁與對應 API（趨勢圖、聽力圖）皆依此檢查授權，且禁止家人透過 API 送出問卷。
- **邀請安全與同意書把關**：長輩產生邀請連結前須先經過既有的 `confirm_identity`（確認本人），再勾選個別授權同意；同一時間最多 1 條待接受連結（3 天有效、用一次、被接受前可取消；LINE 預覽不帶個資、登入後按按鈕才生效；自點或已連上不消耗連結）。若長輩尚未同意最新版同意書，家人切到長輩時先擋下並提示請長輩本人登入確認（不顯示資料、不代記）。
- **下載我的資料隔離**：長輩下載包含已連上的家人帳號名稱、連上日期與代記標示；家人下載只包含已連上的長輩自訂稱呼與連上日期，絕不包含長輩的任何健康資料。同意書維持不升版，於隱私權說明新增「家人連結」一段（沿用 ADR 0046）。

## 理由

限刪改自己代記的聽力圖可在「幫長輩修錯／重匯」與「防誤刪長輩原圖」間取得平衡；不寫入看過紀錄避免旅程狀態失真；未同意最新版即擋下可守住個資法當事人同意底線；收進頭像選單可守住 320px＋200% 字級的頁首無障礙規範。

## 代價

聽力圖需新增記錄者欄位並在頁面與 API 同步檢查權限；所有健康資料 view 與 API 需改寫為讀取目前授權對象，實作前必須設計清楚共用權限層並在合併前做交叉審查；長輩若忘記登入同意新版，子女陪診當下無法代看。
