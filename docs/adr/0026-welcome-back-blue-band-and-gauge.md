# 0026 首頁歡迎回來：藍色招呼區＋儀表

日期：2026-10-24（本人在三份比較頁選 D 案；只做過沒分級問卷的人，選「藍色招呼＋灰框不畫儀表」）

## 情境

老使用者首頁的「歡迎回來」照 ADR 0022 是平面區塊：標題、日期、分級色框、文字連結、提醒、兩顆整排按鈕上下疊，本人覺得醜、不夠活潑。

## 決定

- 頂端改成一條品牌藍漸層的招呼區：白字「歡迎回來！」、「上次是某年某月某日做的」，右邊放新訪客首頁那位微笑長輩。這裡的標題不加藍條，是全站標題樣式的例外。
- 上次結果的分級色框疊在招呼區下緣。有分級的問卷（HHIE-S、HHIA-S）框裡多一個半圓儀表：門檻分成的幾段弧，指針指在分數的位置。分級和分數照樣寫成文字，儀表只是裝飾。「看這次結果」移進框裡。
- 只做過沒分級問卷（IOI-HA、SSQ12、SADL、THI）的人：招呼區一樣，框是灰色、不畫儀表。
- 提醒前面加月曆圖示，到期時改成淡藍底加旗子。寬螢幕兩顆按鈕並排。
- 動畫照 ADR 0006，進來時播一次，約 2.6 秒停：長輩晃一下、聲波亮兩下，儀表三段依序畫出來，指針從 0 擺到分數停住，壞消息也一樣平穩、不回彈。「減少動態效果」時直接停在最後的樣子。儀表畫出來不算「卡片進場動畫」，因為框本身不動、字一開始就在；指針擺動也不算「數字往上跑」，分數和分級的文字從頭到尾都是最後的值。
- 字放大到小螢幕放不下時，長輩先讓位，不顯示。

## 理由

儀表讓長輩不用讀數字就知道落在哪一段。藍色招呼區跟頁首同色，有品牌感，也把「歡迎」和「結果」分成兩層，不再是一長串。

## 代價

首頁的標題跟其他頁長得不一樣。儀表是新元件，弧和指針角度由程式依門檻算出來；以後門檻改了，儀表會跟著變。儀表的弧用比分級文字亮的綠、黃、紅，淡色底上對比不高，所以一定要搭配文字，不能單獨拿來表示分級。
