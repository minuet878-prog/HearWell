# 0028 篩檢分頁：老使用者看目錄，推薦精靈改問想了解什麼

日期：2026-10-24（本人審定，篩檢分頁改版拷問 Q1–Q15）

## 情境

每次點「篩檢」都從推薦精靈第一題重來。精靈只問年齡和有沒有戴助聽器，這兩件事網站大多已經知道；推薦結果幾乎固定是 HHIE-S／HHIA-S，剛做過也照推。THI、SSQ12、SADL 藏在小連結或摺疊裡。

## 決定

- 老使用者點「篩檢」直接看問卷目錄（六份照原順序、不分組），最上面放推薦問卷，沒有適合的就不放；做過的問卷卡寫上次日期。目錄底下留一行「幫您挑」進精靈。新使用者照舊走精靈。
- 目錄的推薦問卷依序挑：生活影響問卷滿 6 個月 → 再做一次；從沒做過生活影響問卷 → 做一份；有戴著作答的紀錄、有沒戴紀錄、沒做過 IOI-HA → IOI-HA。
- 精靈改問「您最想了解什麼」（單選）：聽不清楚的影響、耳鳴、吵雜環境、助聽器、不確定。不再問有沒有戴助聽器；年齡只在結果是生活影響問卷又看不出年齡時才問。
- 選助聽器：有沒戴的生活影響紀錄就推 IOI-HA，沒有就先推沒戴時的生活影響問卷（沿用 #154）。
- 生活影響問卷全站同一條：做過就推上次那份，沒做過才依年齡。

## 理由

老使用者已經知道有哪些問卷，要的是快點找到；新使用者才需要被帶。問想了解什麼，推出來的問卷才會不一樣。重測用同一份，前後才能比、趨勢圖不斷。

## 代價

過了 65 歲的人會一直被推 HHIA-S。戴助聽器卻選了聽不清楚、吵雜環境的人，「也可以做」不會出現 IOI-HA、SADL。精靈步數會變（一題或兩題）。
