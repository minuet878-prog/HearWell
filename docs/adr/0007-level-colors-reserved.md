# 0007 綠、橘、紅只用來表示分級

日期：2026-10-21（本人審定，設計系統第 2 階段比較頁與拷問 Q4；規格 #120）

## 情境

結果分級用顏色輔助：正常是綠、輕度到中度是橘、重度是紅（文字一定寫出來，顏色只是加強）。改版的混搭稿給首頁三張步驟卡配了藍、綠松、橘棕，顏色跟分級幾乎一樣，長者可能把「第 3 步是橘色」讀成「我是輕中度」。

## 決定

- 裝飾用的顏色（卡片、圖示、按鈕、漸層）只用藍色系。
- 綠、橘、紅只用在分級：分級徽章、結果橫幅、趨勢圖的分級色帶，以及成功／警告／錯誤的文字。
- 既有的例外保留：聽力圖右耳紅、左耳藍（臨床慣例），遮蔽開關開啟時的橘色（表示「現在在標遮蔽」的狀態）。
- 會刪除資料或讓分享失效、無法立刻還原的按鈕維持紅色（刪除帳號、刪除聽力圖、取消分享）。（2026-10-21 #120 拷問）

## 理由

這個網站最重要的訊息就是分級，顏色一旦被裝飾借去用，分級的顏色就不再有意義。藍色是主色，用同一色系做變化也比較一致。

## 代價

畫面的配色變化少，比較不「繽紛」。以後的功能如果需要別的強調色，要從藍色系挑；真的需要新的例外，另寫一份 ADR。
