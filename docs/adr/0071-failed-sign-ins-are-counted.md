# 0071 登入失敗有次數上限

日期：2026-11-19（本人審定，資安健檢後點選）

## 情境

一般登入、`/admin/` 登入、刪帳號前和確認本人時的密碼確認，原本都能無限次猜密碼。

## 決定

- 同一個帳號名稱 15 分鐘內失敗 5 次，或同一個 IP 一小時內失敗 20 次，就先不檢查密碼（連正確的也不收），顯示「試太多次了，請稍後再試」。
- 四個入口共用同一個帳號名稱的計數；計數存在資料庫快取表，只存雜湊，跟忘記密碼頁（#528）同一張表。

## 理由

只限 IP 擋不住換很多 IP 的撞庫；同時限帳號名稱才擋得住針對某個人猜。

## 代價

別人故意打錯某人的帳號名稱，可以讓他 15 分鐘登不進來（本人接受）。共用 Wi-Fi 的長照機構，很多人一起打錯時可能互相影響。
