# 0023 結果頁的建議下一步跟首頁推同一項

日期：2026-10-23（本人審定，白卡分級拷問 Q2、Q3、Q9、Q10）

## 情境

結果頁底部有三、四張一樣大的可點卡片（看紀錄、看報告、回首頁），看不出下一步先點哪張。首頁已經有「建議您下一步」，結果頁沒有。

## 決定

- 每份問卷的結果頁，在可點卡片區最上面加「建議您下一步」，挑法跟首頁同一套（依目前這一站），兩處永遠推同一項，連「因為」和按鈕都一樣。
- 不看這次的分級；看舊作答時也依現在的狀況挑。
- 被推的項目如果也在底下的卡片裡，就從底下拿掉；建議 1–3 文字裡的連結保留。

## 理由

首頁和結果頁講同一件事，長輩不會兩頁看到不同建議。挑法只有一套，以後改選配路線只要改一個地方。

## 代價

建議跟剛做完的那份問卷不一定直接相關（例如做完耳鳴量表卻推選配指引）。要等 #284 改完建議下一步的挑法才能做。
