# 0049 故事卡片是分享連結裡的一頁，不做成圖片

日期：2026-11-13（本人審定，[第 2 階段拷問決定](../planning/redesign/phase-2-grill-decisions.md) Q21、Q22）

## 情境

產品地圖的「故事卡片」是分享給家人的格式。台灣家人多用 LINE，傳圖片在群組裡最直接；現在的分享是 7 天到期、可以取消的連結，打開是完整報告。

## 決定

- 沿用分享連結。家人打開後最先看到一張大字卡片，往下才是完整報告。
- 一張卡片講一件事：從結果頁分享就講這次問卷結果，從聽力圖分享就講這張聽力圖，從護照或紀錄頁分享就講最近一件事。卡片上附照顧旅程進度和一句「您可以怎麼幫」。
- LINE 預覽只寫「聽伴｜某某分享了聽力紀錄」，不放健康資料。

## 理由

健康資料做成圖片傳出去就收不回來，還會被轉傳；連結可以到期、可以取消。左右滑的多張卡片對長輩和讀螢幕軟體都不好用。

## 代價

LINE 群組裡看不到卡片內容，要點開。分享連結要多記「從哪一筆分享的」。
