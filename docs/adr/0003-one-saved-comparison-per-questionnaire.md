# 0003 報告比較：每份問卷由本人手選、各保留一組

日期：2026-10-19（本人審定，#82、#83 實作）

## 情境

以前 HHIE-S 的配戴前後差值是自動拿紀錄配對。成人問卷加進來以後，HHIA-S、HHIE-S、SSQ12 都會有配戴和未配戴的紀錄，報告要放哪一組比較？

## 決定

- 本人從同一份問卷、同一版本裡，自己選一筆未配戴、一筆配戴，按「保留」才存。
- HHIA-S、HHIE-S、SSQ12 各保留一組，三組可以同時出現在本人和家屬報告。不同問卷不混成一組。
- 更換或移除一組，不影響其他組和原始作答；新增紀錄不會自動換掉已保留的組合。
- 這叫「配戴狀態比較」，不是介入前後測（用語見 `GLOSSARY.md`）。

## 理由

最新兩筆不一定是本人想給醫師或家屬看的那兩筆；自動換組會讓報告內容在本人不知情時改變。

## 代價

要多一個管理比較的畫面，也要納入匯出和刪除帳號的資料範圍。IOI-HA 的固定依據是另一件事（見 0002），不算在這三組裡。
