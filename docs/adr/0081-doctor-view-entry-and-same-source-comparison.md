# 0081 看診畫面的入口、診間外殼與同來源聽力圖比較

日期：2026-11-23（本人審定，承接 [ADR 0078](0078-records-page-without-bento-or-passport.md)）

## 情境

ADR 0078 取消便當格與聽力護照後，原本掛在護照上的「給醫師看」（看診畫面）沒有入口。此外，#702 新增了 Apple 聽力測試（自我測試），需要決定它與醫院聽力檢查並存時怎麼在診間呈現。

## 決定

- **入口與分工**：「我的紀錄」的問卷頁把「給醫師看」當主按鈕（重測到期時主按鈕仍讓給重測提醒），聽力圖頁保留「記錄聽力圖」為主按鈕、「給醫師看」放下方動作列；看診畫面底部連到完整的「看／印聽力報告」。
- **診間外殼**：看診畫面隱藏底部分頁列、只留返回鍵，頂端僅顯示年齡（有填出生年才有）與整理日期，不顯示帳號 email；聽力圖縮圖可點開查看詳細頁。
- **聽力圖同來源比較**：一律顯示日期最新的一張聽力圖；若為「自我測試」則標明「自我測試（非醫院檢查）」，且有更早的醫院聽力檢查時附一行提示。與上一張的差值只跟**同來源**的上一張相比，不拿自我測試與醫院檢查直接相減。
- **內容精簡**：生活影響顯示最新一筆與同配戴狀態變化，若有保留的配戴狀態比較則多附一行戴／沒戴對照；助聽器區塊在未配戴時只呈現已填的補助／證明事實（不寫選配路線站名）；其他問卷依程式定義自動涵蓋全部做過的問卷（含 SSQ12-TW）；沒有資料的區塊直接省略，全無紀錄才顯示空狀態。

## 理由

65+ 長輩在診間直接遞手機給醫師比列印紙本更常見，把看診畫面放在「我的紀錄」主動作位可減少現場尋找時間；隱藏底部分頁列可防醫師滑手機誤觸；醫院純音聽檢與 AirPods 自我測試量測條件不同，直接相減容易誤判聽力變化。

## 代價

「我的紀錄」最上方的實心按鈕從原本的「看／印聽力報告」換成「給醫師看」，要印紙本多一步點進報告（或從看診畫面底部進入）；醫院聽檢與自我測試交錯記錄時，不會顯示跨來源差值。
