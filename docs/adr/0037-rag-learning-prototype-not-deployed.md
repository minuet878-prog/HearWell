# 0037 RAG 學習原型放在 repo、不上線，不放寬 ADR 0035 的條件

日期：2026-10-27（本人審定，grill Q1–Q16）

## 情境

本人想親手學 RAG，但 ADR 0035 的開始條件（每月提問數、連續 3 個月的比例、不花錢的做法）要等 FAQ 版上線好幾個月才有數字。不想乾等，也不想為了學習去改上線條件。

## 決定

- 做一個**學習原型**，放在 `prototypes/rag/`，不部署、不給使用者用；部署和 CI 都不裝它的套件，它的測試只在本機跑。
- 模型用 Ollama 跑在本人電腦上，不送資料出去、不花錢。
- 先做 AI 挑題（檢索＋評估），最後才加 AI 回答。知識庫用 #402 的正式 FAQ 題目，測試問句由本人寫 50 句（30 句調整、20 句測試）。
- 最後寫一份結論報告：跟關鍵字比對的成績、本機的記憶體和速度。報告只供參考，不改 ADR 0035 的條件；數字再好看也不算「條件達到」，因為測試問句是本人寫的，不是真實提問，本人電腦也不是網站主機。

## 理由

放在 repo 裡可以直接讀 FAQ 定義檔，題目改了原型就拿到新版，也照樣走 PR 審查。把「學習」和「上線」分開，就不會因為想做 AI 而偷偷放寬條件。

## 代價

repo 裡多一個不部署的資料夾，套件清單要分開放；原型的測試不進 CI，忘了跑就沒人發現。
