# 0041 全站改版：白底、少用框、靠字級分層

日期：2026-11-12（本人審定，[拷問決定](../planning/redesign/grill-decisions.md) Q1–Q3）

## 情境

本人覺得畫面「不夠有設計感」：框太多、每樣東西份量一樣、底色太雜。ADR 0022、0024、0025 一路加了白卡、米色底、段落框，0026 在首頁加了藍色招呼區和儀表，層級反而更不清楚。

## 決定

- 全站一起改：頁面背景改白，拿掉米色底、段落框和多餘外框，用留白和字級分層；主色只用 #1f4e8c，分級色照 ADR 0007。
- 一頁只有一顆實心主要按鈕。內文至少 18px，按鈕高至少 56px，觸控目標至少 44px，文字對比至少 4.5:1。
- 共用元件（標題、區塊、清單、按鈕、可點卡片、提示框，以及白底上怎麼看出能點）先用一頁比較頁由本人選，各頁照套。首頁、空狀態首頁、結果頁、聽力圖詳細頁另做比較頁。每頁改版前都先給本人看設計圖。
- 共用元件（2026-11-12 本人在 [#454 比較頁第二版](../planning/redesign/mockup-454-components.html) 照建議選 T1、E、S1、P3、L1、N3、W1；第一版選過後本人要求多畫幾種重選）：
  - 字級：頁面標題 28px、段落標題 22px、內文 18px、次要說明 18px 灰（#4a5460）、出處 16px；標題不加藍條。
  - 能點的東西：清單列，左邊淡藍圓形圖示、右邊藍箭頭、細線隔開，標題維持黑字；單獨一個可點的東西放在色塊裡。
  - 按鈕：圓角方形；實心主要按鈕（高 56px、字 20px 粗體）一頁一顆，第二重要的用 2px 藍框，其他用文字連結。
  - 提示框：淡灰底、沒有外框；淡藍只給首頁現在這一步的卡片與能點的東西；緊急就醫框紅底加圖示。不再用左邊色條。
  - 分數與分級：整塊分級色（ADR 0007），分級一定寫成文字。
  - 步驟編號：藍框圓點加連接線，跟照顧旅程、選配路線同一個樣子。
  - 底部分頁列：浮動膠囊、88% 白毛玻璃，選中的分頁淡藍膠囊；減少透明度時實心白底（ADR 0043）。
- 取代 ADR 0022、0024、0025、0026；0026 的首頁改由 ADR 0042 決定。
- 在功能分支 `feat/redesign` 做完、全部驗收後一次合回 `main`；期間 `main` 只修 bug，不做會動畫面的新功能。

## 理由

只改幾頁的話，從首頁點進去就會看到兩種風格；分批合回 `main`，正式站也會有一段時間新舊混雜。先定元件再套全站，比每頁各自設計快，也比較一致。

## 代價

範圍大，分支活得久，要一直同步 `main`；e2e 與截圖基準幾乎全部要更新。暫停新功能，結果和圖表可以點、知識小測驗、聽損模擬會晚上線。沒有定稿圖的頁面只是換上新元件，版面結構大致不變。
