# 0039 產品改名「聽伴」，只改看得到的地方

日期：2026-11-05（本人審定）

## 情境

HearWell 在同領域有撞名，以後要上架 app。查過之後，「聽伴」在台灣商標和台灣 App Store 沒有衝突，但中國區 App Store 有同名的聽力 app「听伴」（2019 年後沒更新，其他地區查不到）。拼音 `tingban` 在台灣容易讀成「停班」，`tingban.com` 也已被註冊。

## 決定

- 中文名「聽伴」，完整名稱「聽伴 聽力自我照護」，英文名 `tingpal`。
- 只改使用者看得到的內容，以及 README 這類描述現況的文件。
- repo、資料庫、服務、套件名稱不改；舊 ADR 和驗證紀錄也不改。
- 作答草稿的鍵名 `hearwell:answer-draft:` 不改，改了使用者還沒交的草稿會不見。
- `hearwellweb@gmail.com` 先留著，這是真實信箱，要換由本人決定。
- 隱私權說明的營運者名稱改了，同意書升到第 3 版，所有人再同意一次。
- logo 換成「翅膀是一隻耳朵的小鳥」，藍色漸層卵石底留著。本人看過三批比較頁和小鳥加耳朵的組合後選的。

## 理由

使用者在台灣，中國區的同名 app 影響不大。內部名稱使用者看不到，改了只會增加網站出問題的風險。舊文件是當時的紀錄，回頭改就不真實了。舊的波浪 W 是 HearWell 的 W，名字換了就對不上；小鳥帶出「伴」，耳朵帶出「聽」。升版規則原本只寫蒐集的資料、用途和經手的服務，營運者名稱不在其中；但「誰在蒐集」是同意的內容，所以這次寧可多問一次。

## 代價

- 程式和主機裡會長期留著 hearwell 這個舊名，看的人要知道兩個名字是同一個產品。
- 用「聽伴」搜尋可能看到中國那個 app，以後要進中國市場也會卡住。
- 所有已同意的人下次使用都要再按一次同意。
- 目前沒有盈利，本人決定先不向智慧局或商標代理人確認，也還沒查圖形商標；鳥形 logo 很常見，可能撞圖。開始收費、上架 app 或申請商標之前要補做，到時可能要再改名或換圖。
- 16 像素的分頁籤上只看得出小鳥，看不出耳朵。
