# 0065 診間小卡用專用網址，永久保留，記一次再轉頁

日期：2026-11-16（本人審定，[「讓家屬找得到」第 6 項拷問決定](../planning/found-by-family/clinic-card-grill-decisions.md) Q5、Q7、Q15）

## 情境

本人要在診間發印有 QR code 的小卡，分長輩卡和家屬卡，也想知道每月有多少人從小卡進來。規劃原本寫在落點網址後面加一個來源參數。

## 決定

- 兩種卡各有一個小卡專用的短網址，QR code 裡放的是它。打開時在匿名月計數加一，再轉到落點（長輩卡：先問年齡的篩檢頁；家屬卡：家人專區首頁）。
- 這兩個網址永久保留，以後不改、不拿來做別的用途；要換落點只改轉去哪裡。
- 機器人（User-Agent 寫著自己是機器人的）照樣轉頁但不計數。短網址帶禁止收錄、不進 sitemap，`robots.txt` 不動（ADR 0062）。

## 理由

印出去的卡收不回來。落點網址加參數的話，網站改版時落點網址就不能動；重新整理、把網址再傳給別人也會重複計數，還要避開已經被保存卡用掉的 `?from=card`。短網址的 QR code 格子少，印在名片大小上比較好掃。

## 代價

多兩個不能刪的網址，以後整理網址時要記得留著它們。計數只是大概的數字：同一個人掃兩次算兩次，有心人亂打也會多算。
