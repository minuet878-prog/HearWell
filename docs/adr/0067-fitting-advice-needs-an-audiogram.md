# 0067 建議評估選配要看聽力圖，輕度再看問卷

日期：2026-11-17（本人審定，[拷問決定](../planning/audiogram-gated-advice/grill-decisions.md) Q1–Q11）

> 取代 [ADR 0017](0017-judge-only-with-a-basis.md) 的「任一耳 PTA 超過 25 dB 就建議評估選配」，以及 [ADR 0044](0044-home-is-the-care-journey.md) 的「目前不需要」條件。

## 情境

問卷結果頁三級都有「看助聽器選配與補助」，顯著影響還寫「考慮配戴助聽器」；聽力圖只要超過 25 dB 就建議評估選配。輕度、甚至聽力正常的人也一直被推助聽器。本人指出：篩檢結果不好不等於有聽損，有聽損也不等於需要助聽器。

## 決定

- 問卷結果只叫人去做聽力檢查、記錄聽力圖，不提助聽器。
- 任一耳四頻平均超過 40 dB 才直接建議評估選配；26–40 dB 的輕度要最新一筆生活影響問卷超過 8 分（輕度到中度影響以上）才建議，沒影響建議追蹤，沒問卷先請他做。
- 不建議評估選配的人，照顧旅程第 3、4 步是「目前不需要」；回答了路線上的問題才算本人自己要走，看過章節不算。

## 理由

書頁 40：沒有明顯障礙感受，難以說是合適的候選人。切點用問卷原作者的分級，不另外訂數字，由本人以聽力師身分審定。

## 代價

輕度又沒做問卷的人要多做一份問卷才看得到建議。這條組合規則是本人訂的，不是文獻直接寫的。只靠看章節走進路線的人，第 3、4 步會變回「目前不需要」。
