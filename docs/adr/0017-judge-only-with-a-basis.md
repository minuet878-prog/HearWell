# 0017 有法規公式或審定的臨界值，才對本人下判斷

日期：2026-10-22（本人審定，助聽器選配指引拷問 Q1、Q3、Q9、Q10）

## 情境

ADR 0013 規定所有頁面只講數字和方向、不下結論。助聽器選配指引卻需要兩個判斷：聽力圖到什麼程度該去找聽力師評估選配、聽力圖有沒有達到身障鑑定的門檻。只轉述數字的話，長輩要自己拿比率去對照法規表格，指引就失去意義。

## 決定

- 有依據才判斷：依據是法規公式，或本人審定、寫明出處的臨界值。其他情況照 0013 只轉述。
- 鑑定門檻：用身障鑑定聽覺機能（b230）的公式估算雙耳障礙比率，可以說「達到／未達到」，並附上比率和計算過程。句子固定寫「依您輸入的聽力圖估算……實際等級以鑑定醫院為準」。不說等級，也不說「符合補助」，因為補助要的是身障證明。
- 有測不到反應的點時，照標記的數值算出來的是最低估計：達到照說；未達到改說「無法確定」。
- 選配：任一耳 PTA 超過 25 dB（沿用網站現有的正常上限），只說「建議找聽力師評估選配」，不說「您需要助聽器」。只有問卷、沒有聽力圖時不判斷，只照問卷原本的建議請本人去做聽力檢查。

## 理由

門檻是法規算式，算出來的數字跟鑑定醫院用的是同一套，不是網站自己的臨床判斷。選配建議只叫人去評估，就算提醒錯了傷害也很小；漏掉的人反而損失比較大。

## 代價

使用者自己輸入的聽力圖可能打錯，結論跟著錯，所以每句都要附上「以鑑定醫院為準」。法規一改，公式和句子就要跟著改（每年查核一次）。以後想加別的判斷，都要先找到依據、由本人審定。
