# 0063 補助站預設收起，本人回答了才展開

日期：2026-11-16（本人審定，[拷問決定](../planning/hearing-aid-guide/subsidy-route-grill-decisions.md) Q1–Q4、Q6）

> 取代 [ADR 0021](0021-route-advanced-by-the-person.md) 的「不申請身障補助，跟補助有關的站標不適用」。

## 情境

選配路線九站裡有四站是身障補助（九號表、等待核定公文、二十五號表、等待補助發放）。本人回答之前，這四站照正常樣子排在路線上，看起來每個人都要走；沒有身障證明的人還要自己選「沒有，不申請身障補助」，讀起來像是自願不申請。本人指出這對申請不了補助的人是誤導。

## 決定

- 補助站預設收成一行：「有身障證明的人另外有四站」加一個到九號表章的連結。沒登入的人看到的也一樣。
- 本人回答「有」或「還沒有，打算申請或正在申請鑑定」才展開；已經回答過補助站題目的人也展開。
- 第三個選項只寫「沒有」，不問原因。答了之後路線上固定有「看沒有身障證明時」的連結。
- 不依聽力圖估算自動收起或展開。

## 理由

網站驗證不了證明，一向相信本人的回答（ADR 0020）。估算只能說「達到」或「未達到」，不能替本人決定要不要申請（ADR 0017）；聽力圖打錯、或靠視障那一條取得資格的人，自動判斷會把他們排掉。「申請不了」和「不想申請」在路線上結果一樣，不必讓長輩多分辨一次。

## 代價

- 有證明的人要先答一題才看到完整的九站。
- 分不出答「沒有」的人是申請不了還是不想申請。
- 我的選配指引同時是章節目錄，九號表章只剩收起那一行的連結進得去，二十五號表章要從九號表章再點一次。
- 路線多了「收起」這個狀態，規則和測試的組合又變多。
