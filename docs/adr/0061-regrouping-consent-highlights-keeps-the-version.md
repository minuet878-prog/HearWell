# 0061 同意書重點只分組、不改字，不升版

日期：2026-11-16（本人決定，[可讀性檢查](../planning/readability-review-2026-11-16.md)「第 3 批選定」）

## 情境

同意書的八條重點（同意頁和隱私權說明最上面共用）每加一個功能就多一條，八條同一層，不好讀。可讀性第 3 批把它分成三組，加上小標「用來做什麼」「登入和寄信時」「存在哪裡、您的權利」；每一條的字一個都不改，只為了分組調了順序（「結果只是參考」移到第一組）。

## 決定

- 同意書維持第 8 版，隱私權說明的更新日期也不改。
- 以後同樣只動排版、小標或順序，告知的內容沒變，都不升版；字句或蒐集的資料有改變才升版（ADR 0054 的規則照舊）。

## 理由

隱私權說明寫的是「蒐集的資料有改變」才請大家再同意。這次告知的內容一樣，只是比較好讀；升版要所有人再按一次同意，上次升第 8 版還引出首頁打勾回 405（#552）。

## 代價

改版前後同意的人看到的排版不同。哪天分組時順手改了一個字，就要記得升版；`test_consent.py` 逐字比對八條重點，會擋下來。
