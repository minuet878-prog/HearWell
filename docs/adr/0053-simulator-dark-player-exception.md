# 0053 聽損模擬的播放區用深藍底

日期：2026-11-13（本人審定，[#485 設計圖](../planning/redesign/mockup-485-simulator.html)）

## 情境

全站改版定了白底、少框，只有按鈕用實心藍（ADR 0043）。本人要聽損模擬「符合網站風格、又不要太像其他頁」，在三個方向裡選了聲音條加深藍播放器。

## 決定

- 聽損模擬的播放區是一整塊深藍（主色）底，裡面放白底的方塊聲音條、白色大播放鈕、上一句／下一句與兩個二選一。這頁的其他部分照舊白底。
- 這是 ADR 0043 的例外，只限這一頁的播放區。

## 理由

一眼看出這頁是拿來聽的，跟清單頁、結果頁分得開；聲音條讓換程度、切正常聽時看得到少了哪些聲音。白字在深藍上對比 8.31:1，夠讀。

## 代價

整頁只有這裡長這樣，元件要另寫，不能直接用網站的藥丸與按鈕樣式；以後別的互動頁想照做，要各自再判斷。深藍面積大（約 520px 高），字放大時要捲比較多。
