# 0077 只播一次的進場動畫可以做

日期：2026-11-21（本人審定，[頁面改版拷問決定](../planning/redesign/page-redesign-grill-decisions.md) P7、P9）

> 取代 [ADR 0006](0006-motion-rules.md) 的「不做卡片進場動畫、數字往上跑」、[ADR 0028](0028-button-feedback-motion.md) 的「位移只限列出的幾種」、[ADR 0029](0029-scroll-aware-motion.md) 的「結果頁分數位置條不動」。[ADR 0075](0075-stamp-and-countdown-ring-animations.md) 的蓋章與圓環併入這條。

## 情境

畫布上很多東西自己會動：小鳥跳一下、光圈、標題擦字、分數和天數從 0 往上跑、儀表和折線畫出來、圓點彈出、聲波跳、「幫我選」晃、區塊捲到時滑上來、分頁列膠囊滑過去。舊規定幾乎都不准。

## 決定

- 進場動畫可以做，但：每個東西只播一次、總長約 2 秒內、不循環、捲走再捲回來不重播、捲到才播（照 0029）。
- 分數直接顯示最後的值，不往上跑；只有天數（倒數的「還有 N 天」）從 0 往上跑。儀表和折線照樣畫一次。
- 數字往上跑時，讀螢幕的人直接聽到最後的值。
- 系統開「減少動態效果」：全部不動，直接是最後的樣子。
- 按鈕、作答選項的按下回饋仍然只變色（0028 不變）。分頁列選中的藍色膠囊可以滑到點的那格，做法跟二選一切換相同。

- 2026-11-21 本人改：分數不再往上跑（動畫拷問 C8）。等數字跑完才看得到結果，拖慢讀結果；分數差的時候一路往上跑也不適合壞消息。

## 理由

長輩需要「網站有反應、剛剛做的事有結果」的感覺；只播一次、可以關掉，比較不會讓人頭暈或分心。

## 代價

動畫變多，每個都要測「減少動態效果」和捲到才播；慢的手機可能卡。容易頭暈的人要自己去系統設定關掉。
