# 0043 底部分頁列半透明，往下捲隱藏

日期：2026-11-12（本人審定，[拷問決定](../planning/redesign/grill-decisions.md) Q17-1）

## 情境

本人希望底部分頁列像 YouTube App：半透明毛玻璃，往下捲時藏起來、往上捲時出現。ADR 0006 規定位移只給可點的卡片；長輩也可能以為選單不見了。

## 決定

- 分頁列維持浮動膠囊形狀，做成 88% 白的毛玻璃（#454 比較頁 W1；80% 也合格但本人沒選，72% 最壞情況對比不到 4.5:1），透明度只開一點，文字對比固定至少 4.5:1；系統開「減少透明度」時改成實心白底。
- 往下捲隱藏、往上捲出現；捲到頁面底部、鍵盤焦點移到分頁上時一定出現。系統開「減少動態效果」時永遠顯示、不滑動。
- 這是 ADR 0006 位移規則的例外，只限分頁列。

## 理由

字放大到 200% 時，分頁列佔掉不少畫面，捲動時讓出來能多看幾行。保護措施讓需要穩定畫面的人不受影響。

## 代價

不熟這種操作的長輩可能找不到選單；半透明後面透出的內容會讓分頁列看起來每次都不一樣。多一段 JavaScript 和一組 e2e 測試。靜態設計圖只能畫出半透明的樣子，隱藏的行為要在預覽網站上試。
