# 0038 忘記密碼頁直接說「沒註冊」，靠限制次數減速

日期：2026-10-27（本人審定，#355 拷問 Q4、Q5、Q10）

## 情境

忘記密碼頁輸入信箱後，畫面可以一律說「如果有註冊就會收到信」，也可以直接說「這個信箱沒有註冊」。後者讓人能拿別人的信箱試出對方有沒有帳號（列舉攻擊）。OWASP 建議敏感服務一律回同一句；HearWell 是聽力篩檢網站，「有帳號」本身就透露可能有聽力問題。

## 決定

- 查不到信箱就直接說沒註冊，讓打錯字的長輩馬上發現。
- 在 Django 裡限制次數：同一個 IP 每小時最多查 10 次、同一個信箱每小時最多寄 3 封。
- 信箱只對到管理員帳號時，顯示跟沒註冊同一句。

## 理由

本人參考一般網站的做法，認為長輩打錯信箱、一直等不到信的困擾，比被慢慢試出有沒有帳號更常發生。限制次數同時防止有人狂按、灌爆別人信箱和用完每天的免費寄信額度。

## 代價

有心人換 IP、慢慢試，還是試得出某個信箱有沒有帳號；這是刻意接受的風險，審查時不要當成漏洞「修掉」。以後要改回一律同一句，只改畫面文字和測試，限制次數可以保留。
