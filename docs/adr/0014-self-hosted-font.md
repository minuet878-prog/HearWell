# 0014 字型由網站自己提供，不用 Google Fonts

日期：2026-10-22（本人審定，2c 支線改版拷問 Q41）

## 情境

#108 讓每一頁都從 Google Fonts 下載 Noto Sans TC，Google 看得到使用者的 IP。隱私權說明卻還寫著遷移 Tailwind 前用的 cdnjs，說明跟實際不符。照 `models.py` 的規則，多一個經手的服務要提高同意版本，所有人重新同意。

## 決定

用套件把 Noto Sans TC 打包進網站，由自己的主機提供；隱私權說明刪掉 cdnjs 那條，算小修，只更新修訂日期。

## 理由

少一個看得到 IP 的第三方，對長輩的隱私最好，也不用驚動所有人重新同意。

## 代價

多一個字型套件，網站要自己送字型檔；要量首頁載入，確認沒有比 Google Fonts 慢。以後想改回 Google Fonts，要先改隱私權說明並提高同意版本。
