# 0032 問答小助手只答一般問題，衛教數字附來源、不對人

日期：2026-10-26（本人審定，wayfinder 地圖 #371 的 #372 拷問 Q1–Q4）

## 情境

問答小助手要先做 FAQ 版，之後可能升級成 RAG。長輩常問「我 18 分嚴重嗎」這類跟自己紀錄有關的問題；登入後讀紀錄來回答會比較貼近，但會碰到 ADR 0013（只轉述、不判讀）和法規研究提到的「協助診斷」風險，升級 RAG 時還得把健康資料送到境外 AI 服務。

## 決定

- 只回答一般問題，登入與否答案都一樣，不讀本人的問卷或聽力圖。問到自己的結果時，給轉介答案、連到「我的紀錄」。
- 解讀本人結果、診斷與用藥、品牌型號與店家、急症（突然聽不到、耳朵流血）各有一題轉介答案；急症置頂、醒目，請盡快就醫。
- 答案可以寫一般性的數字、門檻、時限，但每題要本人審定、附來源與查核日期，用「一般來說」「依法規」的句型，不寫「您……」。

## 理由

法規研究認為只給衛教資訊最接近「不屬醫療器材」，也不用把健康資料送出去。一般性數字有來源就不是網站自己的判斷，跟選配指引的寫法一致。

## 代價

答案比較通用，長輩要自己點去結果頁。衛教數字要納入每年查核。以後想做個人化回答，要先重新查法規、改這份 ADR。
