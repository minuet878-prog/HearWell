# 0048 紀錄頁改成便當格，加上聽力護照與看診畫面

日期：2026-11-13（本人審定，[第 2 階段拷問決定](../planning/redesign/phase-2-grill-decisions.md) Q15–Q20）

## 情境

「紀錄」分頁現在是「問卷｜聽力圖」二選一（ADR 0019）。定稿紀錄頁是一頁便當格總覽，最下面一格是「聽力護照」，有「給醫師看」按鈕。

## 決定

- 「紀錄」分頁打開便當格，四格：生活影響問卷（分數、小趨勢線，底下一行列出其他做過的問卷）、聽力圖、助聽器（戴了幾天；還沒戴時寫選配路線目前這一站）、聽力護照。點格子進原本的清單。取代 ADR 0019 的「問卷｜聽力圖」二選一。
- 本週日記、每天有沒有戴（「本週 5/7 天」）等第 3 階段。
- 聽力護照：每做一份問卷、記一張聽力圖、開始配戴助聽器就多一個有日期的章，最後一格虛線是現在這一步。從既有紀錄推算，不新增資料表。
- 「給醫師看」是新的看診畫面：最近一張聽力圖、生活影響分數與變化、助聽器狀態、做過的其他問卷摘要。完整的聽力報告照舊。

## 理由

便當格讓第一個畫面就看得到全部重點。章跟著紀錄長，不配助聽器的人也一直有章可蓋，不會像固定里程碑那樣永遠收不齊。聽力報告是為列印設計的，診間拿手機給醫師看要捲很久，所以另做一個畫面。

## 代價

看清單要多點一下，導覽和 e2e 要改。看診畫面要跟聽力報告保持一致。紀錄多的人章很多，要收合。
