# 0040 語言香蕉區依雅文海報，每群注音比聽力線，說「可能」

日期：2026-11-06（本人審定，互動內容拷問 Q4–Q23；細節見 [拷問決定](../planning/speech-banana/grill-decisions.md)）

## 情境

聽力圖看語言香蕉區要告訴本人哪些說話聲可能聽不到。ADR 0013 規定只轉述、不下結論；ADR 0017 允許有依據才判斷。只講「ㄙ 在標記上方」，長輩要自己想一步，就失去這一頁的意思。文獻裡華語資料不足：Hu 等 2018 的音素只測到 3000 Hz 附近，ㄙ 落在約 1200 Hz，和臨床印象差很多。

## 決定

- 這是 ADR 0017 的新判斷，依據是雅文基金會的〈聽力圖和語言香蕉區〉海報，數值從圖上讀出，本人審定並寫明出處；審定前不能上線。上線前本人向雅文確認使用許可和資料來源。
- 注音分六群，每群一個代表點，比該頻率上的氣導聽力線，兩個標記之間用連線估計。
- 代表點比聽力線大聲寫「可能聽得到」，小於或等於寫「可能不容易聽到」，聽力線因無反應斷開時寫「無法確定」，超出最低或最高標記寫無法估計。
- 不加 10–12 dB 邊際，跟海報畫法一致。
- 香蕉區上的斜線是同一條規則畫成圖，也算判斷，一起審定。
- 第一版不放生活聲音；火警、煙霧警報只用文字提醒：清醒時聽得到不等於睡著會被叫醒。
- 不依斜線多寡給建議。下一步只用現有條件的選配指引卡。
- 圖上的字跟著圖縮放，是 ADR 0031「本人選過的小字」的例外；結果和清單照使用者字級放大。

## 理由

海報是台灣機構給聽損家庭用的繁體注音圖，高頻音位置也符合臨床。37 個標籤在手機上點不準，分群才按得到。文字比聽力線，和斜線、海報的畫法才不會互相矛盾；聽閾是剛好聽得到一半的音量，等於時說「不容易」比較誠實。

## 代價

依據是一張海報，沒有數字和資料來源，讀值有誤差，也是畫給兒童家長看的；雅文不同意使用就要換來源。一群只用一個代表點，比較粗；8 個母音有兩個位置，會出現在兩群。兩個標記之間用連線估計，是估計上再估計。不加邊際，「可能聽得到」不代表聽得清楚，要靠提醒說明。使用者輸入的聽力圖打錯，結果就跟著錯。以後想加生活聲音或依斜線多寡給建議，要先找到依據。
