# 0013 支線頁也只轉述、不判讀

日期：2026-10-22（本人審定，2c 支線改版拷問 Q1）

## 情境

ADR 0010 只管首頁和生活影響問卷的結果頁。設計比較頁第 8–14 列在別的頁面加了不少下結論的句子：配戴比較「戴助聽器有沒有幫助？」「戴著時影響比較小」、IOI-HA「需要注意」「一起看怎麼改善」、聽力圖「兩耳都有聽力損失」「程度都還是輕度」「（高音）」。

## 決定

- 0010 的原則延伸到所有頁面：只講數字和方向，不說變好、變差。
- 說明文字只能改寫已審定的原文；不是改寫的新句子，在規格裡逐條列出，本人審定後才能用。
- 已有的提醒照留，例如「差值不能單獨判定助聽器效益」。

## 理由

這些句子大多沒有臨界值或文獻依據；網站自己下結論，等於多了沒根據的臨床判斷。

## 代價

設計稿的文案變得比較平淡；每次新增句子都要本人審。
