# 0042 首頁改成照顧旅程，建議下一步就是現在這一步

日期：2026-11-12（本人審定，[拷問決定](../planning/redesign/grill-decisions.md) Q4–Q15、Q17）

## 情境

老使用者首頁的主角是上次的分數（ADR 0026），下一步藏在「建議下一步」和「您還可以」幾張卡片裡。本人選定的定稿圖改成「今天只要做一件事」：一條五步的照顧旅程，目前那一步展開。

## 決定

- 有任何問卷或聽力圖紀錄的人看照顧旅程，五步：填生活影響問卷、記錄聽力圖、了解助聽器選配與補助、戴滿 3 個月做效益問卷、半年後再篩檢。都沒有紀錄的人看空狀態首頁。
- 每一步的狀態全部從現有資料推算，不新增資料表：第 1 步看生活影響問卷；第 2 步看聽力圖能不能判讀；第 3 步看有沒有填開始配戴日期；第 4 步看開始配戴日之後有沒有 IOI-HA；第 5 步不打勾，從上次生活影響問卷倒數 6 個月。
- 現在這一步：由上往下第一個沒完成、也不是目前不需要的步；已戴助聽器的人從第 3 步算起。聽力圖在正常範圍、本人還沒開始走選配路線時，第 3、4 步是目前不需要。
- 展開的卡片只寫一件事：第 3 步是選配路線的目前這一站；第 4 步是二十五號表（有期限時）或倒數到滿 3 個月。
- 建議下一步就是現在這一步，結果頁推同一件事（沿用 ADR 0023 兩處一致的原則）；沒有能做的事時推分享或列印報告。
- 頂端兩格：上次結果只放生活影響問卷；下次篩檢日期大字、天數小字，到期寫「已到期」並附連結，不搶走現在這一步。
- 結果頁跟上次比只寫數字和分級變化，不寫進步或退步（ADR 0017）。

## 理由

長輩一次只需要知道一件事。選配路線已經會判斷目前這一站，旅程第 3 步直接借用，不必重寫，也不會跟我的選配指引說法不同。從現有資料推算，不用請本人多填東西。

## 代價

旅程第 5 步永遠到不了「全部完成」。已戴助聽器的人第 1、2 步可能一直沒打勾。卡在第 3 步半年以上的人，重測只有頂端一個文字連結，比較不醒目。判斷散在問卷、聽力圖、助聽器與補助資料三處，任一邊規則改了都要回頭看旅程。
