# 0046 家人模式：各自帳號，長輩邀請，家人可以看、可以代記

日期：2026-11-13（本人審定，[第 2 階段拷問決定](../planning/redesign/phase-2-grill-decisions.md) Q1–Q10）

## 情境

定稿首頁右上有「我／爸爸」切換。現在家人看長輩的資料只有 7 天到期的分享連結，不用帳號、只能看報告，看不到照顧旅程，也不能幫忙記。

## 決定

- 長輩和家人各自有帳號。長輩在帳號設定發邀請連結，畫面上寫清楚家人能看什麼、能替他記什麼、怎麼解除，按下同意才產生；家人登入自己的帳號接受，並自己取稱呼（爸爸、媽媽、阿公……）。
- 一位長輩可以連好幾位家人，一位家人也可以連好幾位長輩。雙方都能隨時解除，長輩在帳號設定看得到連著的每一位。
- 家人切到長輩後，整個網站都顯示長輩的資料，每頁頂端寫「正在看爸爸的資料｜切回我」。
- 家人可以看全部健康資料，也可以代記事實：聽力圖、選配路線的回答、手動待辦。問卷只能本人填。帳號設定、同意書、分享連結、下載資料、刪除帳號、邀請別人只有本人能做。
- 代記的資料記下是誰記的，畫面上寫「小明代記」；家人解除或刪帳號後資料留在長輩帳號，只寫「家人代記」。
- 同意書不升版；隱私權說明加一段家人連結，同意記在每一次邀請上。
- 現有的分享連結照舊，給沒有帳號的家人用。

## 理由

資料屬於長輩本人，授權也由本人給，個資法上當事人清楚。HHIE-S 等是自填量表，代填的分數意義不同，所以只讓家人記事實。只有用這功能的人需要同意，不用讓所有人重新同意一次。

## 代價

每個健康資料頁都要改成「看目前切到的人」，每個寫入的地方都要改權限檢查，必須交叉審查。不會用手機的長輩還是要有人陪著註冊和發邀請。代記要在幾張表加欄位，刪帳號的順序也要處理。
