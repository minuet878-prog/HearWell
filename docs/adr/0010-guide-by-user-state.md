# 0010 主線依使用者狀態引導：首頁分新老使用者、結果頁依分級給步驟

日期：2026-10-22（本人審定，2b 主線動線改版拷問 Q2、Q12、Q13、Q15）

## 情境

Phase 4（2026-10-15）決定「首頁不依登入狀態或紀錄變化」「結果頁不依分級給不同的下一步」，當時沒記原因。主線動線改版發現：老使用者回來看到的還是「第一次使用請先註冊」，重測提醒沒有地方放；顯著影響的人讀完一大段建議，下一步仍只有「看紀錄／回首頁」。

## 決定

- 首頁分兩種：新使用者看介紹；老使用者（至少一筆問卷紀錄）看上次結果、重測提醒與下一步。首頁因此顯示健康資料，要禁止瀏覽器快取。
- 結果頁依分級給「接下來建議您」步驟清單，原本的建議文字一字不改放在下方。
- 步驟只能改寫建議原文，每一條對得回原文的一句；唯一例外是「半年後再做一次」（重測提醒）。
- 趨勢只講數字和方向（「比上一次少 4 分，分數越低越好」），不下「變好／變差」的結論；要下結論得先有臨界值的文獻依據。

## 理由

長輩回來第一眼要看到自己的狀況和下一步，重測循環才接得起來。步驟和趨勢只轉述、不判讀，網站就不會多出沒有根據的臨床建議。

## 代價

首頁要測兩種狀態；每份生活影響問卷每一級都要多寫一套步驟、本人審定。趨勢句比較保守，長輩要自己理解「少 4 分」代表什麼。
