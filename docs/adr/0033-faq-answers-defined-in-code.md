# 0033 問答小助手的答案寫在程式裡，重疊的連去指引

日期：2026-10-26（本人審定，wayfinder 地圖 #371 的 #375 拷問 Q1–Q8）

## 情境

問答小助手 FAQ 版要放幾十題答案，每題本人審定、附來源與查核日期（ADR 0032）。可以放資料庫讓本人在 admin 直接改，也可以像問卷一樣寫在程式裡（ADR 0005）。有些題目（補助金額、鑑定流程）選配指引已經寫過。

## 決定

- 每題寫在一個 Python 定義檔：主題、題目、答案、來源、查核日期、其他問法、網址代碼。不建資料表，admin 看不到；改內容走 PR，本人同意合併就算審定。
- 跟選配指引、家人溝通頁重疊的題目只簡答，不重寫金額、年限這類會變的數字，下方連到那一章。
- 答案原地改、更新查核日期，不像問卷要開新版。網址代碼上線後不改、不重用；拿掉的題目，舊網址轉到小助手首頁。
- 查核併入選配指引的年度查核。

## 理由

本人是唯一審定者，PR 紀錄就是審定紀錄。比對在記憶體做（#374），不需要資料庫。數字只寫在指引一處，查核時不會漏改。家人會互傳答案連結，網址要一直有效。

## 代價

改一個錯字也要開 PR、重新部署。想看金額要多點一次到指引。要留一份「已拿掉的網址代碼」清單。
