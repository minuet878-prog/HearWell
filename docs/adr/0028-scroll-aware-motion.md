# 0028 動畫等捲到才播、跳到段落後框亮一下、儀表條從 0 填滿

日期：2026-10-24（本人在捲動效果比較頁選 A、B、K、N，拷問時加上儀表條填滿）

## 情境

進場動畫是頁面一打開就播。我的選配指引的選配路線排在摘要下面，「目前這一站」的光圈在畫面外就播完了，長輩捲到時看到的是停住的樣子；200% 字級時首頁的儀表也可能被擠到下面。點了「看沒有身障證明時」這類連結，跳過去之後長輩常不確定自己落在哪一段。

## 決定

- **進場動畫捲到才播**：所有進場動畫一律等那個東西整個進到畫面才播一次（比畫面還高的，佔滿畫面一半就播）。一打開就在畫面裡的跟原本一樣馬上播。照 ADR 0006：只播一次、捲走再捲回來不重播，「減少動態效果」時直接停在最後的樣子。沒有 JavaScript 時無法知道進到畫面了沒，跟原本一樣一打開就播（ADR 0006）。
- **儀表條從 0 填滿**：我的選配指引的儀表條（兩耳四頻平均、雙耳障礙比率）捲到時從 0 長到數值，約 1.2 秒，兩耳同時，停住不回彈。不算「數字往上跑」：旁邊的數字從頭到尾都是最後的值（同 ADR 0026 的儀表指針）。結果頁的分數位置條和 SSQ12 位置條仍然不動。
- **跳到段落後框亮一下**：點了連結跳到同一頁或別頁的某一段（網址帶 #），目標所在的整個框（段落框、並列區塊、選配路線的一站；不在框裡的就亮目標自己）外圈亮起主色藍外框加光暈，停約 1.5 秒、再 1.5 秒淡掉。「跳到主要內容」和表單錯誤摘要的跳題連結不亮。「減少動態效果」時不淡入淡出，直接出現、3 秒後直接消失。

## 理由

捲到才播只改「什麼時候播」，不加新動畫，長輩終於看得到。儀表條是一段從 0 量起的長度，長出來的過程就是在說「這麼多」；分數位置條是色段加標記，當初決定不動，這次不改。亮整個框，長輩看得出「這一整段就是你要看的」，跨頁跳轉換了一整頁，更需要。

## 代價

以後每加一個進場動畫，都要接上「捲到才播」，測試也要能讓它播。網站上有的條會動、有的不會。用瀏覽器「上一頁」回到帶 # 的網址時框會再亮一次。
