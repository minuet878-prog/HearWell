# 0052 聽損模擬用合成語音，在手機上即時變模糊

日期：2026-11-13（本人審定，[第 3 階段拷問決定](../planning/redesign/phase-3-grill-decisions.md) Q11、Q12）

## 情境

互動內容清單的聽損模擬寫著「要有語音授權、無法校準」。要決定模擬誰的聽力、說話聲從哪來、怎麼變成聽損的樣子。

## 決定

- 只做幾種典型程度（輕度、中度、中重度、高頻下降），不用登入，不用本人的聽力圖。
- 說話聲用台灣口音的 TTS 語音合成先生好幾句家常話，存成音檔。
- 變模糊用 DSP 在手機上即時處理：分頻、各頻率照代表聽力圖調小聲，可以跟「正常聽」來回切。
- 畫面寫明只模擬變小聲，實際可能更吃力。

## 理由

典型程度不用登入，家人專區直接進得去，也不必等家人模式。合成語音不用找人錄、改句子容易，避開授權問題。即時處理只要一組音檔，比每種程度各做一份輕。

## 代價

- 不是爸爸真正的聽力。
- 合成語音語氣稍機械，小孩聲不好做；要先查清楚 TTS 服務准不准把音檔放上網站。
- 網站不知道手機音量，只能模擬「哪些頻率比較小聲」的形狀；聽損讓聲音糊在一起、大聲刺耳這些模擬不出來。
