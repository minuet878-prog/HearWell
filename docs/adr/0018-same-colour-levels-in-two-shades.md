# 0018 相鄰兩級同色時，較重的那級用深一點的底色

日期：2026-10-23（本人在 THI 色帶比較頁選做法 A）

## 情境

THI 有五級，照規格 #208 Q13 只用 ADR 0007 的三色：輕度、中度都是橘，重度、極重度都是紅。趨勢圖的色帶和結果頁的分數條是照顏色畫的，相鄰同色的兩級就黏成一條，圖上只看得到三條，圖下卻列了五個名稱。

## 決定

- 相鄰兩級同一個顏色時，較重的那一級用同色系深一點的底色（橘 `#f9dd96`、紅 `#f6c3b3`）；三級以上連著同色就淺深交替。規則寫在問卷定義的 `Definition.shade()`，API、圖例、分數條、趨勢圖都讀它。
- 趨勢圖的色帶之間、分數條的每段之間加 2px 白線。所有問卷都一樣，不只 THI。
- 分級徽章和結果橫幅維持三色：上面一定寫著級別名稱。
- 不新增綠、橘、紅以外的顏色，ADR 0007 不變。

## 理由

只改底色深淺、不加新顏色，就能讓五個名稱和五條色帶一一對上；比在圖裡寫名稱簡單，也不會壓到分數點。

## 代價

淺色底之間的深淺差，對視力不好的長者還是不算明顯，主要靠白線分界。以後如果有問卷的某個顏色連著三級以上，淺深交替的效果會比較弱，到時候要重新看。
