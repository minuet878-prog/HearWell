# 0024 並列區塊上米色底，聽力報告按問卷摺疊

日期：2026-10-23（本人在平面區塊可讀性比較頁選 A＋B＋D，拷問 Q1–Q17）

## 情境

#297 照 ADR 0022 把資訊白卡都改成平面區塊、完全沒有底色後，長輩反映難讀。跟改版前對照：一組內容的邊界不見了，組與組的距離跟組內段落差不多；區塊裡的小標跟內文一樣大；分隔線跟背景只差 1.16:1。聽力報告最嚴重，螢幕版約 7 個手機畫面連成一片。

## 決定

- **並列區塊**（GLOSSARY）上淡米色底：比頁面背景深一點、沒有陰影。可點的卡片仍是白底加陰影，一個凹下去、一個浮起來。用在報告各問卷、IOI-HA／SADL／SSQ12 的單題或分量表、左右耳結果、家人頁每個主題、結果頁的建議 1–3（三條合成一塊）、分享設定步驟、戴與不戴比較的預覽。
- 選配指引各章是照順序讀的文章，不上底色，段與段的距離拉開到段內的兩倍，不加分隔線。首頁歡迎回來、帳號設定、選配路線維持 0022 的畫法。
- 平面內容裡的小標放大：並列區塊的標題、區塊裡的粗體小標（家人頁技巧、指引小標、IOI-HA 題名）。可點的卡片、問卷題目不動。
- 聽力報告螢幕版（本人的報告和家人看的分享報告都一樣）每份問卷收成一列，預設全部收起；摘要列寫問卷名稱、日期和結果，外觀跟全站下拉框一樣（白底灰框、沒有陰影）。配戴比較收在該問卷裡；重點摘要和聽力圖不收。列印時全部展開，紙本不變。
- 白底卻不能點的東西一併改掉：指引的小膠囊和「常常／有時／從未」拿掉外框變成清單或粗體字；IOI-HA 五格量尺的白格改成透明加細線。
- 報告表格的日期不斷行；放不下時（例如字級 200%）每一筆改成上下排的一塊。

## 理由

外框能讓長輩一眼看出「到這裡是一組」，拿掉之後光靠留白不夠。底色比背景深、白卡比背景淺，「白的就能點」反而更好分。細框（C 案）會被當成外框按鈕，所以不用。報告太長，摺疊後先看到一排結果，想看細節再打開。

## 代價

推翻 #298 選定的「平面區塊完全沒有底色」，0022 的畫法有一部分改由本檔決定。新頁面要判斷內容是不是並列區塊。報告要多點一下才看得到細節，分數在重點摘要和摺疊列各出現一次。報告表格有兩種長相，測試較多。
