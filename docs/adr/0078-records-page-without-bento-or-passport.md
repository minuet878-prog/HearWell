# 0078 紀錄頁照新設計，不做便當格和聽力護照

日期：2026-11-21（本人審定，[頁面改版拷問決定](../planning/redesign/page-redesign-grill-decisions.md) P17、P18）

> 取代 [ADR 0048](0048-records-bento-and-hearing-passport.md)。

## 情境

0048 決定紀錄頁改成便當格總覽加聽力護照，還沒做。這次畫布畫了另一種紀錄頁，本人選畫布。

## 決定

- 紀錄頁：最近一次（分數、分級、比上一次）、分數趨勢（折線加分級色帶）、每次的紀錄；問卷｜聽力圖切換保留。
- 不做便當格、聽力護照。
- 趨勢圖橫軸寫月／日，保留每次有沒有戴助聽器的形狀標記和開始配戴日。

## 理由

畫布的紀錄頁一頁看得完、跟結果頁同一套樣子；便當格要多點一層才看得到趨勢。

## 代價

聽力護照（蓋章紀錄）這個想法放掉。0048 的看診畫面原本從護照的「給醫師看」打開，入口要另外決定。
