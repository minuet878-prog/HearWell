# 0073 拿掉待辦，刪掉打勾紀錄

日期：2026-11-21（本人審定，[照顧旅程展開改版拷問決定](../planning/redesign/journey-redesign-grill-decisions.md) Q1–Q3）

> 取代 [ADR 0047](0047-journey-to-dos-auto-and-manual.md)。

## 情境

本人在設計圖上逐站看照顧旅程的展開，每一站的「要做的事」、打勾框和「⋯網站會知道」都請刪掉：卡片上同一件事講三次，長輩不知道要按哪個。

## 決定

- 首頁照顧旅程和我的選配指引都不再有待辦，自動、手動都拿掉。卡片只寫這一步的一件事和它的按鈕或問答。
- 已經存的打勾紀錄連同資料表一起刪掉，下載我的資料不再列；只為了算待辦輪次的「第幾台」也一起刪。
- 正式環境部署前先告訴本人會刪幾筆。

## 理由

畫面不用了，留著使用者看不到的打勾紀錄沒有用途，個資能少存就少存。

## 代價

刪了就救不回來；以後想把提醒式的待辦加回來，要重新設計、重新存。換過幾次助聽器的計數也跟著沒了。
