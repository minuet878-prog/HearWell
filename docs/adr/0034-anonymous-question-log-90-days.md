# 0034 打字提問匿名存 90 天，同意書不升版

日期：2026-10-26（本人審定，wayfinder 地圖 #371 的 #376 拷問 Q1–Q10）

## 情境

問答小助手可以打字提問。不記下問句，就不知道缺哪些題、比對門檻對不對，也沒有判斷要不要做 RAG 的數字。但問句是自由輸入，可能夾帶姓名或病情。法規研究（#377）把做法分三級：只記次數、存原文不連人、存原文並連帳號。

## 決定

- 每句打字提問都存原文和比對結果（對到哪一題或沒對到）與日期；不存帳號、不存 IP。點選清單不記。
- 90 天後自動刪除。本人每月在 admin 看一次，admin 不能修改，但可以提早刪單筆。
- 問句不能出現在網址裡，不然會連同 IP 進到主機商紀錄和瀏覽器歷史。
- 要留下來的問法，由本人改寫、去掉個資後才寫進定義檔（repo 是公開的），不複製原文。
- 隱私權說明加一段、更新日期，打字框旁提醒「會匿名保存 90 天、請不要輸入個資」。同意書**不升版**。
- 不連帳號，所以「下載我的資料」和「刪除帳號」不包含提問紀錄。

## 理由

只記次數看不到長輩怎麼問，沒辦法補題；連帳號對補題沒有幫助，研究推論超出必要範圍。同意書的規則是「收新資料就升版」，但這份紀錄不連帳號，沒登入的人也會打字；升版只會擋下已註冊的人，管不到最需要告知的人。在打字的當下提醒，每個人都看得到。

## 代價

原文仍可能有人打進個資，要靠提醒、90 天刪除和本人提早刪。這是升版規則的第一個例外；以後要把問句連到帳號或送到 AI 服務，就要升版、改這份 ADR。
