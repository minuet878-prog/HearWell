# 0070 信箱要先確認，才寄重設密碼信和重測提醒

日期：2026-11-19（本人審定，資安健檢後點選）

## 情境

註冊、LINE 名字頁、補上 email 時打的信箱，網站都不會確認。打錯的信箱（例如 gmial.com），持有人可以用「忘記密碼」替帳號設密碼、登入看健康資料。任何人也能填別人的信箱，讓聽伴寄重設信或提醒信過去。

## 決定

- 打的信箱會收到確認信，按「確認信箱」才算確認；連結 3 天有效，打開連結不算，要再按一次按鈕（防信箱的連結掃描）。
- 沒確認的信箱：忘記密碼頁說「還沒確認」並請人寫信給我們，不寄信；重測提醒打不開也不寄。
- Google 給的信箱直接算已確認；這次上線前已填的信箱也先算已確認。
- 帳號設定可以重寄，每個帳號每小時 3 封。

## 理由

長輩打錯信箱很常見，被人接管就會看到健康資料。舊帳號直接算已確認，是為了不讓現有使用者突然重設不了密碼。

## 代價

上線前已填錯的舊信箱，風險還在。還沒確認就忘記密碼的人，只能寫信請本人在 admin 手動處理（填 `confirmed_email`）。多一封信會用到 Resend 每天 100 封的額度。
