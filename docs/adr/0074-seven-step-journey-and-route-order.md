# 0074 照顧旅程改成七步，去找聽力師之前排到核定公文之後

日期：2026-11-21（本人審定，[照顧旅程展開改版拷問決定](../planning/redesign/journey-redesign-grill-decisions.md) Q5–Q16、Q22）

## 情境

舊的照顧旅程五步裡，「了解助聽器選配與補助」一步包了選配路線九站，長輩看不出自己做到哪。本人在設計圖上把幾件事拉出來、重新排順序。

## 決定

- 旅程七步：填生活影響問卷、到醫院進行聽力檢查、記錄聽力圖、了解助聽器選配與補助、申請補助與配戴助聽器、戴滿 3 個月做效益問卷、半年後再篩檢。
- 到醫院進行聽力檢查：記了任何聽力圖（醫院或 AirPods）就完成。了解助聽器選配與補助：打開過我的選配指引頁就完成；聽力正常的人這步和後兩步都是目前不需要。
- 選配路線改成：記錄聽力圖、身障鑑定、九號表、等待核定公文、去找聽力師之前、助聽器的種類與價格、配戴之後、二十五號表、等待補助發放。首頁和我的選配指引用同一個順序。
- 首頁不寫助聽器的種類與價格這一站，指引停在這站時首頁直接寫下一站；核定公文還沒收到時連到這章。
- 配戴之後要記下開始配戴日期、也做完第一次 IOI-HA 才完成；戴滿 3 個月做第二次，結果頁跟第一次比。

## 理由

本人說身障證明、九號表、核定公文決定要不要、能不能用補助，知道這些之後再去找聽力師比較實際。IOI-HA 本來就是比剛戴和戴一陣子的變化，只做一次看不出效果。

## 代價

- 首頁和指引的「目前這一站」不再永遠一樣（只差種類與價格這站）。
- 舊使用者的現在這一步會變：很多人會從到醫院或了解助聽器重新顯示，已經看過去找聽力師之前那章的人，這站仍算完成。
- 配戴之後多了一個條件，剛戴、還沒填問卷的人會停在這站。
- 要新做 IOI-HA 的前後比較，也要開始記錄看過指引頁。
