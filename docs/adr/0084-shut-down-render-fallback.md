# 0084 關掉 Render 退路

日期：2026-11-26（本人決定）

## 情況

2026-11-12 正式站搬到 VPS 時，Render 留著當退路（ADR 0041）：關掉自動部署，停在搬家前的版本。兩週下來 VPS 穩定，部署也改成 `main` 的 CI 通過後由 `.github/workflows/deploy.yml` 自動執行 `scripts/deploy.sh`。

## 決定

- 本人 2026-11-26 刪掉 Render 的服務和 Neon 專案（只有舊的測試資料），並解除 Render 這個 GitHub App 對 repo 的存取。
- 刪掉 Render 專用的 `build.sh`，部署步驟只看 `scripts/deploy.sh`；原本檢查 `build.sh` 順序的測試改讀它。部署時不再順便清提問紀錄，交給 VPS 每天 02:30 的排程。
- repo 裡把 Render 當現況的說明一起拿掉；歷史文件和舊 ADR 的內文不改。

## 原因

- 退路跑的是搬家前的舊程式和舊同意書，真的切回去反而是一個過時的網站。
- Neon 的資料在美國，跟隱私權說明寫的「主機和資料庫在日本東京」不一致（2026-11-19 資安健檢第 11 項）。
- 已經有 deploy.yml 自動部署，壞了就修 VPS 或退回上一個 commit，用不到另一個平台。

## 代價

- 沒有第二個站可以切換：VPS 整台壞掉時，要從備份在新主機上重建。
