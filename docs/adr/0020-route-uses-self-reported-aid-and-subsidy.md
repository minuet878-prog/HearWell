# 0020 選配路線改看本人自填的助聽器與補助資料

日期：2026-10-23（本人審定，[路線推進拷問](../planning/hearing-aid-guide/route-progress-grill-decisions.md) Q1–Q13）

## 情境

選配路線只看問卷和聽力圖。估算達到鑑定門檻的人，「您在這裡」會一直停在身障鑑定，拿到證明也推不動；網站也不知道本人什麼時候開始戴，二十五號表「配戴 1–3 個月內」的期限只能寫在章節裡，最容易錯過。

## 決定

- 新增「我的助聽器與補助」：本人自己填四項：有沒有聽覺機能身障證明、開始配戴日期、戴哪一耳、有沒有用身障補助買（用了再填等級）。都可以不填，只記目前這一副。
- 路線照填的內容推進：有證明就到九號表；要做二十五號表的人，配戴滿 1 到 3 個月時停在二十五號表並寫出期限；用身障補助的人寫出滿 4 年可以再申請的日子。
- 隱私權說明加上這些資料，同意書升到第 2 版，所有人再同意一次。

## 理由

網站沒辦法去驗證證明或購買紀錄，只能相信本人填的；這比繼續讓路線卡住好。照隱私權頁自己的承諾，蒐集的資料變了就要請大家再同意。

## 代價

- 身障證明是敏感的健康資料，多存一種就多一份外洩的風險；分享報告不放、列印報告也不印證明。
- 每個現有使用者下次登入都會被同意頁擋一次。
- 本人填錯或忘了改（例如換了新機），路線就會標錯。
- 網站還是不知道本人做完二十五號表了沒，超過 3 個月就不再提。
