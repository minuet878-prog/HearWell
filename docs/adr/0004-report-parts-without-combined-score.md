# 0004 聽力報告分三個面向，不合成一個總分

日期：2026-10-19（本人審定，#84 實作，#90 修正分區）

## 情境

報告裡同時有 HHIA-S／HHIE-S、SSQ12、IOI-HA，量的東西、刻度、計分方式都不一樣。

## 決定

- 報告分三區：生活影響（HHIA-S、HHIE-S）、日常聆聽能力（SSQ12）、助聽器使用成效（IOI-HA）。每份問卷的結果和它的比較放在自己那一區。
- 每份問卷保留自己的計分與解讀，不另外算一個「聽力健康總分」或總級別。
- 沒有資料的分區不顯示空標題。

## 理由

生活影響和聆聽能力是不同面向，可以互補，但加起來等於自創一個沒有依據的臨床指標。

## 代價

報告比較長，讀的人要分區看；沒有一個數字可以「一眼看完」。
