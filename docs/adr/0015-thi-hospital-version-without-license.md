# 0015 THI 用醫院現用版本，不等書面同意就上線

日期：2026-10-22（本人審定，THI 拷問）

## 情境

ADR 0011 規定有版權的問卷要先取得原作者與中文譯者的書面同意，才放進正式目錄。THI 的中文版是本人醫院現用的版本（黃啟原修訂、李恆惠信度考驗），完整書目沒有追到。

## 決定

THI 照醫院表單逐字上線，不寄信、不等書面同意，是 ADR 0011 的例外。

## 理由

本人決定：這是醫院臨床上一直在用的版本。

## 代價

HearWell 是公開網站，不是醫院內部使用。日後原作者（Newman）或中文修訂者反對，就要下架；已經有的作答紀錄要保留給本人看。
