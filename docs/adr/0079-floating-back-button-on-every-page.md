# 0079 每一頁往下捲都有霧玻璃返回鍵

日期：2026-11-21（本人審定，[頁面改版拷問決定](../planning/redesign/page-redesign-grill-decisions.md) P2、P8）

> 補充 [ADR 0045](0045-translucent-tab-bar-hides-on-scroll.md)：霧玻璃不只用在分頁列。

## 情境

現在只有加到手機主畫面的人看得到「‹ 上一頁」。長輩常從 LINE 或別的頁點進來，不知道怎麼回去。

## 決定

- 每一頁（包括首頁和四個分頁）往下捲後，左上的「聽伴」淡出、換成圓形霧玻璃「‹」返回鍵，右上頭像也變霧玻璃，浮在內容上、不加白色橫條。捲回最上面恢復原樣。
- 返回鍵是瀏覽器的上一頁；沒有上一頁（從外面直接打開）就回首頁。
- 霧玻璃照 0045：88% 白，系統開「減少透明度」時改實心白。
- 2026-11-21 本人驗收時改：返回鍵一開始就在「聽伴」左邊，不用等往下捲；首頁沒有返回鍵（往下捲也沒有，只剩霧玻璃頭像）。往下捲時「聽伴」淡出、「‹」留在原位變霧玻璃，位置不跳。答題頁照舊是「‹ 離開」。

## 理由

每頁都在同一個位置有返回鍵，長輩不用找瀏覽器的上一頁。

## 代價

頁首要改成固定在上方；返回鍵要判斷有沒有上一頁，判斷錯時會回首頁而不是使用者以為的地方。
