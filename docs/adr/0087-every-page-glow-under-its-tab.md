# 0087 每一頁都有光暈，停在目前分頁下面

日期：2026-11-28（本人在光暈比較頁選 G1、N3，見[驗證紀錄](../verification/every-page-glow.md)）

## 情況

同一天稍早，本人選了「只有照顧旅程首頁有淡藍光暈」（走查第四輪，首頁光暈 B），其他頁維持 ADR 0043 的白底。看了之後，本人覺得電腦版首頁的白色分頁列很突兀，想讓每一頁都有類似的光暈，換頁時光暈會動。

## 決定

- 每一頁上方都有淡藍光暈（顏色、大小跟首頁一樣），停在目前分頁的正下方。電腦版的分頁列在上面，手機的在底部，光暈都在畫面上方，左右位置對齊亮起來的那一格。不屬於任何分頁的頁面（隱私說明、意見回饋、帳號設定等）放在正中間。
- 換頁時，光暈從上一頁的位置用 0.4 秒滑到新位置，只滑這一次。開了「減少動態效果」就直接出現在新位置。
- 標題列改成透明；電腦版分頁列改成半透明白（N3），保留下面的細線。
- 頁面底色不變：照顧旅程首頁是極淡灰白、區塊是白卡片，其他頁還是白底，只多了上方的光暈。

## 原因

- 光暈跟著分頁走（G1）時移動距離短、方向跟按的分頁一致，比起每頁換一個角落（G2）更不容易讓長輩覺得畫面在晃。
- 符合 ADR 0028 的原則：使用者自己按了才動、只動一次、減少動態時不動。
- 滑動用 CSS 的 transition，沒有沿用分頁膠囊的跨頁轉場（view transition）：跨頁轉場那 0.4 秒會把光暈畫在整頁內容的上面。

## 代價

- ADR 0043「全站白底」多一個例外：頁面上方有淡藍色。e2e 改成檢查每頁都有光暈；字標「伴」是大字，在光暈最深處的對比度約 4.2:1（大字標準 3:1）。
- 上一頁的位置記在瀏覽器的 sessionStorage（`hearwell:glow-x`）；記不住時（無痕視窗等），光暈就從正中間滑過去。
- 其他頁的淡色元件（小鳥對話框、二選一切換、問卷小卡）現在疊在淡藍上，比原本在白底上淡一點，要在實機上看。
