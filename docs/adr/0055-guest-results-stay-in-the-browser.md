# 0055 訪客結果只留在瀏覽器，同意後才保存

日期：2026-11-13（本人審定，[開放階段第 1 項拷問決定](../planning/open-access/grill-decisions.md)）

## 情境

要讓沒登入的人先做 HHIE-S／HHIA-S。作答與分級是健康資料，網站目前一律在本人註冊並同意之後才存。

## 決定

- 訪客結果只存在訪客自己的瀏覽器裡，留 7 天。
- 伺服器提供一個「只算分」的入口，照問卷定義回傳分數與分級，不寫資料庫。
- 註冊並同意後，用原本的寫入 API 保存，紀錄日期是保存那天。
- 伺服器只留匿名月計數（訪客完成幾次、保存幾次），不存明細、不存 IP。

## 理由

沒同意就不存健康資料，個資法上最單純，同意書也不用升版。分數照樣由伺服器照問卷定義算，訪客看到的跟保存後一樣。

## 代價

- 換手機或換瀏覽器就看不到，7 天後自動消失。
- 從 LINE 裡打開、再跳到外部瀏覽器登入時，可能讀不到訪客結果（見[登入研究](../planning/open-access/login-research.md)）。
- 網站不知道訪客做了什麼，只能看月計數。
- 以後要做跨裝置接續（例如社區篩檢），得改成伺服器先存，同意流程也要重想。
