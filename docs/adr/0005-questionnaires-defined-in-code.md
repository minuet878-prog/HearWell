# 0005 問卷由程式定義，admin 只能看

日期：2026-10-20（本人審定，成人問卷第二批的前置重構）

## 情境

「這份問卷用哪些選項、怎麼計分、能不能選不適用」散在 `forms.py`、`models.py`、API、`views.py` 和模板，約 45 處 `if code == ...`。加一份問卷要改 8 個以上檔案。第二批的 APHAB、SADL 計分都跟現有的不一樣，不先整理會更亂。

## 決定

- 每份問卷一個定義檔，放在 `screening/questionnaires/`，裡面有選項、門檻、計分、比較、目錄文案、題目文字。其他地方問定義檔，不再寫死代碼。
- 規則放 Python，不放資料庫。
- 新問卷用一支通用的 `seed_questionnaires` 依定義檔建立；HHIE-S、IOI-HA 照舊用 fixture。
- admin 的問卷和題目改成唯讀。沒有定義檔的問卷不出現在目錄，網址打開是 404。

## 理由

計分規則本來就是程式。放在資料庫的話，admin 或部署時的 `loaddata` 一改就會改到計分，跟「門檻不能直接改」的原則衝突。問卷內容既然由程式定義，admin 能新增、修改問卷或題目，只會做出跟定義檔對不上的半成品。

## 代價

改錯字也要從程式改，而且要走「新增一份問卷」。舊的兩份問卷還在 fixture，等於有兩種建立方式。
