方案 A（推薦）

雙軌路線切換 ＋ 三階段色塊

把「辦身障補助 vs 直接選配」做成一鍵切換，底下用三個平面色塊分階段（無圓點直線），中間嵌「先拿核定公文再買」關卡，每章單擊直達。

方案 B

去流程化・三幕指南手冊

徹底拿掉流程圖！進度與問答全交給首頁「照顧旅程」，這頁上方放聽力判讀大卡，下方純粹按「資格／挑選／配戴」三幕列出六章與關鍵數字。

方案 C

補助四關時限集章單 ＋ 六章清單

只把最容易搞錯期限的「身障補助四關」畫成雙欄集章格（沿用朱紅已完成印章＋標出 3 個月／6 個月／1–3 個月），與下方六章目錄分開。

方案 D

三種處境分流頁籤（一次只看當下）

頂端三個大按鈕「還沒配／辦補助中／已經買了」，登入自動停在目前處境、家屬也能自己切，畫面一次只留當下最需要的 3 篇，完全不拖長。
