# 助聽器選配指引拷問決定

[回功能規劃](../README.md)

- 日期：2026-10-22，本人逐題回答。
- 需求原文：問卷篩檢 → 聽力圖 → 異常建議選配 → 由聽力圖算是否達身障門檻 → 九號表流程＋所需知識＋能配合的醫療院所 → 常見助聽器類型（含價格）與哪裡買 → 二十五號表流程＋所需知識；其他由代理補足。
- 法規與補助的事實查核見[研究報告](research.md)（查核日期 2026-10-22）。
- 原則見 ADR 0017（有法規公式或審定的臨界值才判斷）。

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 可不可以對本人下結論 | A：有依據就可以。鑑定門檻說「達到／未達到」（法規公式）；選配只說「建議找聽力師評估」，不說「您需要助聽器」。新增 ADR 0017（原編號 0015，與 THI 撞號後改號），0013 其他不變。 |
| Q2 | 指引的形式 | B：一頁「我的選配指引」摘要頁（讀本人問卷與聽力圖，屬健康資料頁面，禁止快取）＋不用登入也能看的章節頁，每頁可單獨閱讀。不做一步一步的精靈。 |
| Q3 | 建議選配評估的條件 | A：任一耳 PTA（500／1k／2k／4k）> 25 dB（沿用 `NORMAL_LIMIT`）。算不出 PTA 顯示「資料不足，無法判斷」。只有問卷時照問卷原有建議請本人做聽力檢查（HHIA-S 說明：不能單憑分數決定是否需要助聽器）。 |
| Q4 | 已配戴助聽器的人 | A：這一版只服務第一次選配。最近一筆問卷是配戴狀態時，建議格改成「您已在使用助聽器，換新機與再次申請補助的規定見九號表章節」並連到再次申請段落。不存購買日期。 |
| Q5 | 用哪張聽力圖 | A：最新一張（檢查日期最新），不管多舊；摘要頁開頭寫出檢查日期。不加過期提醒。 |
| Q6 | 補充章節 | 做「選配之後」（試戴、回診調整、用 IOI-HA／SADL／SSQ12 追蹤）、「去之前準備」（帶什麼、問聽力師的問題清單）、「集音器與助聽器的差別」（併進類型章節）。人工電子耳、保養與電池這一版不做。不需身障證明的補助見 Q13。 |
| Q7 | 章節內容存放與更新 | A：寫在模板；每章頁尾寫「本頁資料查核於 YYYY-MM-DD」＋官方來源連結，會變的數字（金額、年限）旁附來源。改動走 PR、本人審定；roadmap 時間型待辦加「每年查核一次」。 |
| Q8 | 入口 | A：首頁「您還可以」加卡片「助聽器選配指引」（新、老使用者都看得到，沒登入點進去看章節目錄）；聽力圖結果頁在任一耳 PTA > 25 dB 時出現連結；生活影響問卷結果頁「建議安排聽力評估」那一步加連結，不改句子。不加底部分頁。 |
| Q9 | 門檻怎麼呈現 | A：用「鑑定門檻」，不用「補助門檻」。句子：「依您 YYYY-MM-DD 的聽力圖估算，雙耳障礙比率約 X%，達到／未達到身障鑑定門檻（45%）。實際以鑑定醫院為準。」下面可展開「怎麼算的」（兩耳 PTA、公式）。不顯示等級（補助金額看收入，不看等級）。固定一句：達到的話要先去鑑定醫院申請鑑定，拿到證明後才能申請九號表補助。 |
| Q10 | 有測不到反應的點 | A：照標記的數值代入，算出來是最低估計。達到就照說，並註明有測不到反應的點；未達到但有測不到反應的點，改說「無法確定是否達到鑑定門檻，請以鑑定醫院為準」。 |
| Q11 | 能配合的醫療院所 | A：鑑定醫院從衛福部名冊 XLSX（版本 1150717）擷取可做 b230 的約 169 家，存成資料快照，頁面依縣市篩選（名稱、地址、電話），標名冊版本與查核日期，每年查核時更新。九號表寫「找醫院耳鼻喉科的聽力師，或您縣市的輔具中心」並列出 22 個縣市輔具中心。不列聽力所（沒有官方來源，有背書與廣告疑慮）。 |
| Q12 | 類型、價格、哪裡買 | A：類型依社家署單張改寫（耳掛、受話器外置、耳內，加上集音器的差別）。價格只列補助四個級距與上限（簡易 2,000／中階 10,000／進階 20,000／雙對側 30,000 元），寫「實際售價依等級與店家差異很大，購買前請店家提供報價單與保固內容」，不寫市價、不提品牌型號。哪裡買寫「有醫療器材販賣業許可的聽力所或醫院」，並教怎麼在食藥署網站查許可證字號。上線前由本人判斷是否向食藥署或律師確認廣告法規。 |
| Q13 | 不需身障證明的補助 | A：九號表章節加「沒有身障證明時」，寫低收入戶老人配戴助聽器補助（65 歲以上、聽損 45–110 dB、每只最多 5,500 元），加上「各縣市可能另有補助，請洽您縣市的社會局」。摘要頁在未達到鑑定門檻時連到這一段。寫規格前要找到社家署原文，找不到就不寫金額，只寫請洽社會局。 |
| Q14 | 單耳 PTA 低於 25 dB | 以 0% 計，「怎麼算的」裡註明「低於 25 dB 的耳以 0% 計」。官方沒有規定，研究報告說實務一般如此；只要有一耳低於 25 dB，雙耳比率最多 16.7%，不影響「達到／未達到」的結論，只影響顯示的數字。 |

## 沒有另外問、照預設走的（本人確認共同理解時一併同意）

- 已有身障證明的人：摘要頁固定一句「如果您已經有身障證明，可以直接進行九號表」，不問也不存。
- 未滿六歲的 22.5% 規定不處理（網站對象是成人），章節頁註明。
- 中度以上視障且優耳大於 40 dB 的補助資格：只在九號表章節提一句，摘要頁不判斷。
- 摘要頁與章節頁用 Django 模板（內容頁＋縣市篩選，互動不重），不用 React。
- 摘要頁依狀態顯示：沒登入 → 章節目錄；登入但沒資料 → 請先做問卷或輸入聽力圖；只有問卷 → 建議做聽力檢查；有聽力圖 → 選配建議＋鑑定門檻；最近一筆問卷是配戴狀態 → 照 Q4。

## 研究結果帶出的補充

- 「一耳 ≥ 90 dB 且另一耳 ≥ 48 dB」代入公式剛好是 45.0%，所以只判斷雙耳障礙比率 ≥ 45% 就涵蓋這一款，不另外寫規則。
- 鑑定表規定比率四捨五入到小數點後一位，所以拿四捨五入後的值跟 45.0% 比。
- 公式只用氣導，骨導不納入（研究報告信心中）。
