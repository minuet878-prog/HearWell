# 選配路線與首頁建議下一步拷問決定

[回功能規劃](../README.md)

- 日期：2026-10-23，本人逐題回答。
- 需求原文：替助聽器選配與補助（選配指引）設計更鮮明、互動感強的引導；登入後首頁「您還可以」有沒有更好的導覽設計。
- 本人在比較頁選定：選配指引上面兩個狀況儀表、下面「看我的路線」按鈕接選配路線，加上章節內的步驟條；「您還可以」用「建議下一步＋分組小卡」。
- 用語見 GLOSSARY：選配路線、目前這一站、建議下一步。原則仍是 ADR 0017，這次不新增 ADR。

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 規格怎麼切 | 一份母規格兩部分（選配指引、首頁），共用「目前這一站」的判斷。 |
| Q2 | 路線幾站 | 七站：六章前面加「記錄聽力圖」（不是章節，連到記錄聽力圖）。 |
| Q3 | 「已完成」 | 只用在「記錄聽力圖」（有聽力圖就標，寫檢查日期）。其他站網站不知道，不標。 |
| Q4 | 已戴助聽器的人 | 目前這一站是「配戴助聽器之後」，不管有沒有聽力圖；九號表那站加一句「換新機看再次申請」連到 #reapply。取代 #218 Q4 只連九號表的做法。 |
| Q5 | 估算達到門檻 | 目前這一站是「身障鑑定與鑑定醫院」（先拿證明才能申請九號表補助）。 |
| Q6 | 估算無法確定 | 目前這一站是「去找聽力師之前」；鑑定站照一般站顯示，不加標籤。 |
| Q7 | 兩耳都在 25 dB HL 以內 | 沒有目前這一站。 |
| Q8 | 估算未達到 | 鑑定站標「估算未達門檻」、淡色底，附「看沒有身障證明時」。不寫「可略過」（不替本人決定要不要鑑定）。 |
| Q9 | 聽力圖缺頻率 | 目前這一站是「記錄聽力圖」，標「資料不足」，按鈕「修改這張聽力圖」；不標已完成。 |
| Q10 | 四頻平均長條刻度 | 0–120 dB HL，負值畫成 0，數字照寫；25 dB 畫一條「正常上限 25」的線。 |
| Q11 | 長條顏色 | 右耳紅、左耳藍（跟聽力圖一樣），另有文字標示左右耳。 |
| Q12 | 有測不到反應的點 | 比率長條實心畫到算出的最低值，後面接斜線區到 100% 表示「可能更高」，數字寫「至少約 X%」。達到但有測不到反應的點也一樣。 |
| Q13 | 步驟條套用範圍 | 九號表「申請流程」、鑑定「怎麼申請鑑定」（三段拆成三步，不改字，約 35 天做成期限標籤）。 |
| Q14 | 首頁推薦規則 | 跟選配路線連動：目前這一站是記錄聽力圖 → 推薦記錄（缺頻率時是修改）聽力圖；是其他站 → 推薦我的選配指引；沒有目前這一站 → 沒分享過推薦分享給家人，分享過推薦印聽力報告。 |
| Q15 | 推薦選配指引時按鈕去哪 | 我的選配指引頁（不直接進章節），按鈕「看我的選配指引」。 |
| Q16 | 「因為」句 | 照草稿（見下表）寫進規格，新寫的句子驗收時本人定稿。 |
| Q17 | 其他小卡 | 分組＋圖示、不加說明：記錄／給別人看／了解／方便使用。被推薦的那張不重複，空的組不顯示，主畫面 App 裡隱藏「方便使用」整組。 |
| Q18 | 目前這一站的優先順序 | 由上往下第一個符合：① 最新問卷戴助聽器（含 IOI-HA）→ 配戴之後；② 沒有聽力圖 → 記錄聽力圖；③ 缺頻率 → 記錄聽力圖（資料不足）；④ 估算達到 → 鑑定；⑤ 任一耳 > 25 dB HL → 去找聽力師之前；⑥ 其他 → 沒有。 |
| Q19 | 用語 | 選配路線、目前這一站、建議下一步（畫面文字仍是「您在這裡」「建議您下一步」）。 |
| Q20 | 小卡圖示 | 沿用 `feat/action-cards` 的動作卡片與 `action_icon.html`，只補缺的圖示（聽力圖、加到主畫面）。首頁那張票被它擋住，選配指引不受影響。 |

## 「因為」句草稿（★ 為新寫，驗收時定稿）

| 推薦 | 情況 | 因為 | 按鈕 |
|---|---|---|---|
| 記錄醫院的聽力圖 | 沒有聽力圖 | ★ 您還沒有記錄聽力圖，選配指引要用聽力圖才能整理下一步。 | 去記錄 |
| 修改這張聽力圖 | 缺頻率 | 這張聽力圖缺少頻率，資料不足，無法判斷。 | 修改這張聽力圖 |
| 了解助聽器選配與補助 | 建議評估 | 您有一耳以上的四頻平均超過 25 dB HL，建議找聽力師評估選配助聽器。 | 看我的選配指引 |
| 了解助聽器選配與補助 | 估算達到 | ★ 依您的聽力圖估算，達到身障鑑定門檻（45%）。實際以鑑定醫院為準。 | 看我的選配指引 |
| 了解助聽器選配與補助 | 已戴助聽器 | ★ 您已在使用助聽器，可以看配戴之後要注意什麼、怎麼記錄效果。 | 看我的選配指引 |
| 分享報告給家人 | 沒有目前這一站、沒分享過 | ★ 讓家人也知道您的聽力狀況，家人不用登入就能看。 | 去分享 |
| 印聽力報告給醫師看 | 沒有目前這一站、分享過 | ★ 看診時把報告帶給醫師，一張紙看完所有紀錄。 | 去印報告 |

## 沒有另外問、照比較頁走的（本人確認共同理解時一併同意）

- 頁面順序：問卷結果卡 → 「要不要找聽力師評估」儀表 → 「身障鑑定門檻」儀表 → 「看我的路線」按鈕 → 選配路線。按鈕只在有儀表時出現，按了在同一頁捲到路線標題並把焦點移過去。
- 儀表旁一定留數字與 #220 審定過的原句；比率長條用中性藍，不用分級顏色。某一耳沒有四頻平均時不畫那一耳的長條，寫「資料不足，無法判讀」；兩耳都沒有時不畫比率長條，照現有句子。
- 沒登入：只有選配路線、不標狀態，沒有儀表和按鈕。已登入但沒有任何紀錄：保留現有兩顆按鈕，目前這一站是記錄聽力圖。
- 選配路線每站只留一句短話，不重複儀表上的結論。
- 動態：只有目前這一站有淡淡的光暈；「減少動態」時不動，按鈕改成直接跳過去。
- 「怎麼算的」摺疊框保留在門檻儀表下。
