# 補助站預設收起拷問決定

[回功能規劃](../README.md)

- 日期：2026-11-16，本人逐題回答。
- 需求原文：「感覺現在網頁對無法申請補助的族群有點誤導。」
- 範圍：本人從四處可能誤導的地方選了兩處：選配路線預設人人走補助、邀請句把補助講成人人有份。
- 取代 [九站拷問](route-steps-grill-decisions.md) 的 Q2（三個答案與「不適用」的四站）。

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 補助站什麼時候顯示 | 先問再顯示。本人回答「有」或「還沒有，打算申請或正在申請鑑定」之前，九號表、等待核定公文、二十五號表、等待補助發放這四站收成一行；答了才展開成正常的站。不依聽力圖估算自動決定（ADR 0017：估算不替本人下結論）。 |
| Q2 | 身障證明題的選項 | 三個：「有」「還沒有，打算申請或正在申請鑑定」「沒有」。「沒有」不問原因，選了第 3 站已完成、往種類與價格走，以後拿到證明可以回來改。 |
| Q3 | 收起的那一行 | 一句話加一個連結：「有身障證明的人另外有四站」並列出站名，連結到九號表章。不能就地展開。 |
| Q4 | 沒登入的人 | 跟還沒回答的人一樣：五站加收起的一行。 |
| Q5 | 章節最下面的「下一章」（#579） | 不動。章節照固定閱讀順序，每個人看到的都一樣，不跟路線分流。 |
| Q6 | 答「沒有」之後的其他資源 | 第 3 站的答案下面固定有「看沒有身障證明時」的連結，連到九號表章最後那一段；段落不搬。估算未達門檻、還沒回答時的連結照舊。 |
| Q7 | 名稱「助聽器選配與補助」 | 不改，當成主題名留著。 |
| Q8 | 邀請句 | 訪客問卷結果的兩句、首頁照顧旅程第 3 步點開的說明，三句都不提補助。草稿：「……網站會一步步帶您走助聽器選配。」「照選配路線一站一站走，從找聽力師到開始戴助聽器。」寫規格時本人逐句定稿。 |

## 用來檢查選項的兩個人

- 陳太太：兩耳 40 dB，估算 22.5% 未達門檻，沒有證明。選「沒有」。
- 王先生：兩耳 60 dB，估算 52.5% 達到門檻，沒有證明，打算去鑑定但還沒去公所。選「還沒有，打算申請或正在申請鑑定」，補助站展開，停在第 3 站看怎麼申請鑑定。

## 沒有另外問、照預設做的（本人確認共同理解時一併同意）

1. 沒回答證明題、但已經回答過補助站題目的人（九號表完成沒、收到核定公文沒，或在配戴之後回答「用身障補助」），補助站也展開。
2. 答「沒有」的人一律收起，不再把四站標「不適用」。
3. 補助站展開後，「不適用」照舊：自費或其他補助買的人的二十五號表與等待補助發放、簡易型的二十五號表。
4. 資料庫存的值不改、不搬資料，只改選項顯示的字；以前選「沒有，不申請身障補助」的人顯示成「沒有」。沒有新增蒐集的資料，同意書不升版。
5. 收起時站的編號、那一行放在路線的哪裡，由設計圖決定。
6. 「您在這裡」的規則不變：由上往下第一個還沒完成的站，已戴助聽器的人從配戴之後算起。
7. 補助檢核、問答、章節內文一個字不改。

## 這次不做

本人看過、沒有選的兩處：

- 估算未達門檻時，首頁卡片和路線的主按鈕還是「找鑑定醫院」。
- 種類與價格章、九號表章的重點卡列補助金額時，沒有先說要身障證明。
