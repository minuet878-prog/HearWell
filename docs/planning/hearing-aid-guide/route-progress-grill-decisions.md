# 選配路線推進拷問決定

[回功能規劃](../README.md)

- 日期：2026-10-23，本人逐題回答。
- 需求原文：選配路線到了身障鑑定就沒辦法繼續走（「您在這裡」一直停在身障鑑定）；除了身障證明，還要加什麼資訊，這次一起加。
- 背景：選配路線原本只看問卷和聽力圖（[路線拷問決定](route-grill-decisions.md) Q3、Q18），網站不知道本人有沒有證明、何時開始戴。

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 記錄哪些資訊 | 四項：身障證明、開始配戴日期＋等級、有沒有用補助買、戴哪一耳。不加：九號表與核定進度、戶別、證明重新鑑定日期、證明等級＋第一次鑑定年齡、保固到期日、聽力所電話、情境日記（roadmap 構想，另做）。 |
| Q2 | 在哪裡填 | 新增一頁表單，四項都在上面、每題都可以不填、之後隨時改；路線「身障鑑定」站放「我已經有身障證明」、「配戴之後」站放「記錄我的助聽器」，都連到這頁。 |
| Q3 | 身障證明的選項 | 有／還沒有；沒填當作不知道。題目下小字寫明聽覺機能（b230、s260 或舊制 02）。 |
| Q4 | 補助與等級 | 「用身障補助（有九號表）」／「自費或其他補助」二選一；選身障補助才問等級：簡易型／中階型／進階型／雙對側傳聲型／不知道。沒有 JavaScript 時等級題一直顯示。 |
| Q5 | 開始配戴日期 | 完整日期，跟記錄聽力圖同一種日期欄位；小字「可以看購買收據或保固書上的日期」。 |
| Q6 | 有證明、還沒戴 | 目前這一站是九號表，不管有沒有聽力圖（排在「已戴助聽器」之後、「沒有聽力圖」之前）；身障鑑定站標「已完成」。 |
| Q7 | 要做二十五號表的人 | 「要做」＝用身障補助、等級中階型以上或不知道。配戴未滿 1 個月：目前這一站是配戴之後，二十五號表站寫「X/X 起可以做」；滿 1 個月到 3 個月：目前這一站是二十五號表，寫「X/X 前要做完」；超過 3 個月：回到配戴之後，不再提二十五號表。網站不知道本人做完了沒。 |
| Q8 | 換新機 | 只記目前這一副；換新機時本人改成新的，舊的蓋掉。 |
| Q9 | 隱私權 | 「蒐集哪些資料」加上新資料，`CONSENT_VERSION` 升 2，所有人下次使用時再同意一次（照隱私權頁「資料改變會請您再同意」的承諾）。 |
| Q10 | 報告 | 資料匯出一定有、刪除帳號一起刪。列印的聽力報告加一行配戴資料（哪一耳、開始日期、等級），不印身障證明；分享報告不加。 |
| Q11 | 換新機的日子 | 九號表站對「用身障補助」且有配戴日期的人，加「YYYY/MM/DD 起可以再申請補助」（配戴日加 4 年；使用者都是成人，不算 12 歲以下的 2 年）。不改目前這一站。 |
| Q12 | 用語 | 助聽器與補助資料（GLOSSARY）；頁面標題「我的助聽器與補助」。 |
| Q13 | 固定入口 | 登入後「我的選配指引」在路線上方放一張摘要卡：已填的寫出來＋「修改」；都沒填時一句說明＋「去填」。 |

## 沒有另外問、照預設做的（本人確認共同理解時一併同意）

1. 每題第一個選項「不填」，選了就清掉答案。
2. 開始配戴日期不能是未來，跟聽力圖一樣。
3. 填了開始配戴日期就算「已戴助聽器」；原本「最新問卷有戴（含 IOI-HA）」也保留，任一成立就算。
4. 有證明時，身障鑑定站不標「估算未達門檻」、不放「看沒有身障證明時」；門檻儀表照舊顯示估算（ADR 0017）。
5. 證明「還沒有」在路線上跟沒填一樣。
6. 首頁「建議您下一步」：新情況（有證明停在九號表、二十五號表期間）照 [路線拷問](route-grill-decisions.md) Q14 推薦「看我的選配指引」；新的「因為」句在規格裡寫草稿，驗收時本人定稿。
7. 「我的助聽器與補助」是健康資料頁面：要登入、要同意、禁止快取。
8. 戴哪一耳：左耳／右耳／雙耳。
9. 沒登入時路線不變。

決策紀錄：[ADR 0020](../../adr/0020-route-uses-self-reported-aid-and-subsidy.md)；用語見 GLOSSARY「助聽器與補助資料」「目前這一站」。
