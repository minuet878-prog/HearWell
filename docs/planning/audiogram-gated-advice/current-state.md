# 助聽器建議依聽力圖顯示：現況盤點

日期：2026-11-17（還沒拷問，只是盤點）

本人提出：輕度、不到身障程度、甚至聽力正常的人，網站還是一律推助聽器選配。篩檢（問卷）結果不好，不等於有聽損。

## 已經依聽力圖判斷的地方

- 選配指引首頁（`guide/index.html:116-124`）：任一耳四頻平均 > 25 dB 才說「建議找聽力師評估選配」；兩耳都 ≤ 25 改說「如果仍覺得聽不清楚，建議安排聽力評估」（ADR 0017）。
- 照顧旅程（`care_journey.py:142`，ADR 0044）：聽力圖正常、而且還沒開始走路線，第 3、4 步標「目前不需要」。
- 補助四站預設收起，本人答有身障證明才展開，不看聽力圖（ADR 0063）。

## 要本人決定的事（拷問時一題一題問）

1. A：問卷結果頁的選配按鈕留給誰？全部拿掉改成「記錄聽力圖／去哪裡檢查」、只拿掉正常那級、或照舊。
2. B、C：審定過的建議原文要不要改掉「考慮配戴助聽器」「帶您走助聽器選配」？（ADR 0010：步驟只能改寫原文）
3. D：沒有聽力圖時，旅程第 3、4 步要顯示、隱藏，還是寫「記錄聽力圖後才知道需不需要」？
4. E：「開始走路線」要不要改成只算回答路線問題或填助聽器資料，看章節不算？
5. F：輕度聽損要不要跟中度以上分開說？例如門檻、措辭（「評估需不需要」vs「評估選配」），需要文獻依據（ADR 0017）。

碰到 ADR 0010、0017、0044，屬於建議與判斷規則，要先拷問、再寫規格。
