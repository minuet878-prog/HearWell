# 助聽器建議依聽力圖顯示：拷問決定

日期：2026-11-17（本人審定）。現況盤點見 [current-state.md](current-state.md)，決策摘要見 ADR 0067。

主線：篩檢（生活影響問卷）有問題代表可能有潛在問題 → 請本人去做聽力檢查 → 記錄聽力圖 → 依程度給合適的指引。問卷結果本身不推助聽器。

| # | 問題 | 決定 |
|---|---|---|
| Q1 | 聽力圖到什麼程度才建議評估選配 | 任一耳四頻平均 > 40 dB：建議評估選配。最差耳 26–40 dB（輕度）：要看生活影響問卷，達「輕度到中度影響」以上才建議；沒影響只建議定期追蹤。兩耳都 ≤ 25 dB：不建議（照現有「如果仍覺得聽不清楚，建議安排聽力評估」）。已戴助聽器的人不套這條。 |
| Q2 | 輕度但沒做過生活影響問卷 | 先請本人做問卷，做完再判斷。 |
| Q3 | 輕度看哪一筆問卷 | 最新一筆 HHIE-S 或 HHIA-S，不管日期；太舊的由半年重測提醒處理。 |
| Q4 | HHIE-S／HHIA-S 結果頁三級都有的「看助聽器選配與補助」連結 | 三級都拿掉。選配入口交給「建議下一步」卡，它已經照照顧旅程依聽力圖推。 |
| Q5 | HHIE-S 顯著影響「並考慮配戴助聽器」 | 刪掉這半句（建議原文與步驟都刪）；HHIE-S 三級也加上 HHIA-S 那句「不能單憑分數決定是否需要助聽器」的說明。 |
| Q6 | 訪客儲存卡輕中度、顯著影響「網站會一步步帶您走助聽器選配」 | 改成依聽力圖帶下一步，不提助聽器。 |
| Q7 | 輕度＋問卷切點的依據 | 林克寰《助聽器選配與驗證》書頁 40（沒有明顯障礙感受，難以說是合適候選人）＋問卷原作者分級（HHIE-S：Ventry & Weinstein 1983；HHIA-S：Newman 1990，0–8 分為無／極輕微影響）＋本人以聽力師身分審定。切點就是現有分級界線，不新增數字。書頁 86／168 的 0–24／25–40 分組是對照 IOI-HA 常模用的，不拿來當選配門檻。 |
| Q8 | 照顧旅程第 3、4 步 | 不建議評估選配的人（聽力圖正常、輕度但問卷沒影響）標「目前不需要」；還沒聽力圖、或輕度還沒問卷的人照舊標「之後」。不新增狀態。 |
| Q9 | 怎樣算本人自己開始走選配路線 | 看過章節不算；回答路線上的問題、或填了助聽器與補助資料才算。 |
| Q10 | 衛教入口（「了解」分頁的選配指引、沒登入首頁的連結、家人專區助聽器頁、問答小助手） | 不套，照留：那是每個人都能查的資訊，不是對個人的建議。不跟 #655 撞。 |
| Q11 | 新寫、改寫的字句 | 寫規格時代理擬稿，每句給 2–4 版讓本人點選，選定後寫進規格。 |

## 要改的字句（寫規格時擬稿）

- 選配指引首頁：> 40 dB、輕度有影響、輕度沒影響、輕度沒問卷四種情況。
- HHIE-S 顯著影響的建議原文與「接下來建議您」第一步。
- HHIE-S 三級加的說明句（可沿用 HHIA-S 原句）。
- 訪客儲存卡輕中度、顯著影響兩級。

## 連帶影響（不另外決定）

- 已經只靠「看過章節」走進路線、但新規則不建議評估選配的人，第 3、4 步會變回「目前不需要」。
- 判斷不存資料庫、每次即時算，改規則不會改寫歷史紀錄。
- 跟 #656 重測提醒（#661 在結果頁「半年後再做一次」旁加開關）改同一組結果頁步驟，規則不衝突，後合併的處理衝突。
