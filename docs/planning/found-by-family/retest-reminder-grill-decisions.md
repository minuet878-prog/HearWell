# 「讓家屬找得到」第 4 項：email 重測提醒　拷問決定（2026-11-16）

起點是[規劃](plan.md)的第 4 項；這裡記本人拷問時的決定，跟規劃不同的以這裡為準。

## 拷問前查到的事實

- 到期：上一筆生活影響問卷（HHIE-S 或 HHIA-S，取較新的一筆）的台北日期＋6 個月，不分級、不看配戴狀態；一個人只有一個到期，「再做一次」開同一份問卷（`main_flow.py`，ADR 0010、0030、0044）。THI、IOI-HA 不算重測提醒（ADR 0016）。
- 首頁「下次篩檢」與我的紀錄在到期時顯示「再做一次」；現在網站不主動寄任何提醒（`GLOSSARY.md`「重測提醒」）。
- email：密碼註冊必填、Google 帶已驗證的 email、LINE 選填（可能是空的）；同一個 email 可以在好幾個帳號；網站不驗證信箱；帳號設定只能看、不能改，要寫信請本人改。
- 寄信：只有重設密碼信（Resend，`noreply@tingpal.tw`，HTML＋純文字，寄不出去送 Sentry）。Resend 免費方案一天 100 封，超過直接拒寄；第 3 項的回饋通知信一天最多一封。
- 排程：VPS 每天 02:30 清提問紀錄（第 3 項的回饋清除併在這）、03:00 備份；Mac 每天 12:00 拉備份。都設 `Persistent=true`。
- 同意書第 8 版；升版後所有已登入的人打開網站會先被帶到同意頁。隱私權說明寫「網站不寄其他信」。
- 不用登入的連結：分享報告用 `secrets.token_urlsafe(32)` 存在資料庫；重設密碼用 Django 內建、無狀態的 token。
- ADR 最新到 0064（所有分支都查過）。

## 代理定的（本人確認）

- 誰會收到：開著提醒、有 email、帳號沒停用、不是管理員、有生活影響問卷紀錄的人。還沒做過生活影響問卷也能先打開，做完第一份後才有到期日。
- 同一次到期只寄一封：記下「這個帳號的哪一個到期日已寄過」，排程重跑、同一天跑兩次都看這筆紀錄。重做問卷後到期日變了，就是新的一次。
- 寄不出去：那一封送 Sentry（不帶 email），其他人照寄；隔天 09:00 再試，同一次到期最多試 3 天，之後放棄。Resend 回「今天額度用完」時，當天其餘的停下、隔天接著寄。
- 信的內容：主旨與內文由本人寫；程式帶入使用者名稱、「再做一次」連結（沒登入的話先登入、登入後直接開始那一份問卷）與取消連結。不寫分數、分級、問卷名稱以外的任何健康資料。HTML＋純文字兩份，版面照重設密碼信。寄件者 `noreply@tingpal.tw`，回覆到聯絡信箱。
- 取消連結：每個帳號一組猜不到的亂數代碼（跟分享報告一樣長），存在資料庫，跟帳號對應；只拿得到自己信裡那一組，改網址也取消不了別人。代碼打錯、帳號已刪除，一律顯示同一個「連結無效」頁；已經取消過的再按一次照樣顯示已取消。關掉再打開時換一組新代碼，舊信的連結失效。取消頁與已取消頁不收錄、不快取。
- 結果頁那一塊：已開啟的人顯示「✓ 已開啟，到期會寄到〈信箱〉」；沒有 email 的人顯示要先補 email、連到帳號設定；沒登入的訪客不顯示。沒有 JavaScript 也能用。
- 用語：`GLOSSARY.md` 新增「重測提醒信」，「重測提醒」的避免混用改掉「網站不主動寄出」。
- 隱私權說明：「為什麼蒐集」加「您打開重測提醒時，到期寄提醒信給您」；「網站不寄其他信」改寫；補 email 的說明。字由代理擬、本人改定。
- 先畫設計圖給本人挑：帳號設定的開關與補 email、結果頁那一塊、取消頁與已取消頁、信的版面。
- 必做交叉審查（不用登入的取消連結；規劃已寫）。由 Codex 審。
- 只有一份 ADR：0065（同意書不升版的第三個例外）。
- 實作等第 3 項（#633）合併回 `main` 之後才開工：兩項都改隱私權說明、都加 migration、都動 VPS 排程。規格現在寫。
