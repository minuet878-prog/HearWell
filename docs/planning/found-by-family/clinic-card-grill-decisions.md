# 「讓家屬找得到」第 6 項：診間 QR code 小卡　拷問決定（2026-11-16）

起點是[規劃](plan.md)的第 6 項；這裡記本人拷問時的決定，跟規劃不同的以這裡為準。

## 拷問前查到的事實

- 沒登入時首頁「開始篩檢」到 `/questionnaires`，先問一題年齡，65 歲以上進 HHIE-S、以下進 HHIA-S；已登入的人看到問卷目錄。
- 家人專區首頁是 `/family`。
- 匿名月計數是 `GuestMonth`（後台「訪客月計數」）：每月一列，有訪客完成和三格保存（帳號密碼、Google、LINE），不存 IP、帳號。
- `?from=card` 已經被訪客結果的保存卡用掉。
- 專案沒有產生 QR code 的套件。設定裡有固定的 `SITE_URL`（正式站是 `https://tingpal.tw`），Google、LINE 登入的回呼網址也是用它。
- `robots.txt` 不擋任何頁面（ADR 0062）。
- 「卡上要不要放姓名與單位」第 3 項 Q13 已經決定：只寫「執業聽力師」，第 6 項照這題。

## 代理定的（本人確認）

- 短網址的路徑由代理定，短、看不出用途也沒關係（例如 `/c/a`、`/c/f`），定了就寫進 ADR 0065，之後不能改。
- 轉頁只轉到程式裡寫死的兩個落點，不收任何參數，不會被拿來轉到站外。
- 兩格計數加在 `GuestMonth`，沿用 `count_guest`（資料庫裡直接加一，兩個人同時掃也都算到）；後台訪客月計數多兩欄。migration 只加欄位、不動既有資料。
- 第 5 項的「兩個門各被按幾次」之後也會加在同一張表；哪一項後做，就由它在後面加欄位。
- 隱私權說明不用改：計數只有月份和次數，不存 IP、帳號，也不在瀏覽器留記號；同意書不升版。
- QR code 用中等錯誤更正，印出來至少約 2.5 cm 見方，四周留白邊。
- 列印頁螢幕上寫列印要點（選 A4、實際大小 100%、不要「符合頁面」），印出來看不到；每張卡外框印淡淡的裁切線。印出的尺寸用 e2e 量一次。
- `SITE_URL` 沒設定時，列印頁在螢幕上寫明「沒有設定正式網址，印出來的 QR code 不能用」，QR code 不畫。
