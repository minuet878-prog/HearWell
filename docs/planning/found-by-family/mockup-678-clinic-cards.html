#678 設計圖：診間小卡

  • 卡片是實際大小（9×5.5 cm）；在電腦螢幕上看到的大小會跟紙上差一點，以下面「試印」為準。
  • 虛線底的字都是假字，只說明那一格放什麼、大約幾個字；真正的字由本人在 #679 寫。「不用註冊・免費」也只是位置，說法由本人定。
  • 每種排法都畫了長輩卡、家屬卡，各有彩色印與黑白印（灰階）兩個樣子。白底深色字，主色只用在 logo 與標題，不用大片底色。
  • QR code 是真的：長輩卡連 tingpal.tw/c/e、家屬卡連 tingpal.tw/c/f，連四周白邊約 2.7–3.1 cm 見方（黑白格子的部分約 2.0–2.3 cm，A 最小、B 最大）。#680 部署前掃了會看到聽伴的「找不到這一頁」，可以先用來確認掃不掃得到。
  • logo 在卡上畫成圖，不用網站頁首的背景色寫法：瀏覽器列印時預設不印背景色，用背景色的話 logo 會變成一片白。
  • 請挑：卡片排法 A／B／C（可以說「A，但標題像 C 那麼大」）；列印頁的樣子有沒有要改。

AQR code 在左

QR code 與網址一欄在左，右邊由上往下：logo、標題、掃了會看到什麼、不用註冊・免費。標題最多兩行、每行約 9 字（14pt），說明兩行、每行約 12 字（11pt）。最像一般名片，字的位置最多。

B標題橫跨上方

上面一整排是 logo 與標題（一行約 12 字），下面左邊是說明、不用註冊・免費、網址，右邊是 QR code。標題只有一行，要很短；好處是一眼先看到標題。

C大標題＋QR code 在右

左邊標題放大到 16pt（兩行、每行約 9 字），「不用註冊・免費」做成有框的一塊；右邊 QR code，下面一行「用手機相機掃」（虛線，要不要這行由本人在 #679 決定）和網址。字最大，但說明的位置最小。

P列印頁在螢幕上的樣子

不用登入，網站頁首、頁尾、底部分頁都不放。上方二選一切換卡種（會換網址，沒有 JavaScript 也能切），下面列印要點，再下面是整張 A4 的預覽。按瀏覽器的列印（電腦 Ctrl＋P／⌘＋P）印出來只有那張 A4，標題、切換、列印要點都不會印。

試印印一張看實際大小

這一頁按列印（A4、實際大小 100%、不要符合頁面）只會印出下面這張 A4：第 1–6 張是 A、B、C 的長輩卡與家屬卡（彩色），第 7–10 張是 A、B、C 的黑白樣子。印出來可以量量看是不是 9×5.5 cm、拿手機掃掃看。
