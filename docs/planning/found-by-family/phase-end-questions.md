# 「讓家屬找得到」階段結束時要回答的問題：去哪看、怎麼算

[規劃](plan.md)最後一段要的那一頁。四個問題各寫：去哪裡看、看哪一格、怎麼算、要注意什麼。
數字只有兩個地方：正式站後台的「訪客月計數」和 Google Search Console。

## 兩個地方怎麼打開

- **訪客月計數**：用管理員帳號登入 `https://tingpal.tw/admin/`，點「訪客月計數」（網址 `/admin/screening/guestmonth/`）。
  一個月一列，最新的月份在最上面；只有月份和次數，沒有帳號、IP、作答。
- **Search Console**：`https://search.google.com/search-console`，選 `tingpal.tw` 那個網域資源，
  左邊點「成效」（Performance）→「搜尋結果」（Search results）。驗證和 sitemap 在 2026-11-16 做完（#591，
  步驟見[部署參考](../../deployment/search-console.md)）。

## 每一格從哪天開始算

| 後台欄位 | 算的是什麼 | 從哪天開始有 |
|---|---|---|
| 訪客完成 | 沒登入的人做完 HHIE-S 或 HHIA-S（其他問卷要登入，不算） | #500，2026-11-13 |
| 保存（帳號密碼／Google／LINE） | 訪客的結果存進帳號，依那個帳號怎麼註冊的分三格 | #500、#513，2026-11-13 |
| 小卡：長輩卡／小卡：家屬卡 | 掃小卡打開 `/c/e`、`/c/f`，在瀏覽器真的開起來 | #680，2026-11-17 上線後 |
| 門：了解自己／門：擔心家人 | 沒登入首頁按下兩個門 | #672，2026-11-17 上線後 |
| 從傳給他打開 | 「傳給他」送出去的網址被打開 | #672，2026-11-17 上線後 |
| 寄出提醒信 | 重測提醒信寄出的封數（不是訪客的，放在同一張表） | #663，2026-11-17 上線後 |

「上線後」指那一版部署到 VPS 的那天；上線前的月份，那幾格都是 0。

## 1. 家屬是用哪些字找到聽伴的？

去哪看：Search Console「成效」→「搜尋結果」。

1. 上方日期選「過去 3 個月」（或自訂從 2026-11-16 起）。
2. 按「＋ 新增篩選器」（+ Add filter）→「網頁」（Page）→「網址包含」（URLs containing），填 `/family`，套用。
   這樣只看落在家人專區（包括第 5 項的三頁 `/family/signs`、`/family/loud-tv`、`/family/huh`）的搜尋。
3. 下面表格點「查詢」（Queries）分頁，依「點擊」（Clicks）排序。左邊那欄就是搜尋時打的字。
4. 想看某一頁的字：把篩選的網址改成那一頁的完整網址，例如 `https://tingpal.tw/family/loud-tv`。

怎麼解讀：

- Search Console 不會說搜尋的人是家屬還是長輩。可以看兩件事：落在家人專區的字，以及字裡有沒有「爸媽」「爸爸」「媽媽」「長輩」「家人」。
- 「曝光」（Impressions）是出現在搜尋結果裡的次數，「點擊」是真的點進來的次數。剛開始多半只有曝光、沒有點擊。

要注意：

- 很少人搜的字，Google 為了保護搜尋者會藏起來，不列在表格裡（上方的總點擊數會算進去，所以表格加起來會比總數少）。
  網站剛開始時，大部分的字可能都被藏起來，表格是空的不代表沒人搜。
- 數字大約晚 2–3 天才出現；最多保留 16 個月，想留久一點，每季從右上角「匯出」（Export）存一份。

## 2. 首頁兩個門，哪一個被按得多？

去哪看：訪客月計數的「門：了解自己」和「門：擔心家人」。

- 比同一個月的這兩格。想看比例：擔心家人 ÷（了解自己＋擔心家人）。
- 只算沒登入首頁上的按鈕；登入後的首頁沒有這兩個門。
- 按下就算一次，同一個人按兩次算兩次，所以是「按了幾次」，不是「幾個人」。

相關的一格：「從傳給他打開」是家屬把篩檢傳給長輩之後，長輩那一側打開的次數。

## 3. 從小卡進來的有多少？

去哪看：訪客月計數的「小卡：長輩卡」和「小卡：家屬卡」，兩格相加就是從小卡進來的總數。

- 掃了、在瀏覽器打開才算；同一頁重新整理、把網址再傳給別人都不會多算（打開後網址上的標記就拿掉了）。
  LINE 的連結預覽、搜尋引擎抓網址也不算。
- 是「打開幾次」，不是「幾個人」：同一個人隔天再掃一次會再算一次。
- 可以跟您發出去的張數比：發了幾張、各有幾次打開。

## 4. 訪客完成篩檢的次數有沒有增加？其中多少人保存？

去哪看：訪客月計數的「訪客完成」和三格「保存」。

- 有沒有增加：逐月比「訪客完成」。2026 年 11 月只算到 11/13 以後，比 12 月時要換成每天平均
  （11 月的數字 ÷ 18 天，12 月的 ÷ 31 天），或從 12 月起開始比整月。
- 多少人保存：保存（帳號密碼）＋保存（Google）＋保存（LINE），除以同一個月的訪客完成。
- 保存算在「存進帳號那天」的月份。訪客的結果在手機上留 7 天，月底做、下個月初才保存的，會算到下個月，
  所以月初、月底附近的比例會有一點誤差，看兩三個月一起比較準。
- 已經有帳號、登入後做問卷的人不算訪客，兩格都不會加。

## 四題共同要注意

- **您自己的測試也會算進去**：在正式站驗收、試掃小卡（#683）、試傳給他（#676）都會加一。測試時記下自己按了幾次，看數字時扣掉。
- 這些計數沒有擋次數（小卡拷問 Q15 的決定）：有人故意一直送，數字會變大但不會出事。某個月突然跳很多時，先懷疑這個。
- 計數靠網頁上的程式送出；瀏覽器關掉 JavaScript 的人不會被算到，人數很少。
- 建議等滿一個完整的月份再看第一次（例如 2027 年 1 月初看 12 月），前幾天的數字太少，看不出什麼。
