# 「讓家屬找得到」第 2 項：標題與描述建議表（草稿，等本人逐列確認）

- 「標題」是搜尋結果、瀏覽器分頁、LINE 預覽上的那一行；頁面上的大字標題不動（拷問 Q3）。
- 「描述」是搜尋結果標題底下、LINE 預覽標題底下的一兩句。
- 描述只用頁面上已經有的說法改寫，沒有加新的臨床內容。
- 狀態欄：空白＝還沒確認；本人確認後寫「可」，要改的直接改字。

## 下標的原則（[拷問決定](search-basics-grill-decisions.md)）

1. **標題照頁面內容下。** 家人專區的「助聽器」頁內容是故障排除、適應、怎麼戴、保養，沒有談怎麼挑，所以 B4 沒有寫「推薦」。
   第 4 句「有沒有推薦的助聽器？」由問答小助手的「哪個牌子的助聽器比較好？去哪家店買？」（D8）和選配指引的
   「助聽器的種類與價格」（C5）接（Q9）。
2. **第 5 句「助聽器是不是都很貴？」** 對到選配指引的「助聽器的種類與價格」（C5）；補助檢核、期限試算照各自的功能下標。
3. **首頁只寫「聽力自我篩檢」「回答問題」**，不用「檢測」「測驗」「測試」：首頁做的是問卷，不是聽力檢查（Q10）。
4. **「為什麼他一直說蛤」「看電視開很大聲」「怎麼知道爸媽聽力變差」** 是第 5 項的三個新頁面，這裡沒有用掉這些句子，
   留給那三頁。
