# 捲動輔助：拷問決定

日期：2026-10-24。本人在捲動效果比較頁選 A、B、K、N，拷問時加上「儀表條捲到時從 0 填滿」。動態規則見 ADR 0028；用語「儀表條」見 `GLOSSARY.md`。

## A 回到頂端按鈕

1. 範圍：全站都裝，往下捲超過兩個畫面高才出現，捲回這個高度以內就收起；短頁自然不會出現。
2. 外觀：右下角浮動膠囊，藍底白字「↑ 回到頂端」，高度至少 44 像素；手機上在底部分頁上方。
3. 點了之後：平滑捲回頂端（「減少動態效果」時直接跳），焦點移到頁面大標題（h1）。

## B 進場動畫捲到才播

4. 範圍：全部進場動畫（頁首聲波、首頁插圖與「開始」光圈、歡迎回來儀表、選配路線「目前這一站」光圈，加上新的儀表條）一律等進到畫面才播一次。
5. 觸發：整個進到畫面才播；比畫面還高的，佔滿畫面一半就播。

## 新增：儀表條從 0 填滿

6. 範圍：只有我的選配指引的儀表條（兩耳四頻平均、雙耳障礙比率）。結果頁分數位置條、SSQ12 位置條仍不動。
7. 動法：兩耳同時從 0 長到數值，約 1.2 秒，先快後慢、停住不回彈；雙耳障礙比率在另一個段落框，捲到那個框才自己播。

## K 跳到段落後框亮一下

8. 亮哪裡：目標所在的整個框（段落框、並列區塊、選配路線的一站）；不在框裡的目標就亮它自己。
9. 範圍：同一頁的連結和從別頁帶 # 跳來的都亮；「跳到主要內容」和表單錯誤摘要的跳題連結不亮。
10. 樣子：主色藍外框加淡藍光暈，停約 1.5 秒、再 1.5 秒淡掉；「減少動態效果」時直接出現、3 秒後直接消失。

## N 框內捲動的「還有內容」提示

11. 樣子：還沒捲到的那一邊有漸層陰影，捲到底就換邊或消失；框上方加一行「表格可以左右滑動」，只在真的放不下時出現。目前用在聽力圖比較的兩個數字表格，做成以後其他框內捲動也能用的共用樣式。

## 其他

12. 新增 ADR 0028；GLOSSARY 新增「儀表條」。

## 細節（本人已確認）

13. 回到頂端按鈕出現、收起用淡入淡出（「減少動態效果」時直接出現或消失）；頁面底部留出按鈕的高度，捲到最底時最後一行不被按鈕擋住；列印不顯示；沒有 JavaScript 時不出現。
14. 捲到才播的東西，還沒播之前顯示動畫的起始樣子（例如空的儀表條）；「減少動態效果」時一開始就是最後的樣子；沒有 JavaScript 時跟原本一樣一打開就播（寫規格時發現與 ADR 0006 衝突，本人改定）。
15. 框亮起來要等捲動停下、目標進到畫面才開始算 3 秒，不在平滑捲動途中就亮完。
16. 「還有內容」的陰影沒有 JavaScript 也有；那一行字要 JavaScript 判斷放不放得下，沒有 JavaScript 就不顯示。
