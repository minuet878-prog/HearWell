## 聽力圖看語言香蕉區（第一版）

### 入口

4. 獨立一頁，只有本人登入後看得到，從聽力圖頁的「接下來」卡片進入，看的是點進來的那一張。
5. 聽力圖完全沒有氣導標記時，不出現這張卡片。
6. 第一版不放分享報告，也不做「了解」頁的範例版。

### 依據

7. 語言香蕉區和注音位置用雅文基金會〈聽力圖和語言香蕉區〉海報。海報沒有數字，也沒有寫資料來源，數值從圖上讀出，本人已審定。
8. 上線前本人向雅文確認使用許可和資料來源。
9. 不等 Hung & Lin 2023 全文，也不用 Hu 等 2018 的注音位置。

### 畫面（F 案）

10. 聽力圖上畫語言香蕉區和六群注音。手機上字太小，每群排成一個框放在代表點旁，用細線連到代表點的圓點，圓點才是實際位置。
11. 切換右耳｜左耳時不換頁；打開時先顯示右耳，還沒選任何一群，提示「點圖上的注音」。
12. 這一耳不容易聽到的部分在香蕉區上畫斜線，不只靠顏色。超出最低或最高標記的地方不畫斜線。
13. 手指點圖上任何地方，就選最近的那一群，結果顯示在圖下。
14. 另外有「用清單選」，給鍵盤和報讀軟體使用。
15. 第一版只放注音，不放鳥叫、狗叫這類生活聲音，因為來源偏弱。

### 判斷規則

16. 六群的分法由代理提出、本人確認；每群一個代表點，用來判斷整群，本人已審定：

    | 群 | 注音 | 代表點 |
    |---|---|---|
    | 1 | ㄩㄧㄨ ㄝㄜㄛㄦ | 約 460 Hz、44 dB HL |
    | 2 | ㄚ ㄨㄛ ㄚㄜㄦ | 約 1200 Hz、46 dB HL |
    | 3 | ㄝㄩ ㄇㄖㄧ ㄋㄌ | 約 2400 Hz、48 dB HL |
    | 4 | ㄏㄅㄉㄍ ㄆㄎㄊ | 約 3300 Hz、44 dB HL |
    | 5 | ㄈㄐㄑ ㄓㄔㄒㄕ | 約 5500 Hz、39 dB HL |
    | 6 | ㄗㄙㄘ | 約 6600 Hz、35 dB HL |

17. 8 個母音在海報上各有兩個位置，所以分屬兩群。
18. 比較代表點和該頻率上的氣導聽力線，兩個標記之間用連線估計，兩耳各寫一句，不只看較好的那一耳：

    | 情況 | 寫法 |
    |---|---|
    | 代表點比聽力線大聲 | 可能聽得到 |
    | 代表點小於或等於聽力線 | 可能不容易聽到 |
    | 落在無反應點旁、聽力線斷開的地方 | 無法確定 |
    | 超出最低或最高標記 | 這個頻率沒有標記，無法估計 |

    只標 500–4000 Hz 的人，第 1、5、6 群會寫無法估計；本人看過這個情況，規則不改。

19. 不加 10–12 dB 邊際：跟海報畫法一致，聽力線以上就是聽不清楚或聽不到。

### 文字與下一步

20. 圖上的字跟著圖縮放；結果和清單照使用者字級放大。
21. 圖下固定一段提醒：這是估計、沒戴助聽器時的情況、聽得到不等於聽得清楚、不能取代聽力師判讀。每次的結果只寫兩耳的句子，保留「可能」。確切字句依 ADR 0013 列進規格，由本人審定。
22. 火警、煙霧警報不標在圖上、不判斷，只在頁面上用文字提醒：清醒時聽得到不等於睡著會被叫醒。確切字句列進規格，由本人審定。
23. 每一群可以配例字幫助理解，例字列進規格，由本人審定。
24. 不記錄使用者點了什麼；注音位置寫在程式裡，列入每年查核。
25. 頁尾：回聽力圖，加上現有條件的「看我的選配指引」卡。不依斜線多寡給建議。
