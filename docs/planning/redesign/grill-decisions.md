# 全站改版（照顧旅程首頁）拷問決定

[回功能規劃](../README.md)

- 日期：2026-11-12，本人逐題回答。
- 需求原文：使用者覺得 UI「不夠有設計感」：框太多、元素份量一樣、顏色太雜、缺少層級。本人在 Claude Design 選定方向：
  骨架是照顧旅程（首頁主角是下一步，不是分數）、乾淨白底、單一主色 #1f4e8c、少用框，長輩可讀性優先。
- 定稿圖：[首頁](mockup-home.png)、[紀錄](mockup-records.png)（第 2 階段）、[產品地圖](product-map.png)。共用元件：[#454 比較頁](mockup-454-components.html)（2026-11-12 本人照建議選 T1、E、S1、P3、L1、N3、W1）。
- 用語見 GLOSSARY：照顧旅程、空狀態首頁、現在這一步、目前不需要、建議下一步。決定見 ADR 0041–0043。正式規格：#453。

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 新設計規則套到多大範圍 | 全站一起改版（顏色和版面），取代 ADR 0022、0024、0025、0026。 |
| Q2 | 怎麼交付 | 功能分支 `feat/redesign`，每張票合進分支，全部驗收完一次合回 `main`。 |
| Q3 | 沒有定稿圖的頁面 | 先用一頁比較頁定共用元件（標題、區塊、清單、按鈕、可點卡片、提示框；含「白底上怎麼看出能點」），各頁照套。首頁、空狀態首頁、結果頁、聽力圖詳細頁另做個別比較頁。 |
| — | 設計圖 | 本人中途補充：每一頁正式改版前都先畫設計圖給本人看，只有一種做法也要。 |
| Q4 | 第 3 步和選配路線 | 第 3 步涵蓋選配路線「出發前」到「配戴之後」；填了開始配戴日期就完成。卡片只寫選配路線的目前這一站一件事，按鈕寫出去哪（例如「去填九號表」），不畫可勾的方框。 |
| Q5 | 聽力圖正常範圍 | 第 3、4 步寫「目前不需要」，現在這一步跳到第 5 步；本人開始走選配路線就恢復（跟路線的規則一致）。 |
| Q6 | 現在這一步怎麼找 | 由上往下第一個沒完成、也不是目前不需要的步；已戴助聽器的人從第 3 步算起，第 1、2 步沒完成就留著不打勾。 |
| Q7 | 第 1 步完成 | 只算生活影響問卷（HHIE-S、HHIA-S）。 |
| Q8 | 第 4 步 | 選配路線的目前這一站是二十五號表時，卡片寫它和期限；否則寫「再 N 天滿 3 個月」、沒有按鈕；滿 3 個月後按鈕是做效益問卷。開始配戴日之後做過 IOI-HA 就完成，提早做也算。 |
| Q9 | 用詞 | 照顧旅程用「步」，選配路線維持「站」。 |
| Q10 | 跟建議下一步的關係 | 建議下一步就是現在這一步；結果頁推同一件事。首頁的「您還可以」（印報告、分享、加到主畫面）移到旅程下方，改成一列文字連結。 |
| Q11 | 第 5 步做完 | 永遠不打勾，做完重測就從新日期再倒數 6 個月；進度最多到 4 / 5。 |
| Q12 | 重測到期但前面還有步沒完成 | 現在這一步不變；頂端「下次篩檢」格改寫「已到期」，附「再做一次」文字連結。 |
| Q13 | 下次篩檢那格 | 日期大字、「還有 N 天」小字，字級比上次結果的分數小一級。 |
| Q14 | 誰看空狀態首頁 | 問卷、聽力圖都沒有紀錄的人；只記過聽力圖的人看照顧旅程，上次結果那格寫還沒做。 |
| Q15 | 上次結果那格 | 只放最近一份生活影響問卷的分數與分級，整格可點進那次結果。 |
| Q16 | 底部分頁 | 維持「首頁｜篩檢｜紀錄｜了解」，只換樣子；日記等第 3 階段再談。 |
| Q17-1 | 底部分頁列外觀 | 半透明毛玻璃，往下捲隱藏、往上捲出現。保護措施：對比固定 ≥4.5:1；系統減少透明度時改實心、減少動態效果時不藏；捲到底或鍵盤焦點在分頁上時一定出現（ADR 0043）。 |
| Q17 | 結果頁與上次比較 | 同一份問卷的上一次，只寫數字變化（「上次 2026/03/26 是 10 分，這次少 4 分」），分級有變就寫出來，不寫進步或退步。只用在有總分的問卷，沒有上一次就不顯示。結果揭曉的動態照 ADR 0006：數字不往上跑。 |
| Q18–Q21 | 語音香蕉 | 作廢：開工時讀到落後的本機 `main`，以為還沒做。語言香蕉區已上線（#436、ADR 0040），這次只跟著全站換樣式，判斷規則不動（Q22）。 |
| Q23 | 改版期間的其他功能 | 暫停會動畫面的新功能，`main` 只修 bug；結果和圖表可以點、知識小測驗、聽損模擬排在改版後，直接用新元件做。 |

## 不在這次

紀錄頁便當格、聽力護照、家人模式（定稿圖右上的「我／爸爸」）、情境日記與「日記」分頁、保養、模擬器、噪音計、聽力師端、推播。

## 定稿圖要校正的地方（實作時照做）

- 日期寫年/月/日（ADR 0031），不是「9/26」。
- 內文至少 18px；定稿是 390 寬的 1 倍圖，站名約 16px，放大後版面會比圖長。
- 「之後的步」只淡化底色和圓圈，字的顏色不變淺（定稿實測 `#4a5460`，白底 7.6:1）。
- 第 3 步的待辦依 Q4 改成一件事加明確按鈕，不畫方框。
- 拿掉「我／爸爸」切換和「日記」分頁。
