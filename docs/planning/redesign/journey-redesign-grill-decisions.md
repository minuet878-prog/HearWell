# 照顧旅程展開改版拷問決定

[回功能規劃](../README.md)

- 日期：2026-11-21，本人逐題點選。
- 範圍：首頁照顧旅程每一步、每種狀態展開後的內容，以及跟著動到的選配路線、我的選配指引、待辦資料。
- 設計圖：畫布「聽伴首頁改版設計圖」最下面一排「照顧旅程展開」（本人 2026-11-20～21 逐張留言定稿）。
- 用語見 GLOSSARY：照顧旅程、現在這一步、目前不需要、不符資格、選配路線。決定見 ADR 0073–0075。

## 待辦與資料

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 待辦從哪裡拿掉 | 首頁照顧旅程和我的選配指引兩邊都拿掉（自動與手動待辦都不再顯示）。 |
| Q2 | 已勾的紀錄 | 刪除紀錄和資料表，下載我的資料也不再列。正式環境部署前先告訴本人影響幾筆。 |
| Q3 | 第幾台 | 只用來算待辦輪次，一起刪掉（換新機加一的規則也拿掉）。 |

## 旅程與選配路線的順序

| # | 題目 | 決定 |
|---|---|---|
| Q5 | 去找聽力師之前放哪 | 先了解助聽器，再去找聽力師（Q10 再細分位置）。 |
| Q10、Q11 | 步驟與站的順序 | 旅程 7 步：①填生活影響問卷 ②到醫院進行聽力檢查 ③記錄聽力圖 ④了解助聽器選配與補助 ⑤申請補助與配戴助聽器 ⑥戴滿 3 個月做效益問卷 ⑦半年後再篩檢。⑤的站依序：身障鑑定 → 九號表 → 等待核定公文 → 去找聽力師之前 → 配戴助聽器之後 → 二十五號表（等待補助發放首頁照舊不顯示）。我的選配指引的選配路線也照這個新順序。 |
| Q7 | ⑤叫什麼 | 申請補助與配戴助聽器。 |
| Q8 | 助聽器的種類與價格 | 只從首頁旅程拿掉；選配路線和章節照舊（看過就完成）。核定公文選「還沒收到」時連到這章，點開就算路線上這一站完成。首頁跟選配指引的「目前這一站」因此可能不同：指引停在種類與價格時，首頁顯示下一站。 |

## 各步怎麼算完成

| # | 題目 | 決定 |
|---|---|---|
| Q9 | ②到醫院進行聽力檢查 | 記了任何聽力圖（醫院或 AirPods）就跟③一起完成。 |
| Q6 | ④了解助聽器選配與補助 | 登入後打開過「我的選配指引」頁就完成（要開始記錄看過指引頁）。 |
| Q12 | ④的三種情況怎麼判斷 | 用現有兩個估算：選配建議為正常或追蹤＝聽力正常；建議評估選配但聽力圖估算未達身障門檻＝輕到中度；其他＝符合。估算只決定顯示哪一句，不自動收起補助站（ADR 0063 不變）。 |
| Q22 | 不符資格怎麼算 | 聽力正常：④⑤⑥都是目前不需要，④的狀態字寫「不符資格」，現在這一步直接到⑦。輕到中度：打開選配指引頁或「助聽器的種類與價格」章都算④完成。 |
| Q4 | 身障鑑定問答卡 | 三個大方塊，沿用既有三種答案：有→蓋章、往下一站；正在申請→出現「查詢鑑定醫院」；沒有→蓋章、補助站收起。 |
| Q13 | 答「是」之後 | 先蓋「已完成」章，下面「接著往下一站：ＸＸ →」連結，按了才換站；之後回首頁直接是下一站。九號表同樣。 |
| Q16 | 配戴助聽器之後 | 記下開始配戴的日期，而且做完第一次 IOI-HA，兩件都做才完成。 |
| Q15 | 第一次 IOI-HA | 配戴之後立刻可以填，「填問卷」小卡旁寫「建議先戴一週再寫」。IOI-HA 本來就是比較剛戴和戴一陣子的變化。 |
| Q14、Q17 | ⑥戴滿 3 個月 | 做第二次 IOI-HA，結果頁加「和上一次比較」：兩次總分並排＋每題變好、變差或一樣，照 HHI 前後比較的做法。IOI-HA 每題都是 5 分最好，所以分數高就是變好。 |

| # | 題目 | 決定 |
|---|---|---|
| Q18 | 配戴之後第一張小卡 | 「記錄配戴的效果」改成「記下開始配戴的日期」。 |
| Q19 | 印章顏色 | 朱紅 #b3261e。 |
| Q20 | 動畫 | 新增 ADR 放行蓋章與倒數圓環兩種：只播一次、不到 1 秒、減少動態效果時不動；其他仍照 ADR 0028。 |
| Q21 | 問答卡文字 | 身障三塊寫「有／正在申請／沒有」（存的值不變，指引章節的同一題一起改）；九號表「您的九號表完成了嗎？」是（已經完成）／否（還沒有）；公文「您收到核定公文了嗎？」是（已經收到）／否（還沒收到）；蓋章後「接著往下一站：ＸＸ →」。驗收時再調。 |

## 畫布上已定、照畫的部分

- 所有「要做的事」、打勾項、「⋯網站會知道」箭頭說明都拿掉。
- 已完成的步展開：朱紅「已完成」印章置中，有蓋章動畫。
- 可點的入口用白色小卡：淡藍圓底圖示＋字＋「›」，同一張卡片裡的多個選擇份量相同。
- ①已完成只剩印章。
- ②現在這一步：「查詢醫療院所」小卡。
- ③已完成：印章＋聽力圖結果小卡（左右耳程度標籤、平均 dB、看聽力圖）；還沒到：「記錄您在醫院做的聽力檢查或 AirPods 自我測試結果。」；現在這一步：小標「聽力圖來源」＋醫院檢查報告、AirPods 自我檢測兩張小卡；資料不足：說明＋修改這張聽力圖。
- ④已完成：印章＋「看助聽器選配與補助」小卡；還沒到：「統整助聽器補助流程供您參考。」＋同一張小卡；不符資格（聽力正常）：「您的聽力檢測結果為正常，但若有耳鳴、耳悶等其他症狀，仍建議尋求醫師協助。」；不符資格（輕到中度）：「您的聽力未達補助資格，但依舊可以考慮配戴助聽器。」＋「看助聽器的種類與價格」小卡。
- ⑤各站：身障鑑定與九號表用問答卡（Q4、Q13、Q21）；核定公文問答卡，收到→「記下核定的耳朵與等級」，還沒收到→「先了解助聽器種類與價格」；去找聽力師之前：只有「了解須知」按鈕（連到那一章）；配戴之後：「配戴一個月後才能做二十五號表，配合問卷使用更能知道助聽器的效果。」＋兩張同等小卡；二十五號表：月曆日期卡（幾月幾日起可以做，下面小字截止日）＋「看二十五號表要帶什麼」。
- ⑥還沒滿：小標「和上一次進行比較」＋倒數卡（圓環「還有 N 天」、大日期、「起可以再做一次」）；滿 3 個月：「做效益問卷」按鈕。
- ⑦還沒到、倒數中：倒數卡（還有 N 天、下次篩檢日期）；時間到了：「時間到了！」＋「再做一次（大約 3 分鐘）」；還沒做過：「還沒有完成第一次篩檢。」＋「去做問卷」。

規格預設（本人審規格時再看）：已戴助聽器的人從⑤的配戴之後算起，①～④沒做也不打勾；隱私權說明拿掉待辦打勾那一段（不再蒐集，不需要重新同意）；畫布上其他頁（首頁小鳥、紀錄圓點等）的動畫不在這次範圍。
