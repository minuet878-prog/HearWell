佩戴步驟怎麼「動起來」・比較頁

拿已審定的「耳掛（耳塞和細線）・戴上 4. 推進耳塞」那張線條圖（#503）做三種版本，圖本身一筆都沒改，只讓手指和耳塞動起來。手機寬 390px、字 18px。這頁沒有 JavaScript，只用 CSS 動畫；按鈕按了會重播。

請您決定的事

  • 選 A、B 或 C（我建議 B　按了才播，原因在各版本下面）。
  • 動作對不對：從外面往耳道推進去的方向、距離、手指捏的位置，會不會誤導長輩。
  • 選定後，我再列出 18 張裡哪幾張值得做成動畫（分左右、開機這類不用動）。

現況　審定的靜態圖（對照用）

  1. 4. 推進耳塞捏住細線靠近耳塞的地方，把耳塞輕輕推進耳道，細線貼著頭的側邊。

用箭頭表示方向。下面三個版本裡，手機設定「減少動態效果」的人都會看到這張。

A　自動播放

  1. 4. 推進耳塞捏住細線靠近耳塞的地方，把耳塞輕輕推進耳道，細線貼著頭的側邊。

做法：一滑到就播 2 次（共 4.8 秒）後停在戴好的樣子；按「再看一次」重播。播放時拿掉箭頭，動作本身就是方向。

好處：不用按就看到動作。

代價：一頁有好幾步都會動時，畫面一直在動，長輩容易分心、看不到字。控制在 5 秒內才不用另外做暫停鍵（無障礙標準 WCAG 2.2.2）。

B　按了才播建議

  1. 4. 推進耳塞捏住細線靠近耳塞的地方，把耳塞輕輕推進耳道，細線貼著頭的側邊。

做法：平常是審定的靜態圖；按「看動作」播 2 次、停在戴好的樣子。

好處：頁面安靜，想看的人才看；靜態圖照樣看得懂，動畫是加碼。一頁幾步都有動畫也不吵。

代價：多一顆按鈕，每步高約多 50px；不按的人看不到動作。

C　分格（不動）

  1. 4. 推進耳塞捏住細線靠近耳塞的地方，把耳塞輕輕推進耳道，細線貼著頭的側邊。

做法：拆成「捏住、對準」「推進去」兩格，像連環圖。

好處：不會動，最穩；可以印出來。

代價：每格只剩一半寬，耳朵和手指變小、細節看不清；一步兩張圖，頁面變長。比較像現況的改良，不是動畫。
