## 家人模式（T）

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 爸爸的資料屬於誰的帳號 | 各自帳號，長輩授權家人連結（不在子女帳號底下建家人、不只延長分享連結）。 |
| Q2 | 家人切到爸爸後能做什麼 | 看，並替他記事實：聽力圖、選配路線的回答、手動待辦。問卷只能本人填（本人沒選建議的「只能看」）。 |
| Q3 | 連結怎麼建立 | 長輩在帳號設定發邀請連結，子女登入自己的帳號接受。 |
| Q4 | 數量 | 多對多：長輩可連多位家人，家人可連多位長輩（切換列「我／爸爸／媽媽」）。 |
| Q5 | 稱呼 | 家人接受時自己取（爸爸、媽媽、阿公、阿嬤或自己打），之後可改。 |
| Q6 | 解除 | 雙方都能隨時解除，立刻生效；長輩在帳號設定看得到連著的每一位（帳號名稱、連上日期）。代記的資料留在長輩帳號。 |
| Q7 | 代記要不要標示 | 記下並顯示：聽力圖、待辦打勾各筆記記錄者，選配路線的回答記最後修改者；畫面寫「小明代記」，家人解除或刪帳號後寫「家人代記」。 |
| Q8 | 看得到的範圍 | 健康資料全看（照顧旅程、我的紀錄含逐題作答、聽力圖、我的選配指引、聽力報告）；帳號設定、同意書、產生分享連結、下載我的資料、刪除帳號、邀請家人只有本人。 |
| Q9 | 切換的範圍 | 整站切換，每頁頂端「正在看爸爸的資料｜切回我」；篩檢分頁寫「問卷要由爸爸自己填」並可切回；關瀏覽器或登出後回到「我」。 |
| Q10 | 同意 | 同意書不升版；隱私權說明加一段家人連結；長輩發邀請時在畫面上個別同意，記下同意時間。 |

規格預設（本人審規格時再看）：邀請連結 3 天內有效、只能用一次；沒帳號的子女先註冊再接受；家人模式下「給醫師看」可以開（陪診用），「分享給家人」不出現。

## 待辦打勾（O）

| # | 題目 | 決定 |
|---|---|---|
| Q11 | 待辦是什麼、誰來勾 | 混合：網站知道的自動打勾、不能手動取消；網站不知道的（例如預約聽力師）由本人或家人自己勾，存起來。 |
| Q12 | 手動勾會不會讓一步完成 | 不會。完成仍照 ADR 0044 與九站規則推算，手動待辦只是提醒。 |
| Q13 | 掛在哪一層 | 照顧旅程五步；第 3 步展開時顯示選配路線目前這一站的待辦，待辦寫在九站上，首頁與我的選配指引同一份。（本人說「照顧旅程每站」，詞彙表裡旅程是「步」、路線才是「站」，已對齊。） |
| Q14 | 什麼時候重來 | 勾錯可以取消；第 5 步做完下一次生活影響問卷後清空；換新機時第 3、4 步重來。舊紀錄保留並列入下載我的資料。 |

待辦字句（4 步＋9 站）由代理擬、本人審；首頁卡片上方框與按鈕怎麼排放進設計圖選（第 1 階段 Q4「只寫一件事」的部分推翻）。

## 便當格與聽力護照（K、Z）

| # | 題目 | 決定 |
|---|---|---|
| Q15 | 便當格跟現有清單的關係 | 便當格當「紀錄」分頁的入口頁，點格子進現有清單；「問卷｜聽力圖」二選一拿掉（取代 ADR 0019 該部分）。 |
| Q16 | 做哪幾格 | 四格：生活影響、聽力圖、助聽器、聽力護照。助聽器格只寫「戴了 N 天」（從開始配戴日算），還沒戴時寫選配路線目前這一站。日記格與「本週 5/7 天」等第 3 階段。 |
| Q17 | 其他問卷 | 生活影響格底下一行「另有耳鳴、助聽器效益 2 種問卷」，整格點進問卷紀錄；沒做過生活影響問卷時這格寫「還沒做」加那一行。 |
| Q18 | 護照跟聽力報告的關係 | 護照＝集章＋新的看診畫面（「給醫師看」）；完整聽力報告照舊。 |
| Q19 | 怎麼蓋章 | 每做一份問卷、記一張聽力圖、開始配戴，蓋一個寫了日期與種類的章；最後一格虛線是現在這一步。從既有紀錄推算，不新增資料表；章多時只露最近幾個。 |
| Q20 | 看診畫面放什麼 | 四項都放：最近一張聽力圖（縮圖、兩耳四頻平均與程度、日期、跟上一張差多少）、生活影響分數（分級、跟上次同配戴狀態的數字變化）、助聽器狀態（哪耳、開始日與天數、等級、補助、二十五號表期限；沒戴時寫目前這一站）、其他問卷一句摘要（THI、IOI-HA、SADL，做過才顯示）。 |

## 故事卡片（N）

| # | 題目 | 決定 |
|---|---|---|
| Q21 | 圖片還是連結 | 連結：沿用分享連結（7 天到期、可取消），家人打開先看到一張大字卡片，往下是完整報告。LINE 預覽不帶健康資料。 |
| Q22 | 卡片講什麼 | 一張，講這次這件事：從結果頁分享講這次問卷、從聽力圖分享講這張聽力圖、從護照或紀錄頁分享講最近一件事；附照顧旅程進度與一句「您可以怎麼幫」。分享連結要記從哪一筆分享。 |

| #479 待辦（自動待辦小字） | 2026-11-13 | 自審後改小字：自動待辦做完就是那一站完成的，沒打勾時寫「做完就會往下一站」；只是那一站部分條件的寫「做完會自動打勾」，目前只有「記下開始配戴的日期」（配戴之後還要回答補助才算完成）；第 4、5 步自己的自動待辦寫「做完這一步就完成」；打勾時的「已自動打勾」不變。每個自動待辦在待辦定義裡標明是不是完成條件。原因：一站的自動待辦多半就是那一站的完成條件，做完就往下一站，卡片上看不到打勾。上一列的原紀錄不改。 |

## 同意書升第 5 版（#478 自審後）

2026-11-13 本人決定：照顧旅程的待辦打勾開始存進帳號，同意書升到**第 5 版**，所有人下次使用時再同意一次；隱私權說明「蒐集哪些資料」與「先看重點」各補一句待辦打勾，刪除帳號頁也列出，日期改成 2026/11/13。原因：隱私權說明「說明改版」寫著蒐集的資料有改變就請大家再同意，待辦打勾連著帳號，不像匿名的提問紀錄；前例是選配路線開始存回答時升第 2 版（ADR 0020、0021）。推翻同一天先前「當小修、不升版」的做法。
