## ① 結果與紀錄

| 項目 | 題目 | 決定 |
|---|---|---|
| H2 | 標籤長什麼樣 | 只有字、不加箭頭：「比上次多 12 分」，中性深色，不用紅綠（ADR 0017）。 |
| H2 | 放哪裡 | 現在有「跟上次比」的兩處：結果頁的結果框、我的紀錄「最近一次」。原本那句留著當說明，標籤在它上面。比較規則不動（只跟同一種配戴狀態的上一筆比）。 |
| H3 | 「第幾次」怎麼算 | 同一份問卷各算各的，有戴、沒戴算在一起。訪客沒有紀錄，不顯示。 |
| H3 | 第一次寫什麼 | 也寫，只寫第 1 次，不加「半年後再做」（各問卷重做的時間不同）。 |
| H3 | 「上一次是 10 天前」 | 拿掉。日期交給結果框那句。 |
| H3 | 問卷怎麼稱呼 | 「這是您第 3 次做這份問卷。」標題就在正上方，不重複名字、不用英文縮寫。 |
| H4 | 「做第一份問卷」去哪 | 跟首頁第 1 步同一個去處：直接進生活影響問卷（照年齡），不知道年齡的人到問卷目錄。用首頁現成的那支判斷。 |
| H4 | 哪顆當主按鈕 | 「做第一份問卷」實心；「看／印聽力報告」降成清單列，跟「該再做一次」提醒出現時的做法一樣。 |
| H4 | 聽力圖那一頁 | 只補圖示和標題「還沒有聽力圖」，說明句留著，不加第二顆按鈕（上面本來就有實心的「記錄聽力圖」）。 |
| H4 | 做到哪幾頁 | 四頁：我的紀錄（問卷）、聽力圖、聽力報告、分享頁。後兩頁現在只有一行「還沒有可以放進報告的紀錄。」，按進去是死路。 |
| Q1 | 「上次」後面寫什麼 | 有分級的（HHIE-S、HHIA-S、THI）寫分級；SSQ12 寫平均、SADL 寫整體滿意度，跟我的紀錄每一列同一句；IOI-HA 只寫日期（它刻意不給總分，#409）。純文字、不上色。「上次」照現在：最近一筆，不分有沒有戴。 |
| R2 | 標在哪幾張圖 | 有趨勢圖的兩張都標（HHIE-S、THI）。只標日期，不寫「戴了之後變好」。 |

規格預設（本人審規格時再看）：

- H2 加了標籤後，下面那句縮成「上次 2026/09/01 是 0 分」，不重複講「多 12 分」；分數一樣時標籤寫「跟上次一樣」。
- H4 問卷那頁的字照設計圖：「還沒有紀錄」「做完第一份問卷，分數和變化會出現在這裡。」「做第一份問卷」；報告頁和分享頁的那一句由代理擬。
- R2 配戴日在第一筆紀錄之前或最後一筆之後時不畫線，只在圖下面寫一句；有好幾副助聽器時用最早的配戴日；圖下面的文字說明補一句給看不到圖的人。

## ② 填寫

| 項目 | 題目 | 決定 |
|---|---|---|
| J2 | 放哪幾個表單 | 三個填信箱的地方都放：註冊、用 LINE 註冊的選填信箱、忘記密碼寄信那一頁（打錯了畫面照樣說已寄出，人會空等）。 |
| J4 | 那一句怎麼寫 | 「今年滿 76 歲」。只知道出生年、不知道生日，這樣寫生日還沒到的人也不會覺得算錯。 |
| N3 | 鍵盤那顆鍵按了做什麼 | 中間的欄位寫「下一個」，按了跳到下一欄、不送出；最後一欄按了送出，跟現在一樣。最後一欄的字由手機決定（「前往」或「傳送」），不是盤點寫的「完成」。電腦上在中間欄按 Enter 也會變成跳下一欄。 |
| K1 | 大字那一行什麼時候出現 | 固定在圖上方一行，一直留著：還沒標時寫「點一下圖來標記」，標了就寫那一點（例：「右耳氣導　1000 Hz　45 dB」，有遮蔽、無反應也寫），拖的時候數字跟著變，放開才唸給螢幕閱讀器。 |
| K2 | 示範哪些動作 | 只示範「點一下，符號出現」，約 2 秒，按了才播、播一次就停。拖動和無反應留在文字說明。 |
| R1 | 提醒的規則 | 只比兩耳的氣導：某個頻率一耳有標、另一耳沒標就列出來，差一個也提醒。骨導不比。一耳完全沒標時不列頻率，照現在寫「還沒有標任何點」。只提醒、不擋存檔。 |
| Q2 | 安心話怎麼寫 | 「這不是考試，沒有對錯。答到一半離開，答案會留在這支手機，7 天內回來可以接著答。」不寫「照平常的感覺選」，怎麼回答交給量表原本的指導語。 |

規格預設（本人審規格時再看）：

- J2 比對用固定清單：gmail.com、yahoo.com.tw、yahoo.com、hotmail.com、outlook.com、icloud.com、msa.hinet.net；差一兩個字才問，按一下就改好，不擋送出，只在瀏覽器比對。
- J4 放在註冊、用 LINE／Google 取名稱三個表單，寫在綠勾旁邊。
- N3 做在所有有輸入框的表單（註冊、登入、取名稱、重設密碼、聽力圖日期等）。
- K2 的示範畫面裡，上方大字（K1）跟著寫出來，所以 K2 排在 K1 之後；動畫先畫設計圖給本人看。

## ③ 內容與聯絡

| 項目 | 題目 | 決定 |
|---|---|---|
| P2 | 每一筆長什麼樣 | 號碼本身可以按，前面加電話圖示，每一列至少 44px 高；不另外放「撥打」按鈕。分機不帶進撥號，另外寫「轉 211」。 |
