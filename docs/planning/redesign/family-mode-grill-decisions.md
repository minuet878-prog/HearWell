## 沿用 ADR 0046 的核心規則

- 各自帳號、多對多（長輩可連多位家人、家人可連多位長輩）、稱呼由家人自取並可修改、雙方皆可隨時解除且立刻生效。
- 問卷只能本人填（家人模式下「問卷」分頁提示由長輩本人作答並提供切回按鈕；API 嚴格禁止家人送出長輩問卷）。
- 代記標示「○○代記」，家人解除連結或刪帳號後資料保留在長輩帳號並改顯示「家人代記」。
- 帳號設定、同意書、產生分享連結、下載我的資料、刪除帳號、邀請其他家人皆限本人。
- 同意書維持不升版；隱私權說明新增「家人連結」一段，同意時間記在長輩每次發出邀請上。

## 寫規格時要記得

- 目前看誰記在伺服器 Session（不透過網址參數切換），登出、關閉瀏覽器或任一方解除連結立刻退回「我」。
- 聽力圖新增 `recorded_by`（與刪除帳號順序連動：`User.delete_with_data()` 刪除家人帳號時不能被 `PROTECT` 擋住，要清空 `recorded_by` 改顯示「家人代記」）。
- 全站健康資料 view 與 `/api/`（趨勢圖、聽力圖）改寫權限層，**合併前必做交叉審查**。
- 動工前先畫設計圖給本人挑選：頭像選單切換列、頂端「正在看○○的資料｜切回我」橫幅、帳號設定邀請與管理區塊、接受邀請頁。
