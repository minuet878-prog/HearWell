# 佩戴步驟動畫：審定紀錄（#520）

規格 #519，設計圖 [`mockup-520-wear-motion.html`](mockup-520-wear-motion.html)，比較頁 [`mockup-519-wear-motion-compare.html`](mockup-519-wear-motion-compare.html)。

## 本人的決定

- 比較頁三選一：選 **B 按了才播**（2026-11-13）。平常是 #503 審定的靜態圖，按「看動作」才播。
- 播幾次：**按一下播 1 次**，約 2.4 秒（2026-11-13）。照 ADR 0006、0028「使用者自己觸發、只播一次」。
- 做哪幾張：戴上 6 張＋拿下 6 張，共 12 張（2026-11-13）。分左右、開機、關機收好、耳內「對準耳道」不做。
- 拿下怎麼停（2026-11-13）：#503 審定的拿下圖大多畫「還戴著、箭頭指出去」，所以**拿下從審定圖開始、照箭頭拿出來、停在拿出來的位置**；這個停住的樣子是新的一格，在這次設計圖一起審。「拉出固定線」的審定圖畫的是已經拉出來，照戴上的做法，從塞好的樣子開始、停在審定圖。
- 12 張逐張審：**全部照設計圖**（2026-11-13，一批 4 張，三批都沒有要改的）。

## 共通的做法

- 線條一筆不改，只讓手指和零件動；連著零件的細線、導管、固定線只改跟零件相連的那一端（或整條換形狀），另一端不動。
- 一次約 2.4 秒：前 15% 停在起點，接著緩進緩出移動，最後停住。播放時和播完拿掉箭頭；叉叉（不要拉的地方）留在原地。
- 「減少動態效果」時不動、不出現按鈕，看到的是審定圖和箭頭。

## 審過的說明

| 代碼 | 本人審過的動作說明 |
|---|---|
| `behind_ear_mould_twist_in` | 耳模和兩根手指從耳朵前面一點的地方開始，耳模往後歪約 35 度。先推到耳道口，再順時針轉正、貼平。導管上端不動、下端跟著耳模。 |
| `behind_ear_mould_hook_on` | 耳模已經在耳朵裡不動。機身和手指從耳朵上方開始，以耳鉤尖端為軸往後下方轉約 30 度，停在耳朵後面；耳鉤到耳模那段導管不動。 |
| `behind_ear_mould_lift_off` | 從審定圖（機身在耳後）開始，機身和手指以耳鉤尖端為軸往上、往前轉約 30 度，停在耳朵上方。跟「機身掛到耳後」正好相反。 |
| `behind_ear_mould_twist_out` | 從審定圖開始，耳模和手指先逆時針轉約 35 度（往前歪），再往前拉出來約一個耳模寬。導管上端不動；導管上的叉叉留在原地。 |
| `behind_ear_dome_hook_on` | 耳塞和細線垂在耳垂旁不動。機身和手指從耳朵上方偏前開始，往後下方移、轉正，停在耳朵後面；細線上端跟著機身。 |
| `behind_ear_dome_push_in` | 已審過（2026-11-13，比較頁 B）。這版只改成播一次。 |
| `behind_ear_dome_tuck_line` | 耳塞已經在耳道裡。固定線從垂在耳垂下方開始，指尖從下面把它往上推進耳殼凹處。 |
| `behind_ear_dome_untuck_line` | 審定圖畫的是已經拉出來的樣子，所以照戴上的做法：從固定線塞在耳殼凹處開始（跟「塞好固定線」的審定圖一樣），指尖勾住往前下方拉出來，停在審定圖。 |
| `behind_ear_dome_pull_out` | 從審定圖開始，耳塞、固定線和手指一起往前拉出來約兩個耳塞長。細線靠耳塞那一端跟著走，上面那段不動；叉叉留在原地。 |
| `behind_ear_dome_lift_off` | 從審定圖開始，機身和手指往上、往前移到耳朵上方。跟「先掛機身」正好相反。 |
| `in_ear_twist_in` | 上面那隻手指先往後上方拉耳朵（一開始就拉）。機身和手指從耳道前下方開始、往後歪約 40 度，先推到耳道口，再順時針轉正。 |
| `in_ear_twist_out` | 從審定圖開始，機身和手指先逆時針轉約 40 度，再往前拉出來約一個機身寬。 |
