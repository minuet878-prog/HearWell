# 全站改版第 2 階段：看診畫面　拷問決定（2026-11-23）

- 起點：[第 2 階段拷問決定](phase-2-grill-decisions.md) Q18、Q20 與 [ADR 0078](../../adr/0078-records-page-without-bento-or-passport.md)（取消便當格與聽力護照後入口懸空）；本人逐輪點選定案。
- 用語見 `GLOSSARY.md`：**看診畫面**；正式決策見 [ADR 0081](../../adr/0081-doctor-view-entry-and-same-source-comparison.md)。

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 入口與「聽力報告」分工 | 「我的紀錄」問卷頁把「給醫師看（看診畫面）」當主按鈕（重測到期時主按鈕仍讓給重測提醒），看診畫面底部連到完整的「看／印聽力報告」。 |
| Q2 | 醫院「聽力檢查」vs「自我測試」 | 一律顯示日期最新的一張；若為「自我測試」明確標註「自我測試（非醫院檢查）」，且若有更早的醫院聽力檢查則附一行提示（日期與四頻平均）。與上一張的差值**只跟同來源**的上一張相比，不跨來源相減。 |
| Q3 | 其他問卷範圍與缺資料處理 | 依程式定義（ADR 0005）自動涵蓋所有做過的非生活影響問卷（SSQ12-TW、THI、IOI-HA、SADL）各一句摘要；沒資料的區塊直接省略，完全沒有任何問卷與聽力圖時才顯示空狀態引導。 |
| Q4 | 診間畫面外殼與互動 | 隱藏底部分頁列、保留左上返回鍵；頂端大字顯示年齡（有填出生年才有）與整理日期，不顯示帳號 email；聽力圖縮圖可點開前往詳細頁看完整各頻率數值。 |
| Q5 | 生活影響問卷與戴／沒戴比較 | 顯示最新一筆生活影響問卷（分數、分級、日期、配戴狀態與同狀態上次變化）；若該問卷已在聽力報告保留「配戴狀態比較」，順手多附一行「沒戴 X 分 → 有戴 Y 分」對照（未保留時不自動配對）。 |
| Q6 | 沒戴助聽器寫法與聽力圖分頁入口 | 已戴者顯示哪耳、開始日與戴了幾天、補助／等級、二十五號表狀態（若有）；未戴者僅在有填過補助／證明進度時顯示簡明事實，不寫給病人看的選配路線站名。「聽力圖」分頁維持「記錄聽力圖」為主按鈕，「給醫師看」放下方動作列。 |
| Q7 | 領域文件 | 更新 `GLOSSARY.md`「看診畫面」詞條，並新增 [ADR 0081](../../adr/0081-doctor-view-entry-and-same-source-comparison.md) 承接 ADR 0078。 |

## 寫規格時要記得

- 看診畫面屬**健康資料頁面**：必加 `@login_required` 與 `@health_data_page`（禁止快取、預設 `noindex`），所有查詢嚴格限定 `request.user`（未來家人模式再接共用授權對象）。
- 底部加一句免責聲明（自我篩檢與自行記錄，非醫療診斷），與聽力報告一致。
- 動工前先畫設計圖比較頁給本人挑選（390px 手機第一屏配置與 320px＋200% 字級檢查）。
- 不新增資料表、不動計分門檻或同意書版本。
