# 頁面改版拷問決定

[回功能規劃](../README.md)

- 日期：2026-11-21，本人逐題點選。
- 範圍：設計畫布「聽伴首頁改版設計圖」的 Pro 那一排：首頁（登入後、沒登入）、問卷、作答、結果、紀錄（趨勢圖 A）、了解、登入、帳號設定、往下捲的頁首。照顧旅程每一步的展開另見[照顧旅程展開改版拷問決定](journey-redesign-grill-decisions.md)，兩份合成同一份母規格。
- 設計稿和現在網站的逐頁差異：本次比對由代理整理，重點寫在下表「背景」欄。
- 用語見 GLOSSARY：問卷（分頁）、推薦問卷、紀錄。決定見 ADR 0076–0079。

## 全站共通

| # | 題目 | 決定 |
|---|---|---|
| P1 | 第二個分頁叫什麼 | 「篩檢」改「問卷」，跟頁面標題一致。 |
| P2 | 返回鍵 | 每一頁（含首頁、四個分頁第一層）往下捲後左上換成霧玻璃「‹」返回鍵，按了回瀏覽器上一頁；沒有上一頁（從外面直接打開）就回首頁。 |
| P5 | 小鳥對話 | 全站每頁最上面都是小鳥＋淡藍對話泡泡，泡泡裡一句引言加頁面標題。引言由代理擬、本人審。 |
| P6 | 藍色大卡 | 每頁最多一張深藍漸層大卡，放這頁最重要的一件事；卡裡的白色按鈕就是這頁的主按鈕，不再另加實心藍按鈕。ADR 0076。 |
| P7 | 動畫 | 只播一次的進場動畫都可以做（小鳥跳、光圈、標題擦字、數字往上跑、儀表與折線畫出來、圓點彈出、聲波跳、幫我選晃、區塊滑上來），條件見 ADR 0077。 |
| P8 | 頁首 | 左上小鳥 logo＋「聽伴」，拿掉聲波；右上圓形頭像（使用者名稱第一個字）點了到帳號設定，「目前登入」和「登出」拿掉，登出移到帳號設定最下面。沒登入時右上是「登入」框線按鈕。 |
| P9 | 分頁列 | 4 格（首頁、問卷、紀錄、了解）；選中的那格實心藍底白字，藍色膠囊滑到點的那格。之後做日記時再加第五格。 |
| P11 | 分級字 | 大字顯示的地方（結果頁、首頁小格、紀錄最近一次）用短的「輕到中度」等；報告、匯出、分享、讀螢幕的說明用完整的「輕度到中度影響」。 |

## 各頁

| # | 頁面 | 決定 |
|---|---|---|
| P12 | 首頁（登入後） | 小鳥對話「早安，帳號名稱」（依台灣時間早安／午安／晚安），名稱超過 8 個字只寫問候；拿掉「今天只要做一件事」。 |
| P13 | 首頁 | 「加到手機主畫面」保留在首頁（放最下面一小行）。 |
| P14 | 首頁（沒登入） | 有訪客結果時，「上次的結果」小卡放在藍色大卡上面。 |
| P15 | 首頁（沒登入） | 第三扇門「想了解助聽器」跟「自己」「家人」一起算每月點擊數；拿掉「我已經有帳號，登入」。 |
| P3、P4 | 問卷 | 最上面是可以左右滑的堆疊卡：推薦問卷排第一，後面接適合這個人的（依年齡、有沒有戴助聽器），最多 3 張；只有一份適合就一張、不能滑。下面保留全部問卷的清單（含耳鳴等其他問卷）。「幫我選」按鈕在小鳥對話裡。 |
| P10 | 作答 | 題目和選項一字不改（問卷原文），不標關鍵詞；版面（大白選項加勾、上一題／下一題並排、頁首題數與進度格）照畫布。 |
| P21 | 作答 | 左上「‹ 離開」一直顯示；「這份問卷在問什麼？」摺疊移到頁面下方；「已儲存」照舊最後淡出；「這不是考試，沒有對錯。」拿掉。 |
| P16 | 結果 | 版面照畫布（綠色「做完了」條、半圓儀表、和上一次比的兩條長條、藍色大卡建議下一步）；分享給家人、看紀錄與趨勢做成同樣的列，配戴比較、SSQ12 選填、重測提醒照現在的條件出現，放在列的下面。 |
| P17 | 紀錄 | 照畫布：最近一次區塊、分數趨勢（趨勢圖 A）、每次的紀錄；不做便當格和聽力護照。ADR 0078。 |
| P18 | 紀錄 | 趨勢圖橫軸寫「11/19」這種月／日，保留每次有沒有戴助聽器的形狀標記和開始配戴日。 |
| P22、P23 | 了解 | 跟問卷頁一樣：上面每一項各一張可以滑的卡（各有自己的動畫），下面清單。第一張依照顧旅程挑跟現在這一步最有關的；沒登入或沒有特別關聯時是聽損模擬。 |
| P19 | 帳號設定 | 版面照畫布（小鳥對話、頭像、列的樣式、登出在頁底）；內容照現在：保留出生年、重測提醒的定稿說明、各列副標、「還沒新增」、紅色的刪除帳號。 |
| P20 | 登入 | LINE、Google 按鈕維持官方字樣與樣式；其他照畫布（「歡迎回來。」在小鳥對話、欄位圖示、註冊區塊）。 |

## 從其他決定推出、不另外問的

- 首頁藍色大卡的「第 N 步，共 7 步」照照顧旅程七步（ADR 0074）。
- 問卷卡上 IOI-HA 的說明照照顧旅程 Q15：「戴上助聽器後可以填，建議先戴一週」，不寫「滿一個月」。
- HHIA-S 適用年齡照問卷定義寫「18–64 歲」。
- 拖曳換卡是使用者自己的動作，不受 ADR 0077 的「只播一次」限制；減少動態效果時卡片直接換、不滑。
