# 開放階段第 2、3 項：Google 登入、LINE 登入　拷問決定（2026-11-13）

起點是[規劃](plan.md)的第 2、3 項和[登入研究](login-research.md)；這裡記本人拷問時的決定，跟規劃不同的以這裡為準。

| # | 題目 | 決定 | 跟規劃不同 |
|---|---|---|---|
| Q1 | 做法 | 自己寫很薄的 OpenID Connect 用戶端，只服務 Google、LINE，不加套件；每一條安全檢查都要有「被竄改就失敗」的測試，並交叉審查 | |
| Q2 | Google 要拿什麼 | 代號（`sub`）＋email（範圍 `openid email`），不拿名稱與大頭貼 | |
| Q3 | Google 的 email 存不存 | 存進帳號的電子郵件欄，只收 Google 標示已驗證的；之後改了 Google 的 email，這邊不跟著變 | |
| Q4 | LINE 要拿什麼 | 只拿代號（範圍 `openid`），不拿名稱、大頭貼、email | |
| Q5 | 使用者名稱 | 第一次從 Google／LINE 回來後，先到一頁請他取使用者名稱（跟密碼註冊同一套規則），再看同意書；在這一頁離開就不建立帳號 | |
| Q6 | 出生年 | 放在 Q5 取名稱的那一頁，選填，跟密碼註冊頁一樣 | |
| Q7 | 只有 LINE 的帳號怎麼救回 | LINE 註冊的人在取名稱那頁多一個「電子郵件（選填）」，寫明 LINE 帳號不見時用來確認本人；#355 做好前由管理員核對。沒填的人救不回 | |

查到的事實：目前沒有任何功能寄信或要用 email（帳號設定已會顯示「未填」，匯出照樣帶 email 欄）；
會壞的是**刪除帳號要輸入密碼**，沒有密碼的帳號刪不掉（見 Q8）。

| # | 題目 | 決定 | 跟規劃不同 |
|---|---|---|---|
| Q8 | 沒有密碼的人刪帳號 | 有密碼的照舊輸入密碼；沒有密碼的按「用 LINE（或 Google）確認」再登入一次，對方證明是同一個人才刪 | |
| Q9 | 新增、移除登入方式要不要確認本人 | 都要，跟 Q8 共用同一個流程：動到登入方式或刪帳號，都先確認是本人 | |
| Q10 | 用語 | 帳號密碼、Google、LINE 統稱「登入方式」；在帳號設定「新增／移除 Google（LINE）登入」，不叫連結、綁定 | 規劃寫「連結」 |
| Q11 | 登入頁、註冊頁怎麼排 | LINE 在最上面，再來 Google，下面「或用帳號密碼」接現在的表單；LINE 內建瀏覽器裡不顯示 Google；按鈕照兩家官方規定，實作前先畫設計圖 | |
| Q12 | 同意書要不要升版 | 升一版，號碼實作時再定（第 5 版是待辦打勾、第 6 版預計情境日記）；跟別的升版同時上線就併成一版 | |
| Q13 | 月計數分不分登入方式 | 各種方式的新註冊數從帳號資料直接算，不另存；「後來保存」的月計數依保存那個帳號的註冊方式分三格（帳號密碼、Google、LINE），仍不記是哪一筆、不存 IP | 第 1 項只有一格 |
| Q14 | Google 品牌驗證 | 做，驗收前完成：本人先在 Search Console 驗證 `tingpal.tw`，Google 畫面顯示「聽伴」與 logo | |
| Q15 | LINE 存取權杖 | 拿到代號後馬上請 LINE 作廢；作廢失敗照樣讓他登入 | |
| Q16 | 管理員帳號 | 不能新增 Google／LINE 登入，只用帳號密碼 | |
| Q17 | Google 的 email 跟既有帳號相同 | 不合併、不登入那個帳號；畫面先請他用密碼登入再新增 Google 登入，下面次要選項「不是我的，建立新帳號」。同一個 email 可以有兩個帳號 | 規劃只給用密碼登入一條路 |
| Q18 | 從訪客結果頁按 Google／LINE，進的是既有帳號 | 跟第 1 項「登入既有帳號」同一套：寫出使用者名稱、先問要不要存，選「不要」就清掉；全新帳號才視為本人直接保存 | |

## 沒有另外問、照建議走的

- 拷問前不實機測，照最壞情況設計：LINE 內建瀏覽器裡不顯示 Google，放「用 Safari／Chrome 打開」；假設 LINE 跟外部瀏覽器資料不共用（見[規劃](plan.md)）。
- Google 用戶端等到要驗收時才建（閒置 6 個月會被刪）；LINE 的 Provider 建好就不換；LINE 頻道先把本人加為 Tester 驗收，確定後才切「已發布」（不能改回）。
- 取名稱那頁寫一行「已經有帳號了嗎？先用帳號密碼登入，再到帳號設定新增 LINE（Google）登入」，LINE 認不出既有帳號，只能靠這行提醒。
- 不在這次範圍：只用第三方註冊的人自己設密碼（帳號設定目前沒有改密碼功能）、改使用者名稱。
