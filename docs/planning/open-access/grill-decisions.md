# 開放階段第 1 項：免註冊先篩檢　拷問決定（2026-11-13）

起點是[規劃](plan.md)的第 1 項；這裡記本人拷問時的決定，跟規劃不同的以這裡為準。

| # | 題目 | 決定 | 跟規劃不同 |
|---|---|---|---|
| Q1 | 拷問範圍 | 只問第 1 項；第 2、3 項另派研究（[登入研究](login-research.md)），研究完再拷問 | |
| Q2 | 用語 | 「訪客結果」：沒登入做完、只在瀏覽器裡的那一次；「保存」：存進已同意的帳號 | 規劃寫「認領」 |
| Q3 | 月計數的「後來保存」 | 送出訪客結果時帶「來自訪客」標記，伺服器在送出當月的保存次數加一，不記是哪一筆 | |
| Q4 | 訪客入口 | 沒登入首頁的主要按鈕「開始篩檢」直接開始，不先註冊；次要連結「我已經有帳號，登入」；三步驟改成回答問題 → 看結果 → 想保存再註冊 | |
| Q5 | 開放哪些問卷 | 只開 HHIE-S、HHIA-S；推薦精靈只問年齡組別（18–64 歲／65 歲以上）。其他四份留給註冊後，是註冊的理由之一。一度改成六份全開，本人想到「全開就少了註冊的理由」後改回：註冊的好處是記得住、接得下去（與上次比較、重測提醒、聽力圖與選配路線、報告與分享）加上其他問卷，訪客結果頁要把這些寫清楚、不遮結果 | |
| Q6 | 留幾份訪客結果 | 每份問卷留最新一次（HHIE-S、HHIA-S 最多各一份）；註冊後一次保存全部 | |
| Q7 | IOI-HA 的常模組別 | 不用決定：IOI-HA 不開放給訪客 | |
| Q8 | 年齡組別帶進註冊 | 不帶（暫定，題目被打斷，本人可推翻）：保存的那一筆就決定之後推 HHIE-S 或 HHIA-S | |
| Q9 | 有戴／沒戴助聽器 | 照問，跟登入者一樣 | |
| Q10 | 保存後的紀錄日期 | 保存那天（照現在的規則，不信瀏覽器給的時間），最多比實際作答晚 7 天 | |
| Q11 | 訪客結果頁的建議下一步 | 分級的固定建議照舊；照顧旅程卡片的位置換成「註冊保存這次結果」的保存卡，好處依分級寫：無／極輕微影響寫半年後提醒再做、跟這次比；輕度到中度、顯著影響寫接著記聽力圖、一步步帶著走選配與補助；也寫註冊後還有耳鳴、吵雜環境等問卷。三段文案本人審 | |
| Q12 | 放棄註冊後回得去 | 瀏覽器裡有訪客結果時，沒登入首頁最上面多一塊「您有一份還沒保存的結果」（日期、分級、還留幾天），點了看結果 | |
| Q13 | 速率限制 | 「只算分」入口每個連線來源每小時 20 次，只存在伺服器記憶體裡；被擋時寫「剛才做了很多次，請過一小時再試。您的作答沒有不見。」 | |
| Q14 | 同意書版本 | 不升版；訪客作答頁上方一行「沒註冊時只計算、不儲存」加隱私權說明連結 | |
| Q15 | 什麼時候先問再保存 | 只有從保存卡出發的註冊或登入，同意後直接保存；其他入口的註冊、登入都先問「要把這次結果存到這個帳號嗎？」，選「不要」就清掉 | 規劃寫「新註冊不問」只限從訪客結果頁出發，這裡把其他入口的新註冊也改成要問 |
| Q16 | 清除這次結果 | 只清這一份，先確認一次「清除後就找不回來了，確定嗎？」；清完回沒登入首頁，返回鍵看不到 | |
| Q17 | 沒登入的底部分頁 | 不加「篩檢」，維持首頁｜了解｜登入｜註冊 | |

## 沿用規劃、沒有另外問的

- 訪客結果只在瀏覽器裡，伺服器的「只算分」入口照問卷定義回傳分數與分級，不寫資料庫；`Submission` 一律在 `Consent` 之後才建立。
- 保存沿用原本的寫入 API 與同一個收據編號，成功後清掉瀏覽器裡那一份；訪客結果用自己的儲存鍵，不跟作答草稿共用。
- 訪客結果留 7 天，從做完那一刻算；訪客結果頁算健康資料頁面，禁止快取，`test_standards.py` 要涵蓋這個不用登入的頁面。
- 「訪客完成」= 「只算分」入口成功回傳一次；月計數不存明細、不存 IP。
- 訪客結果頁不顯示「與上次比較」、報告與分享（訪客沒有紀錄）。
- 隱私權說明補上「未註冊時只計算、不儲存，作答留在您的瀏覽器」。

## 寫規格時要記得

- 動畫面前先做設計圖給本人選：沒登入首頁（主要按鈕、三步驟、還沒保存的結果）、訪客結果頁與保存卡、「要把這次結果存到這個帳號嗎？」。
- diff 會碰到計分入口與登入後的保存，要做交叉審查。
- 程式等 #478 合併後才開工（首頁同一個 `index.html`、migration 撞號）。#478 那邊的 ADR 0054 已經用掉同意書第 5 版，這次不升版，不受影響。
- 第 2、3 項的認領要接上這裡：LINE 內建瀏覽器跳到外部瀏覽器後讀不讀得到訪客結果，見[登入研究](login-research.md)，拷問第 2、3 項時處理。
