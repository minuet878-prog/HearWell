# 匯入 Apple 聽力測試：拷問決定

日期：2026-11-17（本人審定）。決策摘要見 [ADR 0068](../../adr/0068-self-tests-are-audiograms-not-for-disability.md)。

主線：本人用 AirPods 在 iPhone 上做的聽力測試，從「健康」app 輸出 PDF，上傳到聽伴自動讀成一張聽力圖。網頁讀不到 HealthKit（Apple 只開放給原生 app），所以只能走 PDF。

## 試驗結果（2026-11-17，只有本人一份樣本）

- 「健康」→ 瀏覽 → 聽力 → 聽力測試結果 → 選一次測試 → 輸出 PDF。第 1 頁是聽力圖，第 2 頁是說明與歷年趨勢。
- 數值是真的文字，不是圖片：每耳 8 點（250、500、1k、2k、3k、4k、6k、8k Hz），精確到 1 dB，每個數字旁可能有 `*`（背景噪音可能干擾）。
- 右耳紅字、左耳藍字；兩條折線各 8 個點，x 位置符合對數頻率軸，可以拿來把數字對到頻率，y 位置可以交叉驗證數字。
- 用 Mac 的 PDFKit 座標會亂掉；pdfplumber（底層 pdfminer.six）座標正確。
- 文字用了 CJK 部首相容字（例如「⼒」不是「力」），比對中文前要先做 NFKC 正規化。
- 讀出的值跟肉眼讀圖完全一致，四頻平均跟 PDF 上的摘要一致（Apple 四捨五入到整數）。
- 還沒驗證：英文介面、有聽損、聽不到的頻率怎麼標、舊版 iOS、Apple 改版。

## 決定

| # | 問題 | 決定 |
|---|---|---|
| Q1 | 匯入的結果算不算聽力圖 | 算聽力圖，多記來源。所有用到聽力圖的地方都看得到，個別地方再決定要不要排除。 |
| Q2 | Apple 精確到 1 dB，聽伴只收 5 的倍數 | PDF 匯入的照原值存 1 dB。 |
| Q3 | 低於 -10 的值 | PDF 匯入的下限放到 -20，照存。 |
| Q4 | 身障鑑定估算 | 自我測試不估算，那一塊改說要到醫院做聽力檢查。 |
| Q5 | 有舊的聽力檢查、又有新的自我測試 | 鑑定估算用最新一張聽力檢查，句子寫明是哪一天的檢查。 |
| Q6 | 建議評估選配、目前不需要（ADR 0067） | 兩個都照用最新一張聽力圖，不管來源。 |
| Q7 | 照顧旅程第 2 步、選配路線第 1 站 | 只有自我測試也算已完成。 |
| Q8 | 讀完直接存還是先確認 | 先顯示讀出的聽力圖、數值和測試日期，提醒跟 PDF 對一下，按「存下來」才存。 |
| Q9 | 匯入的能不能修改 | 不能，只能刪掉重匯。 |
| Q10 | 同一份 PDF 傳兩次 | 同一人、PDF 匯入、同一天、數值全同就擋下，連到已有的那張。 |
| Q11 | 星號、背景噪音、鼻塞、噪音暴露 | 都不存。預覽頁在有星號、鼻塞或噪音暴露「是」時各說一句。 |
| Q12 | 隱私權說明與同意書 | PDF 只在記憶體裡讀，讀完就丟。隱私權說明加上「從 Apple 聽力測試 PDF 匯入的聽力圖，PDF 讀完就丟、不保存」，更新日期；同意書不升版（同 ADR 0065 的理由：資料類別沒變，只多一種輸入方式）。 |
| Q13 | 用家人的 iPhone 測，PDF 印的是家人的名字 | 預覽頁大字寫「要存進〇〇的紀錄」（聽伴帳號的名稱），提醒 PDF 上印的是 iPhone 主人的名字、不一定是受測的人。不自動比對。 |
| Q14 | 讀不出來 | 說「這份 PDF 讀不出來」並連到手動輸入；後台只記每月各種失敗原因的次數，不存 PDF 和內容。 |
| Q15 | 手動輸入 App 結果會繞過 Q4 | 來源切成「聽力檢查／自我測試」。手動輸入時先問是在醫院診所檢查，還是自己用手機或耳機測；PDF 匯入自動算自我測試。 |
| Q16 | 已存在的聽力圖 | 全部當聽力檢查；手動輸入的在「修改」裡可以改來源。這是會動資料的 migration，要交叉審查。 |
| Q17 | 畫面上怎麼區分 | 聽力圖清單、詳細頁、看診畫面、分享報告、聽力護照、下載資料都標「自我測試」；我的聽力趨勢同一條線，自我測試的點樣子不同。樣子做設計圖給本人選。 |
| Q18 | 入口與教學 | 「記錄聽力圖」分「自己標」和「從 iPhone 匯入」；匯入頁上面是編號步驟（健康 → 瀏覽 → 聽力 → 聽力測試結果 → 輸出 PDF → 儲存到檔案），每步配自己畫的手機畫面示意圖，下面是選檔按鈕。先做設計圖。 |
| Q19 | 讀 PDF 的套件 | pdfminer.six。 |
| Q20 | 其他預設 | 見下。 |

## Q20 預設（本人同意）

1. 只支援繁體中文介面的 PDF，其他語言有樣本再加。
2. 測試日期用 PDF 上的測試日（不是輸出日），時間不存。
3. 檔案上限 2 MB、只讀第 1 頁。
4. 要登入才能匯入；連結的家人可以替本人匯入。
5. 平均和程度用聽伴自己的算法，不用 Apple 的「幾乎沒有受損」。
6. 手動輸入的自我測試照舊每格 5 dB、從 -10 起、可修改；1 dB、-20 起、不能修改只限 PDF 匯入。
7. 讀不出來的原因只記每月各種原因的次數，跟問答小助手的月統計一樣。
8. 寫一份 ADR（0068）。

## 寫規格前要做

- 設計圖：匯入頁（步驟＋示意圖＋選檔）、預覽確認頁、自我測試在清單／詳細頁／趨勢圖的標示、手動輸入時問來源。
- 示意圖先找現成的衛教圖參考畫法。
- 新寫的字句（鑑定那一塊、預覽頁的提醒、讀不出來）寫規格時擬稿給本人點選。
