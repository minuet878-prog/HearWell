## 一、助聽器怪怪的（#433）

題目：現在是什麼狀況？（選了才看到說明，不打分、可改選。）

選項順序把要就醫的放第一個，避免家人先花時間檢查助聽器。 **【補】**

### 耳朵痛、流膿或突然聽不到

**不用先檢查助聽器，請盡快到耳鼻喉科就醫。** 連結：什麼時候要馬上就醫（`/family#urgent-title`）

### 沒聲音或變小聲

**如果是幾小時到幾天內突然聽不到或聽力變差，不用先檢查，請盡快到耳鼻喉科就醫。**（Q22）

可以先檢查：
- 有沒有戴好、有沒有開機；有音量鍵的話，音量是不是太小。
- 電池有沒有裝對方向、貼紙撕了沒。不確定就換一顆新的；充電式的看有沒有充飽。 **【補：充電式】**
- 耳模或耳塞有沒有被耳垢或水氣堵住，導管有沒有折到或堵住。

該回去找聽力師：
- 檢查完還是沒聲音，或聲音變形。
- 聽力慢慢變差，助聽器需要調整。（Q22）

連結：什麼時候要馬上就醫

### 一直嘯叫

可以先檢查：
- 有沒有戴好，耳朵和助聽器之間有沒有縫。
- 帽子、圍巾或耳機有沒有蓋到助聽器。
- 耳模或耳塞有沒有太鬆或破損，導管有沒有裂開。
- 有音量鍵的話，可以先暫時調小。

該回去找聽力師：
- 檢查完還是一直叫，或耳模已經鬆了。
- 耳朵裡可能有很多耳垢：不要自己挖，請耳鼻喉科或聽力師看看。 **【補：來源寫 GP，改成耳鼻喉科或聽力師】**

### 太吵或聲音太大

可以先檢查：
- 是不是剛開始戴。前幾週可能覺得環境很吵、自己的聲音怪怪的，要時間適應。
- 有音量鍵的話，音量是不是太大。

該回去找聽力師：
- 太吵、太小聲或不舒服，都可以請聽力師調整，不用勉強忍耐。
- 助聽器沒辦法把想聽和不想聽的聲音完全分開。記下哪些場合最困擾，回診時告訴聽力師。

### 有嗡嗡聲

可以先檢查：
- 關機再開機，回到平常的設定。可能是不小心切到感應線圈（T）的設定。

該回去找聽力師：
- 開關機之後還有雜音，或聲音變形。
- 拿下助聽器還是聽得到，可能不是助聽器的問題，請問耳鼻喉科或聽力師。 **【補：本人的臨床判斷，Q22】**

### 戴起來會磨、會緊

**如果是耳朵痛或流膿，請選第一項。**（Q22）

可以先檢查：
- 有沒有戴對位置、左右耳有沒有戴反。 **【補：左右耳】**

該回去找聽力師：
- 戴對了還是不舒服。耳模或耳塞通常可以調整，不用硬撐。

## 二、陪長輩適應（#434）

題目：他現在是哪個階段？

### 剛開始戴

您可以做的事：
- 告訴他前幾週覺得自己的聲音怪、環境很吵是常見的，大腦需要時間適應。
- 照聽力師的建議，陪他從安靜的地方、短時間開始，再慢慢拉長。
- 回診時一起學怎麼戴上、拿下、清潔和換電池，回家才幫得上忙。

### 戴了不習慣

您可以做的事：
- 一起記下哪些場合聽不清楚、哪裡不舒服，回診時告訴聽力師。
- 陪他回去調整。適應可能要好幾個月，設定也可能要調整不只一次。
- 在吵雜的餐廳、多人聊天時還是可能聽不清楚，說話的方法依然有用。連結：怎麼跟聽損的家人說話

### 不想再戴

**如果是耳朵痛或流膿，請盡快就醫。** 連結：什麼時候要馬上就醫（Q22）

您可以做的事：
- 先問他是哪裡不舒服：聲音、耳朵、操作，還是覺得沒有幫助。 **【補】**
- 告訴他這些都可以回去請聽力師調整，不用勉強忍耐。
- 他不想談的時候，可以看「長輩不肯去怎麼說」。連結：`/family/reluctant`

段落最下面，一直看得到：想記錄戴起來的效果，可以做配戴效果問卷（要先註冊或登入）。連結：配戴效果問卷

## 三、日常保養（#435）

題目：他的助聽器是哪一種？

- 掛在耳後
- 戴在耳內

每一步有文字、線條圖和勾選框。頁面上寫：勾選不會留下，換外型也會清掉。（Q21）圖見 [batch-3-drawings.html](batch-3-drawings.html)。

### 掛在耳後

1. **擦乾淨（每天）**：拿下來後，用乾的軟布或面紙擦機身和耳模或耳塞。不要弄濕，也不要用含酒精或化學成分的濕紙巾。
2. **清耳垢（每天）**：用聽力師給的工具，清掉耳模或耳塞出口的耳垢，不要硬戳。耳塞裡有濾網的，濾網有耳垢就換新。
3. **看導管（每天）**：導管有沒有折到、堵住或裂開，裡面有沒有水氣。處理不來就問聽力師。 **【補：每天，來源沒有寫頻率】**
4. **洗耳模（有耳模的，約一週一次）**：把導管從助聽器的掛鉤拔下來，導管不要從耳模拔出。耳模泡溫肥皂水洗乾淨，沖乾淨後把導管裡的水吹出來，放到隔天全乾再裝回去。機身不能碰水。
5. **關機收好（每天）**：不戴的時候關機，放進盒子，遠離高溫和潮濕，也放在小孩和寵物拿不到的地方。充電式的照說明書充電。 **【補：充電式】**

### 戴在耳內

1. **刷開口（每天）**：一天結束時，用聽力師給的軟刷，刷掉開口上的耳垢和碎屑。
2. **挑耳垢（刷不掉時）**：刷不掉的，用挑耳垢的工具輕輕挑，不要硬戳。
3. **擦乾淨（每天）**：用乾淨的乾布或面紙全部擦過。不要弄濕。
4. **關機收好（每天）**：不戴的時候關機，放進盒子，遠離高溫和潮濕，也放在小孩和寵物拿不到的地方。充電式的照說明書充電。

深耳道型這種放在耳道很深處的，由聽力師在回診時清潔。

### 兩種都適用的提醒

- 戴著助聽器時不要噴髮膠或用其他美髮產品。
- 沒電的電池馬上換；電池放在小孩和寵物拿不到的地方。
