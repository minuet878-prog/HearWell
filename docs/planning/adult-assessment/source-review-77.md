### HHIA-S：向書籍作者確認，必要時請其指引中譯權利人

採用對象：《助聽器選配與驗證》書內第 165 頁的十題 HHIA-S 中譯。

1. 這份中譯的翻譯者、原始來源及建議引用格式為何？是否有可公開引用的中文驗證研究？
2. 可否保留原題目、題序、答案標籤與 4／2／0 計分，在 HearWell 公開網站逐題呈現，供使用者自行填答？
3. 可否保存逐題回答與計分結果、由本人列印，以及由本人分享給家屬閱讀？列印或分享包含題目文字時，是否有額外條件？
4. 是否需保留特定聲明、版權標示或版面？如需另取得同意，應向誰確認、涵蓋哪些用途？
5. 網站將結果描述為生活影響，不宣稱該中譯已在台灣完成信效度驗證；是否有建議一併列示的適用限制？

### SSQ12-TW：向婦聯聽覺健康基金會確認

採用對象：基金會聽覺評估工具箱連結的 SSQ12-TW 短版；不是 SSQ12-B。

1. 可否在 HearWell 公開網站保留原題目、題序與各題尺規，供成人自行填答？若需另洽翻譯者或權利人，請提供確認方向。
2. 可否保存逐題回答與結果、由本人列印，並由本人分享給家屬閱讀？應使用何種引用、聲明及浮水印呈現方式？
3. 網站預計以 0–10 整數、每次增減 1 分輸入，保留不適用且不預設作答；這種電子介面是否可採用，有無既定要求？
4. 原表說明的「完全做不到選 1」與 0 分尺規不一致。網站擬將通用說明調整為「完全不行選 0」，保留各題原有錨點及原始 PDF；是否可採用？
5. 網站擬僅在十二題皆有數值時呈現整體平均，任一題不適用則只保留逐題結果；此為本專案審定規則。是否有應優先遵循的 TW 版正式計分說明？如有，請提供來源供核對，不直接變更現有決定。
6. 若提供給 65 歲以上成人自行填答，有無應標示的適用限制或其他研究？目前網站不宣稱已有高齡或電子施測等效驗證，也不設定效益及格線。
