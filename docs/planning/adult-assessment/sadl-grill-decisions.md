## 預設（2026-10-22 本人確認照此）

1. **上線開關**：定義檔可以是「做好但不在目錄」；上線時由一個程式改動（新 PR）打開，不做 admin 開關。上線前精靈與目錄都不顯示，網址直接打開是 404。寫規格時補充：只有本機開發環境（DEBUG）看得到，供本人驗收；正式站一律 404。
2. **選項顯示**：只顯示中文標籤（一點都沒有、一點點、有一些、中等程度、相當程度、非常多、極度），不顯示 A–G 字母。
3. **計分**：存本人選的原始選項（1–7），計分時把第 2、4、7、13 題反向；子量表＝該子量表題目平均；整體＝作答題目平均（排除「不適用」）；顯示到小數一位。
4. **版權標註**：作答頁與結果頁底部標「© University of Memphis, 1999；中文版：Fang 等，2013（國泰綜合醫院）」。

## 寫規格時要提的技術陷阱

- 結果類型不能沿用 `AVERAGE`：聽力報告與匯出用 `result == AVERAGE` 挑 SSQ12（`screening/views.py:494`、`:654` 附近），SADL 歸成 `AVERAGE` 會被混進 SSQ12 的段落。
- SADL 不是生活影響問卷：2b 的重測提醒（#159）與推薦依據要照現在的做法寫死 HHIE-S／HHIA-S 代碼。
