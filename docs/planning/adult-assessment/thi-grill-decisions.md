# THI 拷問決定（第三批問卷）

日期：2026-10-22。ADR 0015（用醫院版本、不等書面同意）、0016（耳鳴問卷不算生活影響問卷）。下一步：寫規格（`/mattpocock-skills:to-spec`）。

## 範圍

| # | 決定 |
|---|---|
| Q1 | 這批只做 **THI**（耳鳴障礙量表）；COSI 先不排，留在 roadmap 構想 |
| Q2 | THI 不算生活影響問卷，自成「耳鳴問卷」：首頁「上次結果」和重測提醒照舊優先看生活影響問卷，THI 不觸發也不改變重測提醒 |
| Q3 | 精靈不加步驟；結果頁對每個人多列一行「如果您有耳鳴：耳鳴障礙量表（THI）」；問卷目錄也放。目錄卡片與結果頁都寫明有耳鳴的人才需要做 |
| Q4 | 作答時問「您現在有沒有配戴助聽器？」，只當背景資料存進配戴狀態；不做配戴狀態比較 |
| Q5 | 結果只顯示總分與分級，不顯示三個分量表（醫院表單沒有中文版的題號對照） |
| Q6 | 重度、極重度的建議一定附 1925 安心專線；另外第 5（絕望）、11（憂鬱）、23（無法忍受）題任一題答「經常」，不論總分都在分級下方顯示溫和的支持訊息與 1925；不用紅色警告樣式，文字本人定稿 |
| Q7 | 五級的建議與「接下來建議您」由代理依耳鳴常見處置寫初稿，另開一張等本人定稿的票；實作先用初稿 |
| Q8 | 我的紀錄有 THI 分頁與趨勢圖；「和上一次比」直接跟前一筆比、不管配戴狀態；兩筆配戴狀態不同時加一行說明（例如「上次沒戴、這次有戴助聽器」） |
| Q9 | 聽力報告加一區 THI（總分、分級、最近幾筆與配戴狀態），分享給家人的報告同樣有；Q6 的支持訊息與逐題作答不放進報告 |
| Q10 | THI 結果頁「接下來建議您」最後一步寫「3 個月後，或開始新的處置（例如配戴助聽器）3 個月後再做一次」；首頁不加 THI 的提醒 |
| Q11 | 目錄卡片「耳鳴對生活的影響（THI）」（和其他問卷一樣只放代碼；全名「耳鳴障礙量表」放作答頁）；對象「給有耳鳴的人，不限年齡。」；約 5 分鐘；沿用耳朵圖示；排在目錄最後；選項照醫院表單「經常／偶爾／不會」；作答頁說明「請依您最近一個月的耳鳴情況回答。」 |
| Q12 | 每題必答、沒有「不適用」；題目逐字照醫院表單（第 22 題也照原文），問號用全形；作答頁沿用 React 一頁一題 |
| Q13 | 分級顏色（ADR 0007 的三色）比照聽力圖：無或輕微→綠；輕度、中度→橘；重度、極重度→紅。不新增顏色 |
| Q14 | 聽力報告的 THI 區塊照 HHIE-S 放分級建議（重度、極重度含 1925）；逐題觸發的支持訊息不放 |

## 版本與授權

- 用本人醫院現用的中文版：黃啟原修訂，李恆惠信度考驗（總分與三個分量表相關 .73～.79）。完整書目不追。
- 本人決定不處理授權，不照 ADR 0011 等書面同意。
- 題目 25 題、經常 4／偶爾 2／不會 0、總分 0–100；分級 0–16 無或輕微、18–36 輕度、38–56 中度、58–76 重度、78–100 極重度。題目逐字見下方「題目」。

## 題目

1. 您是否覺得耳鳴無法控制？
2. 耳鳴的聲音大到讓您聽不清楚別人的談話？
3. 耳鳴會使您感到憤怒？
4. 您會認為您的耳鳴是一種可怕的疾病嗎？
5. 您會因為耳鳴而感到絕望？
6. 耳鳴會使您經常感到疲勞？
7. 您會因為耳鳴而晚上無法入睡嗎？
8. 您是否覺得無法擺脫耳鳴？
9. 耳鳴是否已干擾到您的正常社交活動？（例如出去用餐或看電影）
10. 您會因為耳鳴感到挫折嗎？
11. 您會因為耳鳴而感到憂鬱？
12. 耳鳴會使您感到不安嗎？
13. 耳鳴會干擾您的工作或家務嗎？
14. 您會因為耳鳴而經常情緒不穩定嗎？
15. 您會因為耳鳴而閱讀（書報）困難嗎？
16. 您會因為耳鳴而無法專心嗎？
17. 耳鳴會對於您和家人及朋友的關係帶來壓力嗎？
18. 您是否不容易把注意力從耳鳴轉移至別的事務？
19. 您對您的耳鳴會抱怨連連？
20. 耳鳴會使您感到困擾？
21. 受到壓力時，您的耳鳴會變得更嚴重？
22. 耳鳴會使您心情不好嗎？
23. 您是否覺得已無法忍受耳鳴了？
24. 耳鳴會使您感到焦慮嗎？
25. 耳鳴會使您無法享受人生嗎？
