## 依賴關係

1. **來源定稿**｜阻擋：無｜交付：本人確認兩份問卷的正式文字、來源與電子化使用條件。
2. **HHIA-S 完整作答**｜阻擋：1｜交付：從目錄填十題、查看分級及建議，再從歷史找回。
3. **SSQ12-TW 完整作答**｜阻擋：1｜交付：0–10／不適用作答、整體平均或原因、逐題結果及紀錄列表。
4. **年齡與目的推薦**｜阻擋：2、3｜交付：依帳號出生年直接推薦，必要時補問，已配戴者可依目的選問卷。
5. **IOI-HA 固定常模依據**｜阻擋：2｜交付：兩份 HHI 擇最新有效未配戴紀錄；無依據仍能填，歷史不回溯改寫。
6. **兩份 HHI 的手選比較**｜阻擋：2｜交付：各自手選、保留、更換或移除比較，原始紀錄保持。
7. **SSQ12 比較**｜阻擋：3、6｜交付：逐題對照及符合條件的平均差值，與兩份 HHI 同時各留一組。
8. **本人／家屬整合報告**｜阻擋：4、5、7｜交付：三區報告、三組比較、列印、最新分享及整條流程驗證。

- 1 完成後，可開始 2、3。
- 2 完成後，可開始 5、6。
- 2、3 完成後，可開始 4。
- 3、6 完成後，可開始 7。
- 4、5、7 完成後，可開始 8。

8 同時交付整合報告及從推薦到分享的端對端驗證，因此依賴 4；這個依賴來自本票包含的完整操作驗收，而不是報告計分必須先有推薦頁。整份第一批交付仍須八張全部完成並通過人工驗收。這是依賴關係，不是要求平行派工。

來源票保留母規格目前「來源定稿後才開始正式問卷實作」的前提。查證可以由代理協助，涉及聯繫與採用條件仍由本人處理或審定；本拆票不授權寄信。不把沒有回覆視為可以使用，也不要求必須取得整篇論文才能定稿。

### 1. Finalize adult questionnaire sources and usage conditions

**標題：確認第一批問卷版本、使用條件與正式文字**

**Blocked by：**無，可先進行來源整理與人工確認。

**預計標籤：**`ready-for-human`，不是交由代理自行判定可用。

**交付：**將選定的 HHIA-S 中譯及 SSQ12-TW 整理成可直接核對的正式輸入，讓後續票不再猜題目、使用條件或對外說明。

- [ ] Given 已選書內 HHIA-S 中譯與基金會 SSQ12-TW，When 完成核對，Then 逐題文字、題序、答案標籤、尺規方向與引用方式均有可查證來源及本人確認紀錄。
- [ ] Given 已確認的網站使用情境，When 檢查使用條件，Then 涵蓋公開電子填答、保存、列印、家屬分享、整數輸入與網站 0 分說明調整；若有不相容條件，回報本人決定，不自行換譯本或改計分。
- [ ] Given TW 研究摘要的樣本年齡與現有證據限制，When 定稿對外說明，Then 不宣稱已完成高齡或電子施測等效驗證，不將產品審定規則說成已讀過全文的官方規則。
- [ ] Given 來源及條件已確認，When 本人審定開工資料，Then 留下兩份問卷可採用版本與條件的明確結論；既有計分決定不重新訪談。

### 2. Add the HHIA-S answering and results flow

**標題：成人可完成 HHIA-S 並查看結果與紀錄**

**Blocked by：**1。

**交付：**使用者可從問卷目錄進入 HHIA-S，完成十題、看到生活影響分級與行動建議，之後可找回紀錄。

- [ ] Given 定稿中譯，When 選擇 HHIA-S，Then 新增獨立問卷版本，不改既有上線題目、fixture 或 HHIE-S 門檻；適用提醒不阻擋本人延續原問卷。
- [ ] Given 選定配戴狀態，When 完成十題，Then 以 4／2／0 加總；漏答、重複／錯誤題目或不合法值不存入不完整紀錄，重送不產生重複紀錄。
- [ ] Given 總分 0／8、10／24、26／40，When 查看結果，Then 分別呈現已審定的三段標籤、行動建議及共通說明；十題均填有時為 20 分。
- [ ] Given 完成作答，When 透過結果、歷史或既有問卷 API 讀取，Then 得到一致的後端計分、日期、狀態及逐題回答；沒有他人的資料。
- [ ] Given 本人資料匯出或刪除帳號，When 執行操作，Then 新作答納入既有完整流程；鍵盤、焦點、錯誤提示及 JS 未接手時的表單可完成作答。

### 3. Add the SSQ12-TW answering and results flow

**標題：成人可完成 SSQ12-TW 並查看能力紀錄**

**Blocked by：**1。不依賴 2；兩者使用不同計分規則。

**交付：**使用者可從目錄完成 SSQ12-TW，看到整體平均或不能計算的原因，並從列表找回逐題回答。

- [ ] Given 未選答案，When 顯示分數尺及增減按鈕，Then 不把預設位置當回答；每題接受 0–10 整數或明確的不適用，步距 1，漏答不能完成。
- [ ] Given 本人選擇未配戴或配戴狀態，When 作答，Then 保存實際狀態，依目前生活經驗回答；經驗不足可先不填，不強制兩種狀態都完成，也不將補填稱為配戴前測。
- [ ] Given 十二題均有數值，When 計分，Then 相加除以十二、顯示小數一位；任一題或全部不適用仍可完成，但不計整體平均，不適用不當 0、不補分。
- [ ] Given 定稿原表，When 呈現題目，Then 各題錨點及網站 0 分說明正確，第 9、12 題不額外反向計分；不新增分項分數、風險分級、效益及格線或長期趨勢圖。
- [ ] Given 總和 75／76，When 顯示平均，Then 分別為 6.3／6.3；數值 0、不適用及漏答在保存、草稿恢復、後端驗證、結果與 API 中不混淆。
- [ ] Given 既有 HHIE-S、HHIA-S 或 IOI-HA，When 新增 SSQ12 的計分及不適用支持，Then 原有答案限制與結果不變；新紀錄的歷史、匯出、帳號刪除、本人資料隔離與無障礙一併驗證。

### 4. Guide adults to questionnaires by age and purpose

**標題：依出生年直接推薦，並依配戴情況與目的引導**

**Blocked by：**2、3。推薦的問卷須已有可完成的作答流程。

**交付：**使用者一進入就看到適齡生活影響問卷，已配戴者也能依目的找到問卷，保留自行選擇入口。

- [ ] Given 有出生年且當年減出生年不等於 65，When 進入，Then 直接推薦 18–64 歲 HHIA-S／65 歲以上 HHIE-S，不重問年齡；未填或差值恰為 65 才確認實際區間。
- [ ] Given 已配戴助聽器，When 選擇了解幫助／目前聆聽能力／生活影響，Then 分別進入 IOI-HA／SSQ12／適齡 HHI；不強迫回到年齡推薦才能選其他目的。
- [ ] Given 尚未配戴者完成 HHI，When 查看後續操作，Then 可選填 SSQ12，也可直接查看紀錄，不強制兩份都填。
- [ ] Given 從目錄選非年齡推薦的 HHI，When 作答，Then 提醒適用對象但不阻擋；中文用途優先、代碼附後，維持已確認原型的易懂用詞。
- [ ] Given 鍵盤、上一頁、字級放大及手機畫面，When 走完推薦到作答流程，Then 焦點、導覽與可讀性符合既有無障礙要求，不把原型測試設定放進正式流程。

### 5. Extend IOI-HA norm selection to both HHI questionnaires

**標題：IOI-HA 使用兩份 HHI 的最新有效紀錄並固定依據**

**Blocked by：**2。不依賴 3、4 或手選報告比較。

**交付：**已配戴者填 IOI-HA 前可知道常模依據；缺少依據仍能完成，歷史判讀不被後來資料改寫。

- [ ] Given 有本人完整十題且每題 0／2／4 的未配戴 HHIA-S／HHIE-S，When 準備填 IOI-HA，Then 從兩份問卷取最新有效紀錄，顯示問卷、日期、分數；不因年齡跨過 65 而排除先前 HHIA-S。
- [ ] Given 分數 0／24 或 26／40，When 分組，Then 使用既有兩組對應常模，不改常模數值，不將組別當聽損程度。
- [ ] Given 無有效依據，When 完成 IOI-HA，Then 顯示逐題回答與缺少依據說明，不比較常模或產生低於常模解讀。
- [ ] Given 已完成 IOI-HA，When 新增 HHI、跨過 65 歲或更換報告比較，Then 該筆原分組與依據不變；既有已上線紀錄不回溯分組。
- [ ] Given 本人／他人紀錄及帳號刪除流程，When 查閱或處理固定依據，Then 資料隔離及完整刪除仍正確；既有 IOI-HA 作答路徑維持可用，不額外 React 化或擴增寫入 API。

### 6. Let adults keep one HHI comparison per questionnaire

**標題：HHIA-S／HHIE-S 可手選、保留與管理各自的比較**

**Blocked by：**2。不依賴 SSQ12 或引導頁。

**交付：**本人從紀錄選同一版本的一筆未配戴與一筆配戴結果，比較後可保存，日後回來仍是原選的紀錄；兩份 HHI 各保留一組。

- [ ] Given 本人的兩筆同版本 HHI 紀錄且狀態各一，When 比較，Then 列出日期、狀態及原分數，不將 HHIA-S 與 HHIE-S 混成同一組，不以最新兩筆自動替換。
- [ ] Given 已保留 HHIA-S 及 HHIE-S 比較，When 重新登入、更換或移除其中一組，Then 選擇持續保存，其他組及原始作答不變；不因新增紀錄換組。
- [ ] Given 比較頁及原有結果／歷史中的配戴差異，When 顯示，Then 清楚區分目前查看的兩筆、報告保留組合及真正前測，消除本次流程內與手選規則衝突的自動配對，不擴大重構無關趨勢圖。
- [ ] Given 使用他人的紀錄、跨版本、相同狀態或未記錄狀態，When 嘗試保留，Then 拒絕不合法組合，未保留狀態也能正確呈現。
- [ ] Given 新增報告比較資料，When 匯出、刪除帳號或透過畫面／必要的 API 操作，Then 納入本人資料保護與完整處理；鍵盤與錯誤焦點可用。

### 7. Extend saved comparisons to SSQ12-TW

**標題：SSQ12 可保留逐題比較與整體平均差異**

**Blocked by：**3、6。沿用 6 已交付的報告比較保存與管理行為。

**交付：**SSQ12 也有獨立的一組比較，能與兩份 HHI 同時保留，呈現逐題回答及符合條件的整體差值。

- [ ] Given 同版本 SSQ12 的未配戴／配戴紀錄，When 比較，Then 顯示十二題回答與不適用標記，不拿不適用當 0。
- [ ] Given 兩筆均有完整平均，When 計算差值，Then 以配戴減未配戴，使用未四捨五入的平均計算後才顯示小數一位；總和 52 與 56 的差值為 +0.3，不是 +0.4。
- [ ] Given 任一筆含不適用，When 查看，Then 保留逐題對照、不算整體差值，不抽共同題目重算，不標示臨床顯著改善或效益合格，也不稱為 SSQ12-B。
- [ ] Given 三份問卷均有報告比較，When 更換或移除 SSQ12 組合，Then 兩份 HHI 的選擇保持，IOI-HA 依據亦不變；新增紀錄不換組。
- [ ] Given 跨版本、他人資料、匯出／刪除及無障礙操作，When 延伸至 SSQ12，Then 6 的保護與操作條件同樣適用。

### 8. Integrate adult assessment results into personal and family reports

**標題：本人、列印與家屬報告整合新問卷及三組比較**

**Blocked by：**4、5、7。2、3、6 已由上述依賴涵蓋，不重複列邊；4 是本票完整推薦至報告驗證的前置條件。

**交付：**回診或家屬查看的同一份報告，能分區閱讀新問卷、三組比較與 IOI-HA 成效，最新結果與本人保留的組合不混淆。

- [ ] Given 本人有新問卷及已保留比較，When 開啟本人、列印或家屬報告，Then 依生活影響／日常聆聽能力／助聽器使用成效分區，不合成健康總分；三組各顯示原日期、狀態與獨立結果。
- [ ] Given 新增更晚的作答，When 看報告，Then 最新結果更新，已保留比較不換組；IOI-HA 仍使用其完成時固定的依據。
- [ ] Given 既有未到期且未取消的分享連結，When 本人新增 HHIA-S／SSQ12，Then 家屬看到最新整合內容；建立連結前清楚說明分享面向與已選比較。
- [ ] Given 分享隱藏身分、到期、取消及不快取設定，When 查看新報告，Then 全部繼續適用；家屬只能閱讀，不能更換比較或存取本人管理功能。
- [ ] Given 手機、字級放大、鍵盤／螢幕閱讀器及列印，When 閱讀三組比較與逐題資料，Then 資訊不只靠顏色，不撐寬整頁，收合及列印內容可讀；完成涵蓋推薦、作答、保留比較、本人／家屬報告的端對端驗證。
