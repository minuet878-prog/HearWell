## 實作時注意

- 「沒註冊」的錯誤放在信箱欄位下面（欄位變紅框、輸入留著）；「試太多次」「信寄不出去」放在上面的紅底框，跟登入頁「使用者名稱或密碼錯誤」同一個樣子。
- 設新密碼頁的欄位名稱用 Django 中文版現成的「新密碼」「新密碼確認」；密碼規則和「顯示」按鈕照註冊頁；錯誤字句也用 Django 的（例如「這個密碼只包含數字。」）。
- 「密碼改好了」用網站現有的訊息列，出現在首頁（或還沒同意新版的人的同意頁）上面。
- 連結失效頁用時鐘圖示，不用紅色驚嘆號。
- 信的按鈕下面附完整網址；純文字版的網址自己一行。
- 分頁列在這幾頁停在「登入」。
