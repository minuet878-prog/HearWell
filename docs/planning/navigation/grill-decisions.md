# 導覽 A 案拷問決定

[回功能規劃](../README.md)

- 日期：2026-10-23，本人逐題回答。
- 需求原文：以目前的功能，網站會不會太擁擠？之後還有不少功能想加。
- 本人在導覽分組比較頁（手機 390px，100% 與 200% 字級）選定 A 案：聽力圖併進「我的紀錄」，空出「了解」分頁。決定與代價見 ADR 0019。
- 用語見 GLOSSARY：紀錄、了解。正式規格：#268。
- 寫規格時補上的一點：只有直接打開我的紀錄（底部分頁或其他連結）時，才依 Q2 轉到聽力圖；二選一的「問卷」一定停在問卷這邊，否則只有聽力圖的人永遠看不到問卷那邊。

| # | 題目 | 決定 |
|---|---|---|
| Q1 | 聽力圖在「我的紀錄」怎麼擺 | 上方加一排「問卷｜聽力圖」二選一，下面才是原本的問卷分頁。不併進問卷分頁列（最多變 7 個長名稱）。 |
| Q2 | 二選一預設 | 「問卷」；沒有問卷、只有聽力圖時停在「聽力圖」。兩種都沒有就維持現在的空白提示。 |
| Q3 | 聽力圖網址 | 維持 `/audiograms`，所有連結和書籤不用改。 |
| Q4 | 「開始篩檢」分頁 | 改成「篩檢」（200% 不折行）；首頁「開始篩檢」按鈕不變。 |
| Q5 | 「我的紀錄」分頁 | 分頁上寫「紀錄」，頁面標題維持「我的紀錄」。 |
| Q6 | 點「了解」到哪 | 新的「了解」入口頁，分組放卡片：助聽器（選配指引）、溝通與照顧（給家人看）。 |
| Q7 | 沒登入看得到「了解」嗎 | 看得到：沒登入的底部是「首頁｜了解｜登入｜註冊」。 |
| Q8 | 頁尾的家人溝通連結 | 留著，「了解」入口頁也放一張。 |
| Q9 | 首頁「您還可以」的「了解」組（#261） | 照舊留著；以後的衛教、找醫院只放「了解」分頁，首頁不再加卡。 |

## 一併確認的細節

- 二選一只出現在 `/my_hearing` 和 `/audiograms` 兩個清單頁。聽力圖的新增、詳細、比較、修改、刪除頁沒有二選一，但底部亮「紀錄」；問卷結果頁也亮「紀錄」。
- 選配指引（摘要頁與六章）和家人溝通頁，底部亮「了解」。
- 不在這次範圍：卡片在 200% 字級時太窄（#264 已經把動作卡片的字改排在圖示下面）。
