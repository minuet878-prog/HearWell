## 逐項查證

### 1. 摘要框「配戴前後 26 → 18 分」的箭頭可能被看成時間先後（低）
- **查證**：屬實。`_aided_difference()` 取最近一筆沒戴、最近一筆有戴，不管誰先做（`views.py` 註解寫 "whichever came first"）。先戴著做、後來才沒戴做時，箭頭方向和時間相反。下方細節段落有各自的日期，不會誤解。
- **分類：要修（本人同意，已修）**：摘要改成「沒戴 26 分、有戴 18 分，少了 8 分」，不用箭頭。這是給醫師看的文件。

### 2. 第 8 條沒測到頁尾和頁首（補測試）
- **查證**：屬實。e2e 只檢查導覽列和列印按鈕；Django 測試只檢查 CSS 裡有 `@media print` 這個字串。刪掉 `footer` 那行規則，兩邊都照樣通過。
- **分類：補測試（已補）**：e2e 的列印步驟加上頁首（目前登入、登出）和頁尾（隱私權說明）在列印時看不見的檢查。

### 3. 沒測「不能顯示 email」（補測試）
- **查證**：屬實。測試的使用者沒有設 email，也沒有斷言 email 不在頁面上；樣板目前確實沒輸出 email。
- **分類：補測試（已補）**：A、B 都設 email，斷言兩個都不在頁面上；B 再加一筆 IOI-HA。

### 4. 沒有加 `never_cache`（低）

### 6. 本人意見：第 2 頁大標離紙的上緣太近
- **查證**：Playwright 產生 PDF 時預設邊界是 0；第 2 頁從段落中間換頁，上方沒有留白。一般瀏覽器列印通常會自己加邊界，但每個瀏覽器不一樣。
- **分類：要修（已修）**：列印樣式加 `@page { margin: 1.5cm; }`。加了之後免責聲明被擠到第 3 頁，再把列印時的段落間距縮小（1.5rem → 1rem），重新產生 PDF 確認是 2 頁。
