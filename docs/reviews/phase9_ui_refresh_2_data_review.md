## 審查後本人發現的 bug（2026-10-17）

- 現象：趨勢圖頭尾的日期被切掉，手機 320px 上五個日期全部重疊。審查與自動測試都沒抓到（前端測試在 jsdom 沒有真的排版；e2e 只量了寬度與捲動）。
- 根本原因：自訂橫軸刻度時拿掉了 `tickFormatter={dateOf}`。Recharts 用 `tickFormatter` 的結果量字寬來決定要藏哪些刻度、頭尾要不要往內移（`getTicks.js` 的 `getTickSize`），拿掉後改量原始值（紀錄編號，一個字寬）。
- 修正：加回 `tickFormatter`（只給 Recharts 量寬度用，畫面仍由自訂刻度畫兩行）；補 e2e `test_trend_dates_stay_inside_and_apart`，先看它在兩種寬度都失敗再修。前端只有這一處自訂刻度。
- 本人看過修正後再決定：橫軸不加時間（提示框、卡片照舊加），日期間至少 27px（`minTickGap`）；e2e 改檢查間隔，規格 4.3、驗收 8 已改。
- 本人再追加：同一天同一條直線、最多最近五天、同天同狀態只畫最後一筆；摘要框照舊用全部紀錄、卡片照舊全部列出（規格 4.1–4.3、驗收 8、16–18）。
