## #155 找到並修好的問題：推薦頁在 320px／200% 字級要左右捲動

- 症狀：320px 寬、字級 200% 時，精靈推薦頁的頁面寬 333px，超過 320px，要左右捲動。首頁、註冊、同意、精靈前兩步、作答頁都沒有這個問題。
- 根本原因：推薦卡的圖示和標題排在同一行（`questionnaire.html` 的 `flex items-center gap-4`），而且不會換行。問卷卡片 `.questionnaire-card` 在窄螢幕（`@media (max-width: 35em)`）有 `flex-wrap: wrap`，推薦卡沒有。標題裡的代碼「HHIE-S」不能斷行（放大後 125px），加上 3rem 圖示和間距就超出 320px。整站只有這裡把圖示和標題並排。
- 為什麼原本的測試沒抓到：原本的沒 JS 測試把字級設成 200%（根元素 32px），剛好放得下；新測試照 `SharedLayoutTest` 的做法用 225%（網站基礎 112.5% 的兩倍，根元素 36px）就超出了。
- 修法（本人選 A：在 #155 分支修，沿用既有規則）：推薦卡那一行加 class `recommended-heading`，併進 `.questionnaire-card` 那條窄螢幕 `flex-wrap: wrap` 規則，沒有新增任何數值。寬螢幕不受影響。
- 證明：`e2e/main_flow.py:120` `test_first_visit_pages_fit_a_phone_at_double_text_size` 的推薦頁檢查（`:151`）。修之前失敗（333 > 320），修之後通過。
