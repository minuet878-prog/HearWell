- `screening/main_flow.py`：
  - `home_more(user)` 用 `fitting_state`（#258）的目前這一站挑推薦，第一個符合的就是：
    1. 缺頻率：修改這張聽力圖
    2. 沒有聽力圖：記錄醫院的聽力圖
    3. 其他站：了解助聽器選配與補助
    4. 沒有目前這一站、沒分享過：分享報告給家人
    5. 沒有目前這一站、分享過（含已失效、已撤回）：印聽力報告給醫師看
  - 也組出四組小卡，每組有固定代號；`convenience` 那組在主畫面 App 裡隱藏。
- `screening/scoring.py`：`NEXT_STEP_REASONS` 收七句「因為」句，跟 #257 的表逐字相同，畫面上前面加「因為：」。
- `screening/templates/screening/index.html`：
  - 大框是「不能點的框」，裡面只有一顆按鈕，沒有滑過或按下的效果（ADR 0006）。
  - 小卡沿用 #256 的動作卡片，只有圖示和標題。
  - 被推薦的那張不會再出現在下面的分組裡；整組空掉時不顯示組標題。
- `screening/templates/screening/action_icon.html`：新增聽力圖、加到主畫面兩個圖示。
- `frontend/src/site.css`：大框（`.next-step-`）、組標題（`.more-group-`），只用藍色系與中性色。

### 自審後順帶修的共用樣式（本人決定一起修）

- **#256 的動作卡片**（首頁小卡、結果頁、我的紀錄、聽力圖頁共用）：字放大時，標題原本被擠成一字一行。改成卡片內寬小於 11rem 時，標題排到圖示下面。在 320、390、412、768px 的一般字級下截圖，跟修改前逐像素相同。
- **大框**：320px、字放大 225% 時，「（45%）。」超出白色底框。原因是括號、數字和句號依中文斷行規則不能拆開，加上兩層內距太寬。改成「您還可以」區段內寬小於 14rem 時縮小兩層內距，「因為」那段允許在任何地方斷行。一般字級在 320、390、412px 下內距不變（量計算後的值）。
