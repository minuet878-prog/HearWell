## 本人決定（規格之後追加）

1. 已登入但還沒同意新版隱私權說明的人，小助手所有頁放行，跟訪客一樣。
2. 首頁置頂的急症框沿用家人溝通頁的「馬上就醫」框（藍框），不用紅色（ADR 0007）。
3. 急症那題不列在任何主題頁，答案頁回連結回小助手首頁（照原型）。
4. 隱私權說明維持「我們會提早刪除那一筆」。
5. 在 admin 提早刪除的提問紀錄（單筆與批次）也先計入月統計再刪。
6. 「診斷與用藥」只寫文字、不放連結（網站沒有耳鼻喉科頁）。
7. 同意頁與隱私權頁頂端的「先看重點」不加提問紀錄。
8. admin 刪除確認頁只顯示「提問紀錄 #N」、不顯示原文（避免原文進 admin 操作紀錄）。
9. 外觀改版（2026-10-27，第一次人工驗收後，taste-skill 比較頁選 B 並照 ADR 0022 調整）：首頁改成急症就醫框 → 依主題找 → 大家常問 → 打字問（主題移到常問前面，跟原型 #373 不同）；四個主題是白色大方塊（圖示在上、手機兩欄、200% 字級一欄，長名字只在詞與詞之間換行）；所有題目清單是白卡、不放圖示；打字區與「沒回答到您的問題？」是淡藍平面區塊；答案文字不包白卡，「以醫師、聽力師為準」放淡藍提示框。新增「耳朵」圖示。

## 做了什麼

- 「了解」頁新增一組「有問題想問」→ 小助手首頁：急症就醫框置頂 → 大家常問 → 依主題找 → 找不到？打字問。
- FAQ 定義檔（`screening/qa_assistant/content.py`）：每題代碼、主題、題目、答案、來源、查核日期、其他問法、相關問題、是否轉介；大家常問、已拿掉的代碼、同義詞表。
- 每題一頁（`qa/<代碼>`）、主題頁（`qa/topic/<主題>`）、相關問題、已拿掉的代碼轉首頁、不存在的回 404。
- 打字提問：POST → 轉址結果頁（問句不進網址，session 只放題目代碼）；比對只用標準函式庫（正規化 → 同義詞 → 兩字一組重疊，門檻 0.6）；空白或超過 200 字轉回首頁提示。
- 提問紀錄（`QuestionLog`）：原文、第一順位代碼、時間、沒對到的原因；不存帳號、IP、session。打字框旁提醒；隱私權說明加一段、日期改 2026/10/27，同意書版本不變。
- admin：提問紀錄只能改原因、可刪單筆與批次、可篩沒對到；月統計（`QuestionLogMonth`）唯讀。
- 90 天清除：存新紀錄、開 admin 列表、部署（`purge_question_log`，`build.sh` 在 migrate 之後）三個時機，先計入月統計再刪。
- roadmap 的每年查核加上 FAQ 答案。
