## 行為

- 兩頁頂端都是和頁首同色的藍色漸層橫幅，白字標題、一句話，右下角有一排靜止的淡色聲波條（裝飾，讀螢幕軟體不唸，沒有動畫）。白色表單卡片疊在橫幅下緣。
- 註冊頁的「第 1 步／共 2 步：建立帳號」移進橫幅，進度條改成藍底白條。
- 輸入框（只在這兩頁）：2px 深灰外框（`--color-input-border`，在白底上對比 4.7:1；原本的淡框約 1.3:1），高 3.25rem、字 1.25rem，框內左邊有圖示（使用者名稱＝人像、電子郵件＝信封、密碼＝鎖頭；出生年已經有「民國」，不加圖示）。
- 正在輸入：藍框加淡藍光暈，欄位名稱和圖示變藍。
- 填錯（`aria-invalid="true"`）：框變紅、底變淡紅，欄位名稱和圖示變紅，錯誤文字加粗、前面加驚嘆號，不只靠顏色區分。
- 登入頁：「登入」改成整排大按鈕；「註冊新帳號」移到下面「還沒有帳號？」底下，仍會帶 `next`。密碼欄加了和註冊頁同一支程式的「顯示」按鈕，沒有 JavaScript 時這顆按鈕不出現。
- 其他頁的輸入框沒有變（由 e2e 在刪除帳號頁守住）。

## 人工驗收

請在手機（最好也用電腦）操作：

1. 登出後打開登入頁：藍色橫幅、「歡迎回來。」、白色卡片疊在橫幅上；框裡有人像、鎖頭。
2. 點使用者名稱框：框變藍、有淡藍光暈，「使用者名稱」和人像變藍。
3. 密碼打幾個字，按「顯示」：看得到字，按鈕變「隱藏」；再按一次會藏起來。
4. 故意打錯密碼送出：上方出現有驚嘆號的紅字，兩個框都變紅底紅框。
5. 按「註冊新帳號」：註冊頁橫幅有「建立帳號，篩檢結果會幫您存起來。」和第 1 步進度條；四個框有圖示，出生年沒有。
6. 註冊頁兩次密碼故意打不一樣送出：密碼確認框變紅，錯誤文字有驚嘆號。
7. 手機把字放大（系統設定的字級）再看一次兩頁：沒有東西超出畫面或疊在一起。
