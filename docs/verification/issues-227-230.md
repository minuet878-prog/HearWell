    - 任一耳 > 25 dB：M13，連到「去之前準備」。
    - 兩耳都 ≤ 25 dB：M14，只轉述數字。
    - 資料不足：M15，連到「修改這張聽力圖」。

  - 四格順序：問卷、聽力圖、選配、鑑定門檻（照 #218 Solution 列的四件事）。
- 聽力圖結果頁（`audiogram_detail`）：任一耳 PTA > 25 dB 時，「接下來」最後多一個外框按鈕「看我的選配指引」（E3），樣式跟「和以前的聽力圖比較」一樣；兩耳都 ≤ 25 dB 或資料不足時沒有。一耳 > 25、另一耳資料不足時照樣出現（#226 的規則）。
