## 行為

- **回到頂端（#340）**：全站往下捲超過兩個畫面高才出現；右下角藍底白字「↑ 回到頂端」，手機在底部分頁上方。點了滑回頂端（減少動態效果時直接跳），焦點移到頁面大標題。收起時 Tab 到不了、讀螢幕軟體不念。列印、沒有 JavaScript 時沒有。每頁頁尾多留按鈕高度的空白（本人決定，避免按鈕出現時頁面跳動）。
- **捲到才播（#341）**：頁首聲波、首頁插圖與「開始」光圈、歡迎回來儀表、選配路線「目前這一站」光圈，整個進到畫面（扣掉底部分頁；比畫面還高的佔一半）才播一次，捲走再捲回不重播。版面自己變動（字型、展開）把東西推進畫面也會播。減少動態效果：一開始就是最後的樣子。沒有 JavaScript：一打開就播（ADR 0006）。捲動輔助程式 3 秒內沒接手（載入失敗）也改回一打開就播；其中一個功能出錯不影響其他功能。
- **儀表條（#342）**：我的選配指引兩耳的條同時從 0 長到數值、約 1.2 秒先快後慢不回彈；雙耳障礙比率那條捲到它自己那一框才長。正常上限線、門檻線、數字都不動。結果頁分數位置條、SSQ12 位置條不動。
- **跳轉亮框（#343）**：網址帶 # 打開，或點同頁連結（含再點一次），捲動停下、框進到畫面後，目標所在的段落框／並列區塊（家人溝通頁主題）／選配路線一站亮主色藍外框加淡藍光暈，停 1.5 秒再 1.5 秒淡掉。減少動態效果：直接出現、3 秒後直接消失。「跳到主要內容」、作答頁錯誤摘要、配戴比較表單錯誤連結不亮。不移動焦點。
- **表格提示（#344）**：聽力圖比較的兩個數字表格放不下時，還沒捲到的那一邊有陰影（純 CSS，沒有 JavaScript 也有），上方多一行「表格可以左右滑動」；放得下時都沒有；字級、寬度改變會重新判斷；列印不顯示。
