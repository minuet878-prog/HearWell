# 主畫面圖示放大、未登入首頁加提示卡（小改動，無 issue）

日期：2026-11-06。基準：`7eeb317`（origin/main）；分支：`fix/pwa-icon-and-home-prompt`。

狀態：等本人驗收。自動測試全過。這次沒有碰計分、門檻、資料或權限，不需交叉審查。

## 怎麼選的

本人回報兩件事：iPhone 主畫面的鳥太小；沒登入時好像沒有明顯的加入主畫面提示。查過後兩件都屬實：

- 鳥只佔圖示寬度 52%，當初是為了配合 Android 的圓形裁切留的邊，iPhone 也共用同一個比例。
- 說明頁 `/add_to_home` 不用登入就能開，但連結只在老使用者首頁的「方便使用」和帳號頁，未登入時完全找不到。

本人在比較頁（暫存資料夾，沒進版控）選了圖示 B 案、提示 Y 案。

## 行為

- 圖示：iPhone 的鳥約佔寬度 72%；Android 約 63%，尾巴留在安全範圍內（離中心最遠 39.5%，上限 40%）。
- 原本比較頁寫 B 案「多一個圖檔」，實作時發現 `apple-touch-icon.png` 本來就是獨立的檔案，所以沒有多檔案。代價是原始檔只有 `icon.svg` 一份，iPhone 用的 `scale(8.5)` 寫在它的註解裡，重新匯出要照註解做；照錯了 e2e 會失敗。
- 提示卡：未登入，以及已登入但還沒有紀錄的新使用者，在「開始篩檢」下方看到「把聽伴加到手機主畫面」和一句「下次點一下就能打開，不用輸入網址」，點下去到現有說明頁。
- 不顯示的情況：從主畫面打開時（沿用 `data-hide-in-app`）、寬度 768 px 以上。這是看寬度不是看裝置：縮窄的電腦視窗會顯示，橫放的大手機不會。
- 老使用者首頁不變，只有原本的「加到手機主畫面」小卡。

## 限制

- 已經加到桌面的人不會自動更新圖示，要刪掉圖示重新加一次。
- iPhone 不允許網站跳出系統的安裝視窗，所以提示只能帶人去看步驟。
- 390 寬的 iPhone 上，提示卡剛好在第一屏底部（底部導覽列上緣），要稍微往下滑才看得完整。

## 自動測試

- 單元：1627 個通過。新增 `NewUserHomePromptTests`（`screening/tests/test_add_to_home.py`）：未登入與沒有紀錄的新使用者看得到卡片、位置與連結正確，老使用者看不到。
- e2e：280 個通過。新增 `GettingOnTheHomeScreenTest`（`e2e/main_flow.py`）：
  - 手機瀏覽器顯示在開始篩檢與步驟之間，點了到說明頁。
  - 從主畫面打開（390）和寬螢幕（1280）都不顯示。
  - 量圖示白色像素：iPhone 超過 70%、Android 超過 60% 且在安全範圍內。換回舊圖示時這條會失敗（`0.5 not greater than 0.7`），確認測試有效。
- 前端：363 個通過。Ruff check 與 format 通過。

## 自審

Standards、Spec 兩軸分開審（基準 `origin/main`），都沒有硬性違規。處理結果：

- 已修：`layout.html` 註解因這次改動過時；鳥的大小原本沒有測試鎖住（上面第三項）。
- 不改：測試寫死 `code="hhie-s"`、e2e 的 `setUpClass` 重複，都是這個專案既有的寫法。
- 本人決定：卡片原本寫「放到手機桌面」，跟說明頁的「加到手機主畫面」不同。本人決定統一成主畫面，iPhone 選單上寫的也是「加入主畫面」。

## 本人驗收

- [ ] 手機寬度打開未登入首頁，提示卡位置與文字可以接受。
- [ ] 點提示卡到說明頁，標題和卡片一樣是「把聽伴加到手機主畫面」。
- [ ] 部署後在真的 iPhone 刪掉舊圖示、重新加入，鳥的大小可以接受。這一項在這台電腦上驗不到。
