跟規格或設計圖不一樣、或規格沒寫到的地方（請本人驗收時一起看）：

1. **47 列電話從模板搬成一份資料**（`screening/device_centres.py`），頁面照資料產生。原因：56 個連結的撥號目標、讀螢幕軟體的名稱都要跟顯示的號碼一致，由同一筆資料產生就不會對不上。頁面上的字跟設計圖對照表右欄完全相同（有測試守住，見下表驗收 3、28）。
2. **苗栗縣兩個中心唸出來會帶縣市**：來源的名稱是「北區輔具資源中心」「南區輔具資源中心」，沒有縣市。讀螢幕軟體逐個唸連結時唸成「撥打苗栗縣北區輔具資源中心 (037)268-462」，畫面上的字不變。本人 2026-11-16 決定（自審時發現）。
3. **瀏覽器拒絕複製時，那顆「複製信箱」會消失**：規格只寫「打開頁面時不能複製就不顯示」；按下去才被拒絕的情況沒寫。照使用者故事 28（不要有按了沒反應的按鈕）處理：那一顆收起來，信箱還在旁邊。這是我的判斷，本人可以否決。
4. **驗收 15「一頁只有一顆實心按鈕」**：「身障鑑定與鑑定醫院」那一章內文本來就有一顆實心的「查詢」，這次沒動，所以那一章「已記下」時整頁是兩顆（改動前就是）。這次新增的「下一章」不是按鈕；測試在章節結尾數一顆，另外用九號表那一章驗整頁只有一顆。
5. **複製用的程式改成每一頁都載入**（原本只有分享頁、家人專區載入）。檔案很小（約 2KB），延後執行，不擋畫面。
6. **頁尾按鈕在手機上自己一行**：頁尾比現在高約 50px（設計圖已說明）。


用手機寬度操作（最好用真的手機連進來，才試得到撥號）：

1. 了解 → 助聽器選配與補助 → 「九號表：申請助聽器補助」→ 展開「看各縣市輔具中心電話」：每個號碼自己一行、藍色有電話圖示；分機是後面的黑字「轉 211」。對照設計圖的 47 列表看幾列（建議看基隆、新竹縣北區、高雄市北區總站、金門、連江）。
2. 在手機上按一個號碼：跳出撥號畫面，號碼正確、沒有分機。
3. 任一章捲到最下面：有「下一章」＋章名，按了到下一章；「二十五號表」那一章沒有。
4. 登入 →「身障鑑定與鑑定醫院」最下面：先是「看完了嗎？」的題目，再來是下一章，再來是回目錄。回答題目後：「已記下」那一框在上、下一章在下。
5. 任一頁捲到頁尾：信箱下面有「複製信箱」，按了變綠色「✓ 已複製」，約 2 秒變回來；到 LINE 或備忘錄貼上，是 `hearwellweb@gmail.com`。
6. 登入一個 Email 或出生年沒填的帳號 → 帳號設定：「要修改請寫信到⋯」下面有「複製信箱」，按它時頁尾那一顆不變。兩項都填了的帳號沒有這句話和按鈕。
7. 分享報告給家人：「複製連結」跟以前一樣。

注意：`http://` 的區網位址（例如 `http://192.168.x.x:8001`）瀏覽器不讓網頁複製，按鈕不會出現，這是設計好的行為；要試複製請用電腦開 `http://localhost:8001`，或用正式站。
