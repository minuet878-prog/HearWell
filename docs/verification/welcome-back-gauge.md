## 怎麼選的

本人看了三份比較頁（暫存資料夾，沒進版控）：平面版 A–C、活潑版 D–F、動畫版（D–F 加動畫，另附 ADR 0006 不允許的動法對照），選 **D 藍色招呼＋儀表**。只做過沒分級問卷的人，選「藍色招呼＋灰框不畫儀表」。

## 行為

- 招呼區：品牌藍漸層、兩圈淡淡的圓環，白字「歡迎回來！」，下一行「上次是 YYYY/MM/DD 做的」，右邊是新訪客首頁那位長輩（白色身體、白色聲波）。
- 結果框：分級色框疊在招呼區下緣。HHIE-S／HHIA-S 框裡有半圓儀表（綠、黃、紅三段，0 和滿分寫在兩端，指針指在分數），下面是分級、「總分 X 分（滿分 40）」、「看這次結果 ›」。儀表讀螢幕軟體不唸。
- 只做過 IOI-HA、SSQ12、SADL、THI 的人：招呼區一樣，灰框照原本內容，沒有儀表；「看這次結果 ›」也移進框裡。
- 提醒：月曆圖示＋「下次建議 … 再做」；到期時淡藍底加旗子。
- 按鈕：寬螢幕並排，手機上下排。
- 動畫（只播一次，約 2.6 秒）：長輩晃一下、聲波亮兩下，儀表三段依序畫出來，指針從 0 擺到分數停住。「減少動態效果」時都不動，指針一開始就在分數上。
- 字放大到 200%、320px 寬時，長輩不顯示，標題和日期用整條的寬度。
