## 四、本人驗收結果

驗收中發現並修好的（2026-11-12）：

- **iPhone 作答頁變成整張表單**：根本原因是 `crypto.randomUUID` 在 http 區網位址（與 iOS 15.4 以前）不存在，`main` 原本就有，不是改版造成。另開 `fix/random-uuid-fallback` 修在 `main`（紀錄見 `docs/verification/receipt-key-fallback.md`），並合進本分支（`e947c0a`）。本人用 iPhone 確認回到一題一頁。✅
- **聽力報告折疊列打開後，左邊藍條壓到文字與圖**：#328 的 0.3rem 藍條畫在 #471 改成只有 0.25rem 內距的清單列上。本人選擇拿掉報告折疊列的藍條、標題列保留淡藍底（`9a7b66d`，e2e `ColourOnlyFeedbackTest` 改成守新規則）。本人確認不再疊到。✅
