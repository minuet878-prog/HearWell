# 圓形圖示滑過測試的時間問題（#491）

日期：2026-11-13；分支 `fix/491-icon-hover-flake`（從 `main` 的 `001fb85` 開出）。
狀態：只改測試和文件，自動驗證完成；**不需交叉審查**（不碰計分、門檻、資料或權限）。樣式沒改，不需要實際操作驗收。

## 根本原因

`test_icon_circle_stays_visible_on_hover` 在滑鼠移上卡片後馬上比較卡片和圓形圖示的背景色。卡片從白變淡藍有 0.15 秒的 transition，圓形圖示則是立刻變白；機器忙時讀到的卡片還是白色，兩者相同而失敗（`'rgb(255, 255, 255)' == 'rgb(255, 255, 255)'`）。

## 修法

滑過之後用 `wait_for_function` 等到卡片背景已經不是白色、且卡片身上沒有進行中的動畫（transition 跑完），再比較兩個顏色。比較的斷言不變；`site.css` 沒動。

## 順手修：語音香蕉圖滑動測試（PR #530 的 CI）

PR #530 第一次 CI 的 e2e 失敗在另一條測試 `SpeechBananaTapTest.test_a_swipe_on_the_chart_scrolls_the_page_and_picks_nothing`（`[False, False] != [True, True]`），跟這次改的那條測試無關；`main` 最近幾次 CI 都過。

**根本原因：** 測試先在方塊 5 上往上滑 200 px，再從方塊 5 往下滑。放開手指後頁面會因為慣性繼續捲，捲多遠要看觸控事件送得多快：本機同樣滑 200 px，實際捲了 185–475 px（CPU 降速 6–40 倍）。頁面捲超過約 557 px，方塊 5 就跑出畫面頂端，第二次滑動前的檢查就失敗。

**修法：** 第一次滑動停下後，把方塊 5 捲回畫面裡，再記下位置、做第二次滑動。檔案裡 `empty_chart_spot` 也是這樣處理的。斷言都沒改。

| 條件 | 結果 |
|---|---|
| 掃描捲動位置：捲到 550 px 仍在圖上，560 px 起是 `[False, False]` | 和 CI 的錯誤一致 |
| 舊測試＋第一次滑動後強制捲到 600／800／1100 px | 3/3 失敗，訊息和 CI 相同 |
| 新測試＋同一條件 | 3/3 通過；捲回後 scrollY 為 135，第二次往下滑仍有空間 |
| 兩處都修好後，全套 e2e `--parallel 4` 連跑 2 次 | 420 個測試 2/2 通過 |
