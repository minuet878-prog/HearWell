# 圓形圖示滑過測試的時間問題（#491）

日期：2026-11-13；分支 `fix/491-icon-hover-flake`（從 `main` 的 `001fb85` 開出）。
狀態：只改測試和文件，自動驗證完成；**不需交叉審查**（不碰計分、門檻、資料或權限）。樣式沒改，不需要實際操作驗收。

## 根本原因

`test_icon_circle_stays_visible_on_hover` 在滑鼠移上卡片後馬上比較卡片和圓形圖示的背景色。卡片從白變淡藍有 0.15 秒的 transition，圓形圖示則是立刻變白；機器忙時讀到的卡片還是白色，兩者相同而失敗（`'rgb(255, 255, 255)' == 'rgb(255, 255, 255)'`）。

## 修法

滑過之後用 `wait_for_function` 等到卡片背景已經不是白色、且卡片身上沒有進行中的動畫（transition 跑完），再比較兩個顏色。比較的斷言不變；`site.css` 沒動。
