## 選定的數值（#138、#139 照這裡實作）

### 頁首聲波 F（給 #138）

| 項目 | 數值 |
|---|---|
| 位置 | 頁首底部一排長條，左右各留 1rem，長條間距 4px |
| 長條 | 28 條，平均分配寬度；白色、不透明度 8%；上方兩角圓角 4px |
| 停住的樣子 | 每條都是頁首高度的 22%，平坦一排 |
| 跳動 | 3.5 秒、ease-in-out 播一次。每條在 20%、45%、70% 的時間點各自長到不同高度（約停住高度的 1.1～3.2 倍），最後回到平坦高度；每條延遲 0～0.2 秒，錯開跳動 |
| 柔光 | 105 度的斜向漸層，中間 18% 白、兩側透明（30%～70% 之間），從左邊畫面外掃到右邊畫面外；第 1 秒開始，播 2.5 秒、ease-in-out、一次 |
| 總長 | 約 3.7 秒內全部停住（實測：390 與 1024 寬都在 3700ms 結束；4.2 秒時沒有在播的動畫） |
| 減少動態效果 | 完全沒有動畫，直接顯示平坦一排（實測：0 個動畫） |
| 螢幕閱讀器 | 整塊裝飾 `aria-hidden`（實測） |

對比（白字疊在聲波上）：
- 長條停住時，疊到字的地方最低 **4.57:1**（漸層淺端 #3a6bb0 ＋ 8% 白），深端 6.77:1。
- 柔光掃過長條的那一瞬間，淺端最低 **3.3:1**；只疊到柔光、沒疊到長條的地方是 3.75:1。掃完就恢復，和比較頁上標給 E 的情況相同（本人知情選定）。

### 主要按鈕 C「光暈」（給 #139）

| 狀態 | 樣子 | 白字對比 |
|---|---|---|
| 一般 | 由上往下 #1f4e8c → #3a6bb0，膠囊形 | 8.31:1／5.37:1 |
| 滑過 | 同一個漸層，外圍加 0.3rem 的淡藍光暈 `rgba(58, 107, 176, 0.35)` | 8.31:1／5.37:1 |
| 按下 | 由上往下 #173b6a → #2f5c9c，沒有光暈 | 11.23:1／6.71:1 |
| 停用 | 白底、文字 #4d5f78、2px 內框 #8da2bf | 6.51:1（停用元件不受 WCAG 對比要求，仍列出） |

顏色變化用 0.15 秒過渡，「減少動態效果」時取消過渡；不位移（ADR 0006）。

## 給後續票的限制（審查提出）

- **#138**：
  - 比較頁的長條是 JavaScript 產生的。規格要求「沒有 JavaScript 時每頁都播」，所以實作時長條要直接寫在版面模板裡。
  - #120 規格的實作決策寫「聲波是三條裝飾線」，和選定的 F 不符，要改成照這份紀錄（是否更新 #120 的文字，由本人決定）。
- **#139**：
  - 光暈和現在的鍵盤焦點框（0.25rem 的藍色外框）幾乎一樣，「按下」時又把陰影拿掉。實作時鍵盤焦點框要一直看得到，也要和光暈分得出來（#120：「鍵盤焦點：……維持現在的焦點框」）。
  - 滑過、按下、焦點同時發生時誰蓋過誰，也要在實作時定義並測試。
