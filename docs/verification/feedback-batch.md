## 行為

| 項目 | 現在 |
|---|---|
| 系統訊息（全站 12 處） | 從一行粗體字改成整條有底色的框，放在頁面標題上面：成功淺綠底＋白勾綠圓、失敗淺紅底＋白「!」紅圓、說明淺藍底＋白「i」藍圓。一頁最多一則（最新那則）；不自己消失，換頁才不見；不滑、不淡入。成功和說明 `role="status"`、失敗 `role="alert"`；頁面打開時焦點移到這一條（不捲動頁面），螢幕閱讀器會唸；用鍵盤時有藍色框線，用手指或滑鼠沒有 |
| 刪除聽力圖 | 回到清單時多一條「已刪除 2026/09/01 的聽力圖。」（寫出那一張的日期） |
| 取消分享 | 回到分享頁時多一條「已取消分享，原本的連結不能再打開。」 |
| 登出 | 回到首頁時多一條「已登出。」 |
| 訪客保存結果 | 存好後不再自動跳到首頁：保存頁原地換成綠色大框「✓ 結果已經保存」，下面「接下來　首頁會告訴您現在該做哪一步。」和兩個按鈕「看我的下一步」（首頁）、「看這次的紀錄」（我的紀錄），焦點在大框的標題。首頁頂端原本的「✓ 已保存這次結果」拿掉。有一份沒存成時照舊：留在本頁說哪一份沒存成、可以再試一次，不出現大框 |
| 下載我的資料 | 按下後圖示變綠勾、說明換成綠字「✓ 已開始下載，請到手機的「下載項目」找。」，留到離開這一頁；螢幕閱讀器唸「已開始下載……」，每按一次唸一次。沒有 JavaScript 時跟以前一樣 |

跟設計圖不一樣的地方：

- 下載那句：設計圖寫「停約 4 秒再變回來」，做成留到離開頁面（本人 2026-11-16 確認）。這句有兩行，4 秒長輩未必讀得完；也跟換頁後的訊息條一樣不自己消失。代價：跟「✓ 已複製」2 秒變回的做法不同。
- 訊息條拿到焦點：設計圖只寫「會唸出來」。頁面一打開就在的字，螢幕閱讀器通常不會自己唸，所以加了焦點（本人確認）。真的會不會唸，要在 iPhone 的 VoiceOver 上試。
- 「有表單錯誤時不顯示」（設計圖第一段）沒有另外寫：目前 12 處訊息之後都會轉到一般頁面，不會跟表單錯誤出現在同一頁，碰不到。以後有一頁同時有兩種，要回頭補。
- 大框裡拿掉「帳號也建好了」（本人決定）。
