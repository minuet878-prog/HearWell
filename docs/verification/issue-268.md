## 已知限制（另案）

- **聽力圖清單在 200% 字級會橫向捲動**：在 `main`（`9d51c0b`）上量過，390px 與 320px 都撐到 517px。原因是聽力圖卡片的縮圖固定寬度，放大後佔 216px，右邊的日期與程度標籤被擠到 0 寬而超出。改版前就有，跟這次無關；修法要決定縮圖怎麼重排，需要比較頁。
