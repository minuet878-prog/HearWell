## 本人同意在這張票修的問題

家人分享報告在 320px、200% 字級寬到 415px（本人 2026-10-23「在這張票修：只對螢幕版加換行規則，修完重跑列印比對」）。

- 原因：報告本體「重點摘要」的清單左邊縮排在 200% 字級時約 81px，「（2026/09/28）：」這類日期斷不開，撐出畫面；標題也一樣。
- 修法：只在螢幕上讓報告的標題和清單項目可以在任何位置斷行（`site.css` 的 `.health-report :is(h1, h2, h3, li)`，包在 `@media screen`）；表格不動。
- 證明：列印版逐像素相同（見下）；一般字級的螢幕截圖差異像素數跟加規則前完全一樣。
- 沒解決的：本人自己的 `/report` 在 200% 字級仍寬到 459px，是另一個原因（roadmap 小尾巴記的「`main` 裡一個空的 span」），不在這次範圍。

## 途中修掉的問題（這個分支新加的程式造成的）

- 帳號頁的同意日期在 200% 字級超出卡片，被卡片裁掉看不到 → 列可以在任何位置斷行；e2e 加「每組卡片內容不超出卡片」。
- 隱私權頁新聯絡卡的信箱不換行，頁面寬到 510px。原因是 `.card` 把換行規則改成 `break-word`，蓋掉文章本身的 `anywhere` → 聯絡卡加 `wrap-anywhere`，跟分享頁網址的做法相同。
