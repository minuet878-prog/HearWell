# 引導卡拖曳、箭頭與完成印章

2026/11/25。延續 #774／#779 的實機回饋。依本次確認，加入左右箭頭，更新原規格的操作方式。

- 桌面瀏覽器用滑鼠按住引導卡橫向拖曳，放開吸附到最近一張。直立左右箭頭貼齊目前藍卡的左右邊緣，內側留圓角，對齊藍卡的垂直正中央。按下時保留原底色並呈現下沉與內陰影，放開後逐張移動，連按時箭頭固定在原位，依序換卡。換卡途中箭頭短暫淡化，在瀏覽器通知卡片停穩的同一刻恢復，舊瀏覽器以捲動停止的短暫延遲判斷。
- 目前卡片置中，左右淡淡露出相鄰卡片；首尾接起來。首尾用於銜接的視覺副本不接受點擊、鍵盤焦點或讀屏操作。
- 桌面 Chromium 在修正前拖曳後仍停在第一張。回歸測試涵蓋按住連結拖曳時不誤開頁面、左右按鈕切換、單擊仍能打開試算。
- 320px 寬時，修正前第一張可見的印章仍停在動畫起點的 2.4 倍。改用印章原本的版面位置判斷，回歸測試確認未橫向捲動也能播放完成。
- 既有引導頁瀏覽器測試包含鍵盤逐卡導覽、320px 與 200% 字級。另使用 axe-core 4.10.2 重新掃描，0 項違規。新增瀏覽器測試核對 320px 一般字級與 200% 字級下，箭頭仍貼齊藍卡兩側並垂直置中，並驗證按住時下沉、出現內陰影且底色維持原樣。25 項引導頁及相關版面端對端測試與 1 項掃描、52 項後端重點測試、812 項前端測試、前端建置及 Ruff 均通過。
- 使用瀏覽器模擬手機手勢，確認由第一張滑到第五張，再反向回第一張。
- 本次不需交叉審查。實機確認待驗，重點為桌面拖曳與兩側箭頭、手機手指橫滑、第一張完成印章的播放時機。
