## 範圍

本人說「我的紀錄」頁的「要給醫師或家人看？」那塊很醜。比較頁上選了做法 A（整張卡片可以點，加圖示）加上做法 C（多一張分享給家人的卡片），說明不要提醫師，並要求類似的按鈕都改成同樣的樣子。範圍由本人勾選：結果頁底部、聽力圖頁的「接下來」。首頁「您還可以」和報告頁上的分享按鈕不改。

| 地方 | 改之前 | 改之後（卡片標題／說明） |
|---|---|---|
| 我的紀錄 | 「聽力報告」外框按鈕＋灰字「可以印出來或存成 PDF，帶去給醫師看」 | 看／印聽力報告／可以印出來或存成 PDF；傳給家人看／家人不用登入就能看 |
| 結果頁底部（六種問卷共用） | 三顆按鈕排一列：看我的紀錄（實心）、看／印聽力報告、回首頁 | 三張卡片：看我的紀錄（與趨勢）／每一次的結果都在這裡；看／印聽力報告／可以印出來或存成 PDF；回首頁／選其他問卷或功能 |
| 聽力圖頁「接下來」 | 白框裡疊三顆按鈕，日期提示放在按鈕上面 | 拿掉外框，三張卡片：看／印聽力報告／（看舊的那張時）聽力報告放的是最新一張（日期），否則「可以印出來或存成 PDF」；和以前的聽力圖比較／看聽力有沒有變化；看我的選配指引／依您的聽力圖整理下一步 |

- 卡片沿用紀錄卡片的 `.link-card`，另外加 `.action-card` 和左邊的圖示格（`action_icon.html`，淺藍底方格、主色線條圖示；滑過或按下時圖示格變白）。
- 圖示：報告是印表機、分享是三個點連線、紀錄和首頁沿用底部導覽列的圖示、比較是兩條線的聽力圖、選配指引是書。
- 分享的說明沒寫「7 天」，避免跟 `SHARE_DAYS` 不同步。
