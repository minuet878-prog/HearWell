## 本機人工驗收

由本人先執行 schema 更新（只新增比較資料表，不回填或改寫現有作答）：

```bash
python manage.py migrate
```

若之前尚未建立 HHIA-S，再執行 `python manage.py seed_hhia_s`；既有開發伺服器由本人操作。

1. 有完整未配戴 HHIA-S 或 HHIE-S 後開 IOI-HA，確認填答前的依據問卷、日期與分數；填答後結果的來源相同。無有效依據也能完成，僅顯示逐題回答及缺少來源說明。
2. 從 HHI 結果或「我的紀錄」進入「選擇或管理比較」，各選未配戴與配戴紀錄。「查看比較」先預覽，按「保留到報告」才儲存。
3. HHIA-S 與 HHIE-S 各保留一組；新增作答、重新登入不換組，更換／移除其中一組不影響另一組及原作答。
4. 原 HHIE-S 報告只顯示保留組合；未保留時不自動取最新紀錄。完整三組報告整合於 #84 驗收。
5. 用鍵盤操作下拉選單與按鈕；手機放大字級仍能使用。匯出資料確認含保留組合；不在真實帳號上測試刪除。

Migration 回退會移除新比較資料表及保留選擇；已有保留資料時，先規劃備份，不直接反向執行。原始作答與 IOI-HA 固定依據仍在既有資料表。
