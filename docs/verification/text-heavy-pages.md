第一次跑 Django 測試 38 個沒過，逐一看過：

- **1 個是真錯誤**：`score_bar.html` 寫了跨兩行的 `{# #}` 註解（Django 的 `{# #}` 只能單行，跨行會把註解印到頁面上），`test_standards` 抓到。改成單行。
- **其餘是測試寫死了舊的 HTML 結構**，改法都不放寬要保護的東西：
  - 我的紀錄分頁（`test_history`、`test_account_settings`）：代號放進自己的 `<span>`，改成去掉標籤後比對文字，分頁文字仍是「聽力對生活的影響（HHIE-S）」。
  - 選配指引（`test_guide`、`test_guide_form_9`）：頁尾改斷言「資料來源」下拉框，每個來源的文字和網址照舊逐一確認；標題的 `mt-6` 拿掉。提醒框裡原本想把「提醒：」包成粗體，會讓審定的句子在 HTML 裡斷開，所以不加粗，逐字測試照原樣通過。
  - 結果頁順序（`test_pages`）：「完整建議」改比對下拉框的 `<summary>`；作答明細的測試改成找自己的下拉框（現在頁面上有兩個）。
  - 分級尺（`test_result_score_bar`）：改成斷言指標下只有這次的級別、兩端是 0 和滿分，其他級別不出現；用假問卷的門檻確認滿分取自定義。
  - SADL（`test_sadl`）：分數和名稱改在卡片標題與分數標籤裡比對；本人審定的四段說明照舊逐字確認。
  - SSQ12（`test_ssq12`）：改抓卡片裡的題目和分數標籤，順序與內容照舊。
- e2e：HHIA-S 鍵盤作答那條原本用文字找「不能判定聽損程度」，現在頁面上有兩處（條列下面、收起來的完整建議），改成找條列下面那句、確認看得到。分級尺改成檢查這次級別在指標正下方、粗體、兩端 0 和 40；我的紀錄在 390px 寬時分頁排成兩欄。

- CI（Linux）的 e2e 抓到選配指引「配戴之後」在 320px＋200% 字級時寬 321px：資料來源收進下拉框後，框的外距加清單縮排剩下的寬度，比一個英文字（〈Hearing Aids for Adults〉）還窄；macOS 字型窄一點所以本機沒抓到。頁尾加上跟章節本體一樣的 `wrap-anywhere`，長字必要時可以斷開。
