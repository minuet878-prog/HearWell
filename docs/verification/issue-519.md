## 實作時的做法（請本人知道）

- **標記放在每張圖的 `<svg>` 上**（`data-motion`），寫的是 `wear-motion-review.md` 動作表裡的「第幾塊、軸心、起點、時間」。圖裡面的線條一個字都沒動，#504 逐張比對審定圖的測試照舊通過。
- **兩邊對照**：除了頁面測試會比對標記和審定表，我另外用一次性的腳本，把播放程式在 12 張真的圖上每 2.5% 算出的位置，跟審定設計圖裡的動畫逐格比對。會動的零件和跟著動的線都在 0.3 個單位內（設計圖本身四捨五入到 0.1）。這支腳本沒有進版控。
- **Safari**：播放程式逐格改 SVG 的 `transform` 和線條的 `d`，不用 CSS 改路徑形狀。用 Playwright 的 WebKit（Safari 的引擎）跑了一次試驗，12 張都播得出來；有細線、導管、固定線的 8 張，線都跟著零件移動，沒有斷開。#521 的 e2e 兩條也在 WebKit 過了。試驗檔用完已刪除。真的 iPhone 還沒看過。
- **按鈕名稱**：看到的是「▶ 看動作」，讀螢幕軟體念「看動作：推進耳塞」，播完變「↺ 再看一次」／「再看一次：推進耳塞」。原本想用視覺隱藏文字接標題，但 Chromium 會在中間多念一個空格，改用 `aria-label`（開頭跟看到的字一樣，用語音操作的人說「看動作」也點得到）。
- 按鈕照設計圖：「看動作」是實心藍按鈕（`btn-primary`，白字對主色約 8.6:1），播完的「再看一次」是外框藍按鈕（`btn-outline-primary`，主色字對白底約 8.6:1）。鍵盤焦點有藍色光圈。
- 播放中再按一次，會從頭重播。
