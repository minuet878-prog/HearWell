# #668 手機 320px、字放大 200% 的三處超出

## 原因

1. **我的紀錄的問卷分頁列**：分頁格子最窄 `9rem`，字放大 200%（html 225%）時是 324px，比 320px 手機寬，整頁被撐到 351px、會左右捲。
2. **趨勢圖的分數**：圖的左右留白固定 16px，分數的字是 1rem，200% 時「50」寬約 47px，一半 23px 超過 16px，被圖的左緣切掉約 7px。HHIE-S 的「20」、390px 寬也一樣。
3. **推薦區的日期**：「2026/05/01」不能斷行，200% 時比推薦區的文字欄寬，日期後面的「・」擠進右邊內距約 39px。

## 怎麼選的

本人看了設計圖（暫存資料夾的靜態頁，用真實畫面截圖，沒進版控）：第 1、2 處只有一種做法，照設計圖改；第 3 處在「A 推薦區左右內距變窄」和「B 日期可以從中間斷行」中選 **A**。

## 修法

- `.history-tabs`：最窄寬度改成 `min(100%, 9rem)`（同頁「問卷／聽力圖」切換鈕的寫法），放不下就一格一行。
- `TrendChart.jsx`：左右留白改成跟字一起放大，`16 / 18 × 根字級` 取整數（一般字級 16px，200% 時 32px）。取整數是因為單元測試的根字級是 16px，留白變成 14.22px 這種小數時，滑鼠停在第一點會落在圖外、不顯示提示框（兩個既有單元測試因此失敗，取整數後全過）。
- `.recommended-block`：寬度不到 9rem 時（320px＋200%；390px＋200% 不會），左右內距從 1.125rem 縮成 0.5rem。一般字級、390px 都不變。
