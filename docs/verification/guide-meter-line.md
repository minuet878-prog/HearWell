# 我的選配指引：橫條黑線拿掉白邊、改成上下突出（小改動，無 issue）

日期：2026-10-24。基準：`9f7bf65`（main）；分支：`fix/guide-meter-line`。

狀態：自動測試全過，等本人實際操作驗收。只改橫條上黑線的畫法，沒改計分、分級、門檻數字，沒有 migration、沒碰權限，所以不需要交叉審查。沒有操作真實資料；截圖在臨時測試資料庫上拍。

## 問題

驗收 #318 時本人發現：「正常上限 25」「門檻 45%」那條黑線有白邊（`box-shadow: 0 0 0 0.1rem #fff`）。色條剛好停在線上（兩耳都 25 dB）時，畫面變成「色條→一條白縫→黑線」；比率 0.0% 時，白邊在淺灰底上是一條淡淡的白線。#260（`be8dca3`）就有，`main` 一樣，不是 #318 造成的。

白邊原本的用意：黑線壓在深藍色條上對比只有 1.9:1（紅色上 2.8:1），白邊讓它看得到。

## 怎麼選的

本人看了比較頁（暫存資料夾，沒進版控）：現況、A 只拿掉白邊、B 黑線上下突出、C 一條線從最上面穿到標籤、D 橫條裡不畫線只畫上下短刻度，選 **B**。

## 行為

- 黑線沒有白邊，色條停在線上時直接碰到黑線。
- 黑線比橫條高，上下各露出 0.3rem 在米色底上（對比 14:1），所以壓在深藍色條上時，靠上下露出的部分仍看得出位置。
- 每組最下面一條橫條的黑線往下接到「正常上限 25」／「門檻 45%」的線。
- 做法：每條橫條外面多包一層 `.meter-drawing`（`aria-hidden` 移到這層），黑線放在這層、不放在橫條裡，才能超出橫條的圓角外框。
