# 「我的紀錄」趨勢圖載入時把紀錄卡片推走（無 issue）

日期：2026-10-22。基準：`adb4e42`（main，#144 合併後），中途同步到 `edf01a7`（#145、#146）；分支：`claude/sleepy-hofstadter-c946ab`；commit：`720d246`（重現測試）、`64efc8d`（修正）、`66c0eee`（自審修正）。

狀態：自動測試與自審（Standards／Spec）已通過，等本人操作驗收。沒碰計分規則、分級門檻、資料 migration、權限，**不需交叉審查**：摘要的文字規則從前端搬到後端，分數和分級文字仍然來自 `with_scores()` 與 `classify()`，門檻只讀不改。未操作真實資料；沒有啟動開發伺服器，截圖都在 e2e 的臨時測試資料庫上拍。不需 migration。

## 問題與根本原因

PR #144 的 e2e 在 CI 上時過時不過時，查出「我的紀錄」頁一打開，作答紀錄卡片先出現在上方，接著被往下推。

原因：`my_hearing.html` 裡的 `<div id="trend-chart">` 一開始是空的（高度 0）。`TrendChart.jsx` 要等 `/api/submissions/`、`/api/questionnaires/` 和字型（最多 3 秒）都好了，才一次畫出標題、摘要框、圖、圖例和分級名稱，整塊高 800–2900px，把下面的卡片一口氣推下去。長者正要點卡片時，卡片會跳走。

重現測試（`e2e/main_flow.py:561`，先擋住紀錄 API 的回應，量第一張卡片，再放行讓圖畫出來）在修正前的結果：

| 情境 | 被推下 |
|---|---|
| 320px | 883px |
| 390px | 856px |
| 1280px | 836px |
| 390px、200% 字級 | 2253px |

只預留一個固定高度不夠：摘要框、圖例、分級名稱在窄螢幕和大字級會換行，整塊高度差到 120px（100% 字級）至 1300px（200% 字級）。

## 做法（本人選定）

- **做法 C**（2026-10-22 本人選「照建議」）：標題、說明、摘要框、圖例、分級名稱改由 Django 產生（`views._trend_chart`、新模板 `trend_chart.html`）；React 只在固定 20rem 高的框（`#trend-plot`）裡畫折線圖。頁面一開始就是最終高度，任何寬度、任何字級都不會跳。
- **載入中顯示選項 B**（2026-10-22 本人看比較頁後選「照建議」）：框中間一行灰字「趨勢圖載入中…」。比較頁在分支 `prototype/trend-chart-loading`（`db6fa78`），不合併。
- 沒有 JavaScript：整張圖卡（圖框、圖例、分級名稱）隱藏，摘要框保留。以前整塊都不見，現在不用 JS 也看得到摘要。
- 螢幕閱讀器：「載入中」那行和圖本身照舊不讀（摘要框和卡片已經用文字說了同樣的事）；「趨勢圖暫時無法顯示」的錯誤訊息照舊讀得到。
- 錯誤訊息改放在圖框正中間（字級照舊是 `text-xl`），摘要框照常顯示。以前是整塊換成一句錯誤訊息。
- 前端刪掉 `trend.js` 的 `summarize`，測試搬到 `screening/tests/test_history.py`。

## 行為差異（刻意的）

- 摘要的「上一次」以前只在 API 第一頁（最新 20 筆、所有問卷混在一起）裡找；現在從這份問卷的全部紀錄找，結果只會更準。圖例同樣看全部紀錄。
- 圖本身仍然只用 API 第一頁。

  - **Standards**：0 項硬性違規。採納：圖例文字改由 view 帶出（模板不再重複判斷形狀）、e2e 等請求加上 5 秒上限（原本請求沒來會卡住）。不採納：圖例形狀在模板和 React 各畫一份（做法 C 本身的取捨，兩邊各有測試）、分級顏色與 `level-badge` 同一組（都引用同一組主題變數）、「載入中」文字兩份（註解說明，React 一開始會清掉伺服器輸出的內容）、SVG 寫死色碼（照搬原本 React 的值以維持逐像素相同）。

## 已知限制與後續

- 如果某人最新 20 筆紀錄裡完全沒有 HHIE-S（例如之後連做 20 次別的問卷），摘要照常顯示，但圖框會是空的（React 拿不到點）。以前這種情況整塊不顯示。真的發生時可以讓 API 依問卷篩選。
- 截圖工具在聽力圖頁（390px）兩次拍攝會差幾個到上千個像素，比對時會誤報。

## 人工驗收

請實際操作確認（用手機或把瀏覽器縮窄）：

1. 登入有 HHIE-S 紀錄的帳號，打開「我的紀錄」：標題、摘要框、圖例、分級名稱一打開就在，圖框先顯示「趨勢圖載入中…」，畫好後換成圖；下面的紀錄卡片從頭到尾不動。
2. 網路慢的時候（例如手機用行動網路第一次打開）再看一次：卡片一樣不動。
3. 手機把字放大到最大，再看一次：卡片不動、不用左右捲動。
4. 點一張紀錄卡片：進到那一筆的結果頁。
