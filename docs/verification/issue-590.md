- **每一頁都有三個預覽標記**（LINE 只讀這三個）：
  - 標題：那一頁的分頁標題。公開頁面是 #589 的新標題，其他頁面是各自原本的標題。
  - 描述：公開頁面用自己的描述；其他頁面（分享報告連結、訪客篩檢入口、登入頁等）用全站通用的一句（建議表 E1）。
  - 圖片：全站同一張，完整網址。正式站的靜態檔名帶內容雜湊，換圖時網址會自動變，LINE 會重新抓。
- 分享報告的封面、報告、失效三頁：預覽標題是「聽伴聽力報告」或「連結已經失效｜聽伴」，描述是通用的那一句，不會帶出名字、分數或分級。

## 實作時的做法（請本人知道）

- **分享報告頁的分數保護測試改了一點**（本人 2026-11-16 在對話中決定）：它原本檢查頁面上不能有「數字＋分」，把通用描述的「花 3 分鐘」當成分數。改成「數字＋分，但後面不是鐘」，照樣抓得到「12 分」。
- **分頁標題和預覽標題用同一份字**：新增一個小的模板標籤 `{% capture %}`，把標題算一次、用兩次（Django 不允許同一段標題在版型裡出現兩次）。
- **500 錯誤頁的預覽描述和圖片是空的**：Django 畫「網站出了一點問題」那一頁時，不經過補這些資料的那一步。這一頁不會被分享，所以不改。
- 預覽圖用網站的字型輸出時，字型要從同一個來源載入：直接開本機檔案（`file://`）時，瀏覽器不肯載入網頁字型，所以輸出時用 Playwright 把 repo 的檔案當成網站提供。
