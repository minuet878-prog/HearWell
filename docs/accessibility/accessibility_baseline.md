## 1. 量測方法（照著做可以重現）

### 1.1 環境

- 本機 `python manage.py runserver`（由本人啟動），DEBUG 模式。

### 1.3 自動檢查：axe-core

在每一頁的 DevTools Console 貼上：

```js
if (!window.axe) { await new Promise((ok, err) => { const s = document.createElement('script');
  s.src = 'https://cdnjs.cloudflare.com/ajax/libs/axe-core/4.10.2/axe.min.js';
  s.onload = ok; s.onerror = err; document.head.appendChild(s); }); }
const r = await axe.run(document, { runOnly: { type: 'tag',
  values: ['wcag2a', 'wcag2aa', 'wcag21a', 'wcag21aa', 'wcag22aa'] } });
r.violations.map(v => ({ id: v.id, n: v.nodes.length,
  nodes: v.nodes.map(n => n.target.join(' ') + ' ' + (n.any[0]?.data?.contrastRatio ?? '')) }))
```

- 版本固定 **axe-core 4.10.2**；規則只跑 WCAG 2.0／2.1／2.2 的 A、AA。
- 圖表（SVG）裡的文字，axe 會列在 `incomplete`（算不出背景色），**不算違規也不算通過**。要另外用 `getComputedStyle` 取文字與色帶顏色自己算對比；線條、符號看 WCAG 1.4.11 非文字對比（3:1）。
- 記錄每條規則的違規數，以及代表性的元素和對比值。

### 1.4 手動檢查清單

| 項目 | 怎麼檢查 | 合格標準 |
|---|---|---|
| 鍵盤操作 | 只用 Tab／Shift+Tab／空白鍵／方向鍵完成「登入 → 作答 → 看結果」 | 能完成，焦點順序合理 |
| 焦點可見 | Tab 時看得到目前焦點在哪 | 每個可操作元素都有可見焦點 |
| 200% 縮放 | 瀏覽器放大到 200%（或視窗縮成一半寬） | 不需要左右捲動、文字不重疊不被切掉 |
| 觸控尺寸 | DevTools 量按鈕、選項、連結的大小 | 至少 44×44 CSS px |
| 字級 | 內文、說明文字 | 用 rem，內文 ≥ 1rem |
| 選項群組 | 作答頁每一題 | 用 `fieldset`／`legend` 把題目和選項綁在一起 |
| 頁面語言與標題 | `<html lang>`、`<title>` | 有設定，而且每頁標題能分辨 |

> axe 抓不到「選項沒有分組」：作答頁修正前完全沒有 `fieldset`，axe 沒有算違規。這項只能靠手動清單。

### 5.3 錯誤狀態
